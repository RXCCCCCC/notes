### 0. 考试题型与策略建议

- **选择题（20分）**：共10道题，每题2分。这部分得分率通常比大题高，但做错一道就扣2分，必须细心，老师特别提醒不要在这上面“一不小心错4个丢8分”。
- **解答题（80分）**：由几道大题组成，通常是按步骤给分的流程题（如15-20分一道），避免了“一题错全盘皆输”的风险。

### 1. 编译器的整体结构 (Compiler Phases)

- 

	**核心考点**：熟记编译器各个阶段的名称及相互间的输入输出关系 。  

- 

	**常见题型**：给出一个简单的赋值语句（如 `b=a+i*2`）和一幅带有空白方框的流程图，要求填入对应的编译器组件名称 。  

- 

	**必备概念**：Scanner（词法分析器）、Parser（语法分析器）、Semantic analyzer（语义分析器）、IR Generation（中间代码生成）、Code generator（目标代码生成）以及与所有阶段交互的 Symbol table（符号表）和 Error handler（错误处理） 。  

### 2. 词法分析 (Lexical Analysis)

这一单元重点考察从文字描述到状态机的“全流程”转化，是必考的一道大题 。  

- **正则表达式 (Regular Expressions)**：

	- 根据文字描述写出正确的正则表达式。
	- 反向操作：给出正则表达式，写出其表达的文字含义。

- **自动机完整构造流程 (The Full Pipeline)**：

	- **NFA 构造**：根据正则表达式画出 NFA（非确定有限状态自动机）。老师强调：**不要过度简化 NFA**，哪怕多画几个带 $\epsilon$ 转移的圆圈，也要避免因过度简化导致后续出错。

	- 

		**NFA 转 DFA**：熟练使用**子集构造法 (Subset Construction)**，并画出状态转换表 (Transition table) 和对应的 DFA 状态图 。  

	- 

		**DFA 最小化**：使用 Hopcroft 算法（划分终态与非终态集合）最小化 DFA 的状态，并说明理由 。  

- **校验技巧**：构造完最终的最小化 DFA 后，务必用最初始步的“开头”、“结尾”逻辑去校验一遍 DFA 是否符合原始意图，作为自我检查的手段。

### 3. 语法分析 (Syntax Analysis)

语法分析分为自顶向下（Top-Down）和自底向上（Bottom-Up），通常各占一道大题 。  

- **基础概念**：

	- **二义性 (Ambiguity)**：证明一个文法是二义性的方法是——针对**同一个输入串**，画出**两棵不同的语法树 (Parse Trees)**。

	- 

		**推导与句型**：熟练写出最左推导 (Leftmost derivation) 和最右推导 (Rightmost derivation) 。  

	- 

		**核心要素求解**：求解给定右句型 (Right sentential form) 的**句柄 (Handle)** 和**可行前缀 (Viable prefixes)** 。  

- **自顶向下分析 (Top-Down / LL(1))**：

	- 

		**文法重写**：消除左递归 (Eliminate left recursion) 和提取左公因子 (Left factoring) 。  

	- 

		**集合计算**：准确计算每个非终结符的 **FIRST 集** 和 **FOLLOW 集** 。  

	- 

		**LL(1) 判别**：根据计算结果解释该文法是否为 LL(1) 文法 。  

	- 

		**预测分析表**：构造 LL(1) 预测分析表 (Parsing table) 。  

- **自底向上分析 (Bottom-Up / SLR(1))**：

	- 

		**构造 DFA**：直接计算闭包并绘制基于 LR(0) 项目集的 DFA 。  

	- 

		**冲突分析与判别**：判断文法是否为 LR(0)；如果不是，指出存在的冲突（通常是**移进-归约冲突 Shift-Reduce Conflict**），并结合 FOLLOW 集证明其是否为 SLR(1) 文法 。  

	- 

		**分析表与动作追踪**：构造 SLR(1) 分析表，并针对给定的输入串，写出包括“步骤、状态栈、符号栈、输入串、动作 (Action)”的完整语法分析过程表 。  

### 4. 语义分析与属性文法 (Semantic Analysis & Attribute Grammars)

本部分的核心是理解“语法制导翻译”，通常为一道大题 。  

- 

	**属性文法**：理解综合属性 (Synthesized attributes，如 `.val`) 和继承属性 (Inherited attributes，如 `.len`, `.h`) 。  

- 

	**抽象语法树 (AST)**：根据给定的源代码和语义规则，画出抽象语法树 。  

- 

	**依赖图 (Dependency Graph)**：在树形结构上画出属性之间的依赖图 。  

- 

	**属性计算**：根据语义方程，在依赖图上直接推导并计算出根节点或特定节点的最终属性值 。  

### 5. 中间代码生成 (Intermediate Code Generation)

这部分考察将高级语言转换为机器无关的形式，通常为一道大题 。  

- 

	**三地址码 (Three-Address Code)**：将 C/C++ 的简单代码（如 `for` 循环、`while` 循环、`if-else` 条件判断、赋值语句等）翻译成三地址码序列 。  

- 

	**控制流翻译**：熟练掌握布尔表达式的短路计算，以及循环体中 `true`、`false`、`next` 等标号（Label）和 `goto` 语句的跳转逻辑（如回填技术 Backpatching 的结果） 。
