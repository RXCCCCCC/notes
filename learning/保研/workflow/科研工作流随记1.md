# 初识文献提示词

```
你现在是一位ai4se领域的专家，认真研读所上传的论文，用中文的学术语言撰写一份详尽且深刻的文献报告;
因为我是该领域的初学者,所以你要帮助我深入理解该论文内容、学术意义和创新之处。你的回答必须基于论文,不能瞎编;你可以联网搜索相关的文献和内容; 如遇专有名词或文章里的概念，请在中文总结时于词后添加括号并附上英文名称。报告需内容全面、结构好看、标题清晰、语言通俗易懂，要求如下：

摘要:系统、详尽地概述论文的核心内容，包括研究主题、研究动机、研究问题和研究方法、主要发现与结论。确保信息密度高、概括性强；
背景：阐明该研究的问题背景、学术语境、研究目标、主要内容与方法，以及当前领域的研究空白。明确该研究为何重要、解决了什么问题。在背景部分结尾，明确列出论文的研究问题（Research Questions）和假设（Hypotheses）；
文献综述梳理文章所引用的重要文献；根据论文引用的文献特点，灵活选择时间顺序、主题分类或混合分类方式，并在报告中说明分类依据，确保逻辑清晰。归纳总结文章中引用的核心文献，提炼这些文献中的主要观点、研究方法、结论与贡献。对每篇核心文献进行批判性分析，讨论其局限性或不足，并说明这些不足如何为当前研究问题提供了契机。详细分析作者是如何通过引用与讨论上述文献，逐步过渡到自身的研究问题。强调这一逻辑演进过程，阐明作者研究动机的合理性与创新点。在适当情况下，提及XX领域内未被引用的相关重要文献，分析其与当前研究的关联性或差异性。结构清晰、逻辑严密，突出从‘已有研究’到‘研究问题’的过渡过程，帮助我理解该研究是如何在学术语境中被提出的。
方法：准确、清晰地描述论文的研究设计，包括受试者信息（Participants）、实验材料（Materials）、实验程序（Procedure）等关键要素；
实验和结果：详尽介绍实验设置、操作过程、数据采集方式与关键实验结果，分析数据的意义并解释与研究假设之间的关系；
讨论：总结和讨论文章的Discussion 部分，总结文章研究的主要结果，突出关键发现。对研究结果进行深入分析,列举作者讨论了哪些方面,作者如何分析他的发现; 详细阐明作者如何将自己的研究结果与文献综述中提到的相关研究进行对比，指出相似点、差异及可能的解释;
结论:简要概括作者认为该文章的不足和缺点,以及阐述未来的发展方向(一定要是作者说的,你不能瞎编)
输出格式如下:
层级清晰的标题结构：每一大部分使用一级标题（如“摘要”、“背景”等），每部分内部根据内容适当使用二级标题（如“研究动机”、“研究问题”）提升条理性。
段落分明，逻辑清晰：每个自然段围绕一个中心思想，避免过长段落；逻辑过渡自然，便于阅读理解。
关键词标注突出：对于术语（如“输入假设 (Input Hypothesis)”或“快速映射 (Fast Mapping)”），使用加粗或括号标注中英文术语，突出重点，便于检索与记忆。
中文学术表达准确、凝练：使用中文学术语言，风格正式、简明，避免口语化；对于英文概念或术语应在首次出现时注明英文。
引用与出处格式统一：引用文献时，统一使用括号形式注明作者及年份，如（Smith, 2020），必要时指出该文献的具体研究结论或方法。
段首引导句明确：每一段开头用一句话明确段落核心内容，增强逻辑引导性。
合理使用项目符号或编号（如列出研究问题、假设、方法要素时），增强条理性与可读性。
总字数控制在报告要求范围内，各部分字数尽量靠近预期，不可偏离过多。
```

# 2. 中英文文献导入

## 2.1 英文文献导入

1. 通过浏览器插件导入
	该方法适合边搜索边导入，通过浏览器检索文献时，**随手导入临时文件夹。**
	外文文献导入示例：

	![外文文献导入示例](./%E7%A7%91%E7%A0%94%E5%B7%A5%E4%BD%9C%E6%B5%81%E9%9A%8F%E8%AE%B01/be8985ac6d0e08ddce9b85b36840c40508c76677_2_690x425.png)

2. 参考文献格式导入
	适合针对特定对象进行计量分析、文献综述等，方便快速汇集大量文献数据。
	通过构建合理的检索式检索文献后，批量选择，之后寻找页面上 Export ，下载文件。（不同数据库位置不同，过程相似）
	下载文件后，在 Zotero 中`文件 -> 导入` **通过文件批量导入。**
	外文文献 IEEE 示例：

	![外文文献导入示例](./%E7%A7%91%E7%A0%94%E5%B7%A5%E4%BD%9C%E6%B5%81%E9%9A%8F%E8%AE%B01/be8985ac6d0e08ddce9b85b36840c40508c76677_2_690x425.png)

3. 直接拖入 PDF 文档
	如果已有文献 PDF 文档，可**直接将 PDF 文件拖入主界面完成导入。**
	若无法自动获取文献元数据，可**右键条目，创建父条目，填入通过网页检索到的 DIO、ISBM、PMID、arXiv 或者 ADSBibcode 识别信息导入文献信息。**

1. 各种标识符的作用：

	- DOI：**数字对象标识符（Digital Object Identifier）**，用于期刊文章、会议论文、研究报告等。

	- ISBN：**国际标准书号（International Standard Book Number）**，**仅限书籍**类型。

	- PMID：**PubMed标识符（PubMed ID），生物医学文献。**

	- arXiv ID：**arXiv 预印**本服务器中的文献标识符。一般用于物理、数学、计算机科学等领域发表前的版本，目前人工智能领域前沿文章通常会先发布 arXiv 版本。

		创建父条目图示：

		![创建父条目图示](https://cdn3.linux.do/optimized/4X/f/f/1/ff1651294d6465ca9f53710eb7703c10d229bb05_2_690x380.png)

		创建父条目图示1352×745 72.6 KB

		IEEE 查询文献 DIO（论文）示例：

		![IEEE 查询文献 DIO（论文）](https://cdn3.linux.do/optimized/4X/0/b/d/0bd8a6aaa83f03079d1802fc927e1bf4149a9e68_2_690x283.png)

# 3. 文献分类管理

## 3.1 文献分组

1. 文献的移动
	文献移动有两种不同方式：
	a. **直接拖动条目到另一个分类文件**夹：
	选择的文献条目将同时存在于当前分类和拖入的新分类。

	- 这种方式相当于在另一分类中**创建了一个快捷方式**
	- 在任意分类中修改该条目，另一分类中相同的条目内容也会改变。

	![文献的移动](./%E7%A7%91%E7%A0%94%E5%B7%A5%E4%BD%9C%E6%B5%81%E9%9A%8F%E8%AE%B01/41fafd0ea1860a43cd64b779abdf821ae3951e43_2_480x500.png)

	b. **按住“shift”拖动**条目：将选择的文献条目移动到新分类，条目**只存在于新分类**。

	![shift拖动](./%E7%A7%91%E7%A0%94%E5%B7%A5%E4%BD%9C%E6%B5%81%E9%9A%8F%E8%AE%B01/43355fe98e52507185f9dfcfb0181486a1b001df_2_483x500.png)

2. 文献的查看
	选中文献条目，**长按 `Ctrl` 键，当前条目所属的分类将高亮显示。**

	![文献分类显示](./%E7%A7%91%E7%A0%94%E5%B7%A5%E4%BD%9C%E6%B5%81%E9%9A%8F%E8%AE%B01/859b361a24850ce2893888ed166d5a22991f147f.png)

	选中父分类**，默认不会显示子分类中的条目，可以选中`查看->显示子分类中的条目`，此时如图所示，子分类中的条目将一起显示。**

	

	![显示子分类中的条目](./%E7%A7%91%E7%A0%94%E5%B7%A5%E4%BD%9C%E6%B5%81%E9%9A%8F%E8%AE%B01/b2fd66b11b7c0942d6d46cfdb57f9bbaaa817a30_2_690x277.png)

3. 文献的删除与恢复
	a. **从当前分类移除条目**：

	- 移除条目**不会将文献条目从数据库中删除（不会移入回收站）**
	- **通过直接拖动创建的“快捷方式”也不会被删除**
	- 选中**我的文库仍能找到该文献条目**
	- 恢复：移除条目并未真正删除文献条目，也没有放入回收站，无法直接恢复，需要从我的文库中找到条目，再拖入需要的分类。

	

	![移除条目](./%E7%A7%91%E7%A0%94%E5%B7%A5%E4%BD%9C%E6%B5%81%E9%9A%8F%E8%AE%B01/cc76798aeb44adc674e6df0b969264e60ada0659_2_690x348.png)

	b. **删除**条目

	- 删除条目会**将文献条目从数据库中删除（移入回收站）**
	- 通过**直接拖动创建的“快捷方式”也会被删除**
	- 选中**我的文库无法找到该文献条目**
	- 恢复：删除的条目直接放入回收站，可直接右键还原到文献库，同时该文献的“快捷方式”也会恢复。

	

	![删除条目](./%E7%A7%91%E7%A0%94%E5%B7%A5%E4%BD%9C%E6%B5%81%E9%9A%8F%E8%AE%B01/8ceee0a80e13f162a4db30960f57122de9495960_2_690x302.png)

	c. 删除分类

	- 删除分类与前面移除条目类似，**不会真正删除文献条目**

	- 但是**删除的分类会放入回收站**

	- 恢复：可在回收站**直接右键还原到文献库，该分类中的文献条目将保留**

		![删除分类](./%E7%A7%91%E7%A0%94%E5%B7%A5%E4%BD%9C%E6%B5%81%E9%9A%8F%E8%AE%B01/e5c0bdceb5b561ccb7aa8b58ba68b4af010daf03.png)

		d. 删除分类及条目

	- 删除分类及条目将会删除分类，**同时删除该分类下的所有文献条目**

	- 删除的分类和条目**会放入回收站中**

	- 被删除的文献条目的**“快捷方式”也会被删除**

	- 恢复：在回收站中分类和条目是**分开的，需要分别还原分类及条目**

4. 文献的**去重**

	- 重复是指：**我的文库中相同的条目**，**不包括在不同分类中的“快捷方式”**
	- 重复主要**来源于重复导入文献，此外还有创建的条目副本，手动添加的文献等**
	- 选中重复条目分类**，会显示重复的条目**，选中重复的条目后，**可按需执行删除操作，也可以合并重复的条目。**

	

	![文献的去重](./%E7%A7%91%E7%A0%94%E5%B7%A5%E4%BD%9C%E6%B5%81%E9%9A%8F%E8%AE%B01/b0685aefc6126c3478ad5ad0242d19817b0377a0_2_690x198.png)

## 3.2 文献标签

1. 查看文献标签

	- 主界面**左下角标签选择器**
	- **右侧边栏选择文献标签**

	![文献标签](./%E7%A7%91%E7%A0%94%E5%B7%A5%E4%BD%9C%E6%B5%81%E9%9A%8F%E8%AE%B01/97b8458a40931e26d288a1884034a9c54d8a33ff_2_690x362.png)

2. 自定义标签
	通过**右侧边栏打开文献标签**，点击`+`号，输入标签名称。

	> **通用文献标签**
	> **阅读状态：初步纳入，已精读，已验证**
	> **价值判断：高价值，一般，弃用**
	> **文献用途：方法论，综述，基准，启发**

3. 通过标签筛选文献
	在标签选择器中点击标签，**主窗口中显示筛选后**的文献条目。

	![通过标签筛选文献](./%E7%A7%91%E7%A0%94%E5%B7%A5%E4%BD%9C%E6%B5%81%E9%9A%8F%E8%AE%B01/53ea56020a768f2816c7ba5ad2a88bcf4f06d443_2_690x375.png)

4. 给标签分配颜色
	可以给常用标签**分配不同的颜色和位置**，这些标签将显示在所有标签前面，并**且会在文献条目前显示不同颜色**

	![给标签分配颜色和位置](./%E7%A7%91%E7%A0%94%E5%B7%A5%E4%BD%9C%E6%B5%81%E9%9A%8F%E8%AE%B01/b5c82803adf022ac4700668bbbea77f8de9f98d8_2_690x376.png)

	

# 4. 文献阅读与笔记

1. 初筛论文

	- 右侧边栏选**择摘要，可快速查看文献摘要**。
	- 通过 **Awesome GPT 插件总结**文章解决的问题，解决问题的思想，文章的评价指标等，初步筛选论文。
	- 打开文献原文，主要**阅读文章解决的问题，分析系统结构图、原理图，文章给出的评价指标**等。
