# Java 期末复习讲义：第5章 循环 (Loops)

## 1. 三大循环结构核心总结

Java 中的循环与 C++ 非常相似，但在条件判断的类型检查上更为严格。

### 1.1 `while` 循环 (Pre-test Loop)
先判断，后执行。如果条件一开始为假，循环体一次都不会执行。

*   **语法：**
    ```java
    while (loop-continuation-condition) {
        // loop-body
        statement(s);
    }
    ```
*   **适用场景：** 循环次数**未知**的情况（例如：读取用户输入直到输入0）。

### 1.2 `do-while` 循环 (Post-test Loop)
先执行，后判断。**保证循环体至少执行一次**。

*   **语法：**
    ```java
    do {
        // Loop body;
        statement(s);
    } while (loop-continuation-condition); // 注意：这里必须有分号
    ```
*   **易错点：** `while(...)` 后面的**分号 `;` 不能漏**，这是语法要求。
*   **适用场景：** 循环体必须至少运行一次的情况（例如：菜单交互，先显示菜单再判断是否继续）。

### 1.3 `for` 循环
代码最紧凑，通常用于循环次数**已知**的情况。

*   **语法：**
    ```java
    for (initial-action; loop-continuation-condition; action-after-each-iteration) {
        // loop body
    }
    ```
*   **执行顺序：**
    1.  初始化 (`initial-action`) - **仅执行一次**。
    2.  判断条件 (`loop-continuation-condition`)。
    3.  如果为 `true`，执行循环体。
    4.  执行迭代后操作 (`action-after-each-iteration`)。
    5.  回到步骤 2。

## 2. 考试高频陷阱与易错点 (Logic Errors)

课件中用多个页面强调了这些错误，期末考试极易出现在**代码查错**或**选择题**中。

### 2.1 致命的分号 (The Semicolon Trap)
**错误示例 1 (`for`循环)：**
```java
for (int i = 0; i < 10; i++); // <--- 错误！这里的每一个分号结束了循环
{
    System.out.println("i is " + i); 
}
```
*   **后果：** 循环体被视为空语句，后面的 `{}` 代码块只会在循环结束后执行一次。且如果在块内访问 `i`，会报错（因为 `i` 的作用域仅在 `for` 括号内）。

**错误示例 2 (`while`循环)：**
```java
int i = 0;
while (i < 10); // <--- 错误！
{
    System.out.println("i is " + i);
    i++;
}
```
*   **后果：** 这是一个**死循环**（Infinite Loop）。程序会一直卡在 `while(i<10);` 这一行，因为 `i` 永远不会增加。

### 2.2 浮点数比较陷阱 (Floating-point Equality)
**原则：不要在循环控制中使用浮点数进行相等性比较。**

*   **错误代码：**
    ```java
    double item = 1; 
    while (item != 0) { // item 可能永远不会精确等于 0
        sum += item;
        item -= 0.1;
    }
    ```
*   **原因：** 计算机内部使用浮点数（近似值）表示小数。`1.0 - 0.1 - 0.1 ...` 最后的结果可能是一个极小的非零数（如 `0.00000000000001`），导致死循环。
*   **C++对比：** C++ 也有这个问题，但在 Java 考试中常作为理论考点。

### 2.3 无限循环写法
如果省略 `for` 循环的条件部分，默认为 `true`。
```java
// 写法 A (for)
for ( ; ; ) { 
    // ... 
}

// 写法 B (while) - 推荐，可读性更好
while (true) {
    // ...
}
```

## 3. Java 与 C++ 的重要区别 (重点)

这是软件工程专业学生必须区分的考点：

1.  **条件表达式必须是 Boolean 类型：**
    *   **C++：** `while(1)` 或 `while(count)` 是合法的，非零即真。
    *   **Java：** **非法！** 编译报错。Java 严格要求条件必须产生 `boolean` 值 (`true`/`false`)。
    *   *修正：* 必须写成 `while(true)` 或 `while(count != 0)`。

2.  **变量作用域：**
    *   在 `for(int i=0; ...)` 中定义的 `i`，其作用域仅限于该循环块内。这点与标准 C++ 相同，但老式 C++ 编译器可能允许 `i` 泄露到外部。

3.  **逗号运算符的限制：**
    *   Java 的 `for` 循环允许在初始化和迭代部分使用逗号分隔多个语句，但不如 C++ 里的逗号运算符通用。
    *   *合法示例：* `for (int i = 0, j = 0; i + j < 10; i++, j++) { ... }`

## 4. 流程控制：break 与 continue

*   **`break`：** 立即**跳出当前所在的整个循环**。
*   **`continue`：** 立即**结束本次迭代**，直接进入下一次循环的判断（对于 `for` 循环是先去执行 `i++` 再判断）。

**示例分析 (TestContinue.java):**
```java
while (number < 20) {
    number++;
    if (number == 10 || number == 11) 
        continue; // 如果是10或11，跳过 sum += number，直接回 while 判断
    sum += number;
}
```
*注意：在 `while` 中使用 `continue` 时，务必确保迭代变量的更新（如 `number++`）在 `continue` 之前执行，否则可能导致死循环。*

## 5. 经典算法示例：寻找最大值及出现次数

课件最后的 Quiz 是一个非常经典的算法题，考试可能会要求手写代码。

**题目：** 读取一串以 0 结束的整数，找出最大值，并统计最大值出现的次数。
**输入：** `3 5 2 5 5 5 0`
**输出：** 最大值 5，出现次数 4

**代码逻辑 (背诵级)：**

```java
import java.util.Scanner;

public class MaxCount {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Enter numbers: ");
        
        int number = input.nextInt(); // 读取第一个数
        int max = number;             // 假设第一个就是最大
        int count = 1;                // 计数初始化为 1
        
        while (number != 0) {         // 只要不是 0 就继续
            number = input.nextInt(); // 读取下一个
            
            if (number > max) {       // 情况1：发现更大的数
                max = number;         // 更新最大值
                count = 1;            // 重置计数器为 1
            } 
            else if (number == max) { // 情况2：发现和最大值相等的数
                count++;              // 计数器 +1
            }
            // 情况3：比max小，忽略
        }
        
        System.out.println("Largest: " + max);
        System.out.println("Count: " + count);
    }
}
```

## 6. 复习建议

1.  **手动追踪代码：** 找一段包含 `break` 或 `continue` 的复杂循环代码，在纸上画出变量的变化过程（Trace Table）。
2.  **区分 While 和 Do-While：** 只要看到 "at least once"（至少一次）这个词，立刻选 `do-while`。
3.  **语法填空：** 注意 `for` 循环括号内的三个部分是用**分号 `;`** 分隔，而不是逗号。
4.  **改错题敏感度：** 看到 `for(...);` 或 `if(...);` 或 `while(...);`，警惕分号陷阱。看到 `double` 做循环计数器，警惕精度陷阱。
