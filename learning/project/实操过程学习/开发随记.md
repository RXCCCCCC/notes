# 大知识点

## ubuntu创建用户
```
adduser rxc
```

系统会提示你设置密码和一些信息：

```
New password:              # 输入密码（不会显示）
Retype new password:       # 再输入一次
Full Name []:              # 可以直接回车跳过
Room Number []:            # 回车跳过
Work Phone []:             # 回车跳过
Home Phone []:             # 回车跳过
Other []:                  # 回车跳过
Is the information correct? [Y/n]   # 输入 Y 确认
```

把用户加入 sudo 组, ittinker 换成你自己上面创建的那个用户

```
usermod -aG sudo rxc
```

验证一下：

切换到新用户 ittinker 换成你自己上面创建的那个用户

```
su - rxc
```

# 测试 sudo 是否生效
```
sudo whoami
```

如果输出 root，说明 **sudo 配置成功。**
