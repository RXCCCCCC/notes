## ⼀、基本数据操作

1.数据输⼊与格式化

批量填充：拖动单元格右下⻆的填充柄⾃动填充（数字、⽇期、公式）。按住ctrl可叠加填充

设置格式：右键单元格 → 设置单元格格式，调整数字、⼩数位、货币、⽇期等格式。

2.⾃动换⾏与合并单元格

⾃动换⾏：选择单元格 → Ctrl+1 → 对⻬ → 勾选“⾃动换⾏”。

合并单元格：选中区域 → 点击⼯具栏“合并单元格”。

3.快速清除

清除内容：选中区域 → 按 **Delete 清除内容。**

清除格式： 开始 → 清除 → 清除格式 ，仅删除格式保留内容。

## ⼆、排序与筛选

1.排序

升序/降序：选中数据区域 → 点击“排序” → 选择按列升序或降序。

多条件排序：点击“排序” → 添加条件 → 设置优先级。

2.筛选

快速筛选：选中数据标题 → 数据 → 筛选，勾选需要的数据值。

⾼级筛选：数据 → ⾼级筛选，可设置筛选条件区域和结果输出区域。

## 三、数据填充与公式操作

1.填充序列

连续数字/⽇期：拖动填充柄时**按 Ctrl 可快速⽣成⾃定义序列。**

2.公式复制

批量应⽤公式：拖动填充柄或双击填充柄快速向下扩展公式。

固定引⽤：⽤ \$ 固定单元格引⽤，例如 \$A\$1(不会随着填充而改变) 。

## 四、常⽤表格设置

1.表格美化

边框设置： Ctrl+1 → 边框 → 设置线条样式。

条件格式： 开始 → 条件格式 → 新建规则 ，如按颜⾊标注⼤于某值的单元格。

快速应⽤表格样式： 开始 → 格式化为表格 。

2.冻结窗格

固定标题⾏： 视图 → 冻结窗格 → 冻结首行 。

固定⾸列： 视图 → 冻结窗格 → 冻结首列 。

⾃定义冻结：选中要冻结的单元格下⽅⼀⾏或右侧⼀列 → 冻结窗格。

3.列宽和⾏⾼调整

⾃动调整：双击列或⾏边缘⾃动适应内容宽度。

⼿动调整：拖动列或⾏边界，或右键 → 设置⾏⾼/列宽。

## 五、数据分析与统计

1.透视表

创建透视表： **插入** → 透视表 ，选择数据区域并添加到⾏、列、值等区域。

动态更新：右键透视表 → **刷新**数据。

2.数据分列

⽂本分列：选中数据 → 数据 → 分列，根据分隔符（如逗号、空格）分割内容。

3.合并计算

数据汇总： 数据 → 合并计算 ，选择数据区域进⾏求和、平均值等。

4.数据验证

限制输⼊： 数据 → 数据验证 ，设置允许输⼊的数字范围、列表选项等。

## 六、图表操作

1.快速创建图表

选中数据 → 插⼊ → 选择图表类型（柱状图、折线图、饼图等）。

快捷键：选中数据后按 **Alt+F1 创建默认图表**。

2.图表美化

更改颜⾊：选中图表 → 点击图表⼯具栏更改颜⾊、样式。

添加数据标签：右键图表 → 添加数据标签。

3.动态图表

使⽤公式或表格引⽤动态数据源，实现图表⾃动更新。

## 七、⼯作表管理

1.插⼊与删除

插⼊新⼯作表：点击底部“+”号，或右键 → 插⼊⼯作表。

删除⼯作表：右键 → 删除⼯作表。

2.⼯作表重命名

双击⼯作表名称直接编辑。

3.保护⼯作表

保护内容： 审阅 → 保护工作表 ，设置密码。

解锁部分单元格：选中单元格 → **Ctrl+1** → **锁定**单元格 ，取消勾选。

4.⼯作表视图

同时查看多个表： **视图 → 新建窗口** ，然后排列窗⼝。

## ⼋、快捷键总结

1.常⽤快捷键

选择整列： Ctrl+Space ；选择整⾏： Shift+Space 。

插⼊⾏/列： Ctrl+**Shift+“+”** ；删除⾏/列： Ctrl+“-” 。

2.导航与查找

快速跳转：按 Ctrl+方向键 到达区域边界。

快速筛选：按 Alt+下箭头 调出筛选菜单。

# excel常⽤函数

## ⼀、数学与统计函数

### 1.求和与计数

SUM ：求和，例如 =SUM(A1:A10)

COUNT ：计数⾮空单元格数，例如 =COUNT(A1:A10)

COUNTA ：计数⾮空单元格（包括⽂本），例如 =COUNTA(A1:A10)

COUNTIF ：**按条件**计数，例如 =COUNTIF(A1:A10,">10")

2.平均值

AVERAGE ：求平均值，例如 =AVERAGE(A1:A10)

3.最⼤/最⼩值

MAX ：求最⼤值，例如 =MAX(A1:A10)

MIN ：求最⼩值，例如 =MIN(A1:A10)

4.四舍五⼊

ROUND ：四舍五⼊，例如 =ROUND(A1, 2)

ROUNDUP ：向上取整，例如 =ROUNDUP(A1, 2)

ROUNDDOWN ：向下取整，例如 =ROUNDDOWN(A1, 2)

5.随机数

RAND ：⽣成0到1之间的随机数，例如 =RAND()

RANDBETWEEN ：⽣成指定范围内的随机整数，例如 =RANDBETWEEN(1, 100)

## ⼆、逻辑函数

### 1.条件判断

IF ：条件判断，例如 =IF(A1>10, "大于10", "小于等于10")

IFERROR ：错误处理，例如 =IFERROR(A1/B1, "错误")

2.多条件判断

AND ：多个条件同时满⾜，例如 =AND(A1>10, B1<20)

OR ：满⾜任意条件即可，例如 =OR(A1>10, B1<20)

NOT ：取反，例如 =NOT(A1>10)

### 三、⽂本处理函数

1.拼接与拆分

CONCAT ：拼接多个⽂本，例如 =CONCAT(A1, B1)

TEXTJOIN ：⽤分隔符拼接多个⽂本，例如 =TEXTJOIN(",", TRUE, A1:A5)

LEFT ：提取左边的字符，例如 =LEFT(A1, 3)

RIGHT ：提取右边的字符，例如 =RIGHT(A1, 3)

MID ：从中间提取字符，例如 =MID(A1, 2, 3)

2.查找与替换

FIND ：查找指定字符位置（区分⼤⼩写），例如 =FIND("a", A1)

SEARCH ：查找指定字符位置（不区分⼤⼩写），例如 =SEARCH("a", A1)

REPLACE ：替换指定位置的字符，例如 =REPLACE(A1, 2, 3, "abc")

SUBSTITUTE ：替换指定内容，例如 =SUBSTITUTE(A1, "old", "new")

3.格式化

TRIM ：删除多余空格，例如 =TRIM(A1)

LEN ：计算字符⻓度，例如 =LEN(A1)

TEXT ：按格式显⽰⽂本，例如 =TEXT(A1, "yyyy-mm-dd")

## 四、⽇期与时间函数

### 1.⽇期与时间提取

TODAY ：获取今天的⽇期，例如 =TODAY()

NOW ：获取当前⽇期和时间，例如 =NOW()

YEAR ：提取年份，例如 =YEAR(A1)

MONTH ：提取⽉份，例如 =MONTH(A1)

DAY ：提取⽇期，例如 =DAY(A1)

2.⽇期与时间计算

DATEDIF ：计算两个⽇期的差值，例如 =DATEDIF(A1, B1, "d")

EDATE ：计算偏移⽉的⽇期，例如 =EDATE(A1, 3)

EOMONTH ：获取⽉末⽇期，例如 =EOMONTH(A1, 0)

## 五、查找与引⽤函数

1.单值查找

VLOOKUP ：按列查找，例如 =VLOOKUP(10, A1:C10, 2, FALSE)

HLOOKUP ：按⾏查找，例如 =HLOOKUP(10, A1:C10, 2, FALSE)

2.多值查找

INDEX ：按⾏列索引查找，例如 =INDEX(A1:C10, 2, 3)

MATCH ：返回值的位置，例如 =MATCH(10, A1:A10, 0)

XLOOKUP ：灵活查找，例如 =XLOOKUP(10, A1:A10, B1:B10)

3.动态引⽤

INDIRECT ：动态引⽤单元格，例如 =INDIRECT("A"&B1)

OFFSET ：基于偏移量引⽤单元格，例如 =OFFSET(A1, 1, 1)

## 六、其他常⽤函数

1.信息函数

ISNUMBER ：判断是否为数字，例如 =ISNUMBER(A1)

ISTEXT ：判断是否为⽂本，例如 =ISTEXT(A1)

ISBLANK ：判断是否为空，例如 =ISBLANK(A1)

2.财务函数

PMT ：计算贷款每⽉还款额，例如 =PMT(利率, 期数, -贷款金额)

3.⾃定义名称与动态数组

使⽤动态数组函数（如 UNIQUE 提取唯⼀值， SORT 排序）。
