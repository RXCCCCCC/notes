# Java 程序设计复习讲义：第3章 选择结构 (Selections)

## 1. 核心数据类型：`boolean`

在Java中，逻辑判断的基础是 `boolean` 类型。

### 关键点（考试必考）
*   **取值**：只有两个值 `true` 和 `false`。
*   **与C++的重大区别**：
    *   **C++**：`0` 是 false，`非0` 是 true。`if(1)` 是合法的。
    *   **Java**：**`boolean` 与整型（int）不能相互转换。**
    *   **错误示例**：`if (1) { ... }` // 编译错误！Type mismatch: cannot convert from int to boolean.
    *   **正确示例**：`if (x != 0) { ... }`

### 关系运算符 (Relational Operators)
用于比较两个值，结果必定是 `boolean`。
*   `<`, `<=`, `>`, `>=`
*   `==` (等于), `!=` (不等于)

> **⚠️ 易错坑点**：
> 不要混淆 `=` (赋值) 和 `==` (比较)。
> *   `if (count = 0)` 在Java中通常会报错（除非 count 本身是 boolean），而在C++中这是合法的逻辑（赋值后判断结果）。

## 2. if 语句 (if Statements)

Java提供了三种形式的 if 语句：
1.  **单向 (One-way)**: `if (condition) { ... }`
2.  **双向 (Two-way)**: `if (condition) { ... } else { ... }`
3.  **多向/嵌套 (Multi-way/Nested)**: `if ... else if ... else`

### 语法规范与陷阱
*   **代码块 (Blocks)**：
    *   建议始终使用花括号 `{}` 包裹语句块，即使只有一行代码。这能避免“悬空 else”问题，也方便后续维护。
*   **悬空 else (Dangling else)**：
    *   规则：`else` 总是与**最近的、未匹配的** `if` 配对（在同一个块级作用域内）。
    *   *修正方法*：通过 `{}` 强制指定配对关系。

### ❌ 常见逻辑错误 (Common Errors) - 课件 P21
这是期末考试中最喜欢出的“找错题”。

**错误 1：if 后加分号**
```java
double radius = 10;
if (radius >= 0);  // <--- 这里的 ; 导致 if 语句立即结束
{
    // 这里的代码块变得与 if 无关，无论 radius 是多少都会执行
    area = radius * radius * PI; 
}
```
*   **后果**：这通常不是编译错误，而是**逻辑错误**。

**错误 2：布尔变量的赋值误用**
```java
boolean even = false;
if (even = true) { // 赋值操作！表达式的值为 true
    System.out.println("It is even"); // 永远会被打印
}
```
*   **修正**：应使用 `if (even == true)` 或更简洁的 `if (even)`。

**错误 3：冗余判断**
*   **Bad**: `if (even == true)`
*   **Good**: `if (even)`
*   **Bad**: `if (even == false)`
*   **Good**: `if (!even)`

## 3. 逻辑运算符 (Logical Operators)

用于组合多个布尔表达式。

| 运算符 | 名称       | 说明                         |
| :----- | :--------- | :--------------------------- |
| `!`    | 非 (NOT)   | 逻辑取反                     |
| `&&`   | 与 (AND)   | **短路与** (Conditional AND) |
| `||`   | 或 (OR)    | **短路或** (Conditional OR)  |
| `^`    | 异或 (XOR) | 相同为false，不同为true      |

### 🔥 重点考点：短路效应 (Short-circuiting)
考试中常出现包含自增/自减操作符的复杂表达式，让你判断变量的最终值。

*   **`&&` (短路)**：如果左边为 `false`，则**不计算**右边。
*   **`||` (短路)**：如果左边为 `true`，则**不计算**右边。

**经典例题 (课件 P16 变体):**
```java
int x = 1;
// 情况 A: 使用 &&
if ((x > 1) && (x++ < 10)) { ... }
// 分析: (1 > 1) 为 false。由于是 &&，右边 (x++ < 10) 被跳过。
// 结果: x 仍然是 1。

int y = 1;
// 情况 B: 使用 & (非短路，虽然通常用于位运算，但在boolean中表示逻辑与但不短路)
if ((y > 1) & (y++ < 10)) { ... }
// 分析: 左边 false，但 & 强制计算两边。右边 y++ 执行。
// 结果: y 变成了 2。
```
> **提示**：在常规编程中，绝大多数情况应使用 `&&` 和 `||`。`&` 和 `|` 在处理 boolean 时很少使用，除非刻意需要副作用（side effects），但这通常被视为坏代码风格，却是考试爱考的陷阱。

## 4. switch 语句 (switch Statements)

用于基于单个变量的值选择执行路径。

### 语法结构
```java
switch (switch-expression) {
    case value1: 
        statement(s);
        break; // 可选，但通常必需
    case value2:
        statement(s);
        break;
    default:   // 可选
        statement(s);
}
```

### 规则 (课件 P41-42)
1.  **支持的数据类型**：
    *   **基本类型**：`char`, `byte`, `short`, `int`。
    *   **其他**：`String` (Java 7+), `enum` (枚举)。
    *   **注意**：**不支持** `long`, `float`, `double`, `boolean`。
2.  **Case 值**：必须是**常量表达式**（字面量或 final 常量），不能包含变量（如 `1+x` 是非法的）。
3.  **穿透效应 (Fall-through)**：
    *   如果没有 `break`，程序会继续执行下一个 case 的语句，直到遇到 break 或 switch 结束。
    *   **考试技巧**：遇到 switch 题目，一定要手动 trace 代码，画出何时遇到 break。如果题目问输出结果，大概率考察的是漏写 break 导致的穿透。

**示例 (Fall-through):**
```java
int day = 2;
switch (day) {
    case 1: 
    case 2: 
    case 3: 
    case 4: 
    case 5: System.out.println("Weekday"); break; // 1-5 都会走到这里
    case 0: 
    case 6: System.out.println("Weekend");
}
// 输出: Weekday
```

## 5. 条件表达式 (Conditional Expressions)

也称为**三元运算符 (Ternary Operator)**。

**语法**：
`(boolean-expression) ? expression1 : expression2;`

*   若条件为 true，结果为 expression1。
*   若条件为 false，结果为 expression2。

**示例**：
```java
// if-else 写法
if (num % 2 == 0)
    System.out.println(num + " is even");
else
    System.out.println(num + " is odd");

// 三元运算符写法 (课件 P52)
System.out.println( (num % 2 == 0) ? num + " is even" : num + " is odd" );
```
> **注意**：三元运算符要求 expression1 和 expression2 的类型必须兼容（或者能统一转换），否则可能编译报错。

## 6. 运算符优先级 (Operator Precedence) - 课件 P54

考试中如果出现复杂表达式，遵循以下优先级（从高到低）：

1.  **后缀**：`var++`, `var--`
2.  **一元**：`+`, `-` (正负号), `++var`, `--var`, `!` (非), `(type)` (强制转换)
3.  **乘除**：`*`, `/`, `%`
4.  **加减**：`+`, `-`
5.  **关系**：`<`, `<=`, `>`, `>=`
6.  **相等**：`==`, `!=`
7.  **异或**：`^`
8.  **逻辑与**：`&&`
9.  **逻辑或**：`||`
10. **赋值**：`=`, `+=`, `*=`, etc.

**记忆口诀**：
*   算术运算 > 关系运算 > 逻辑运算 > 赋值运算。
*   `!` 优先级极高。
*   `&&` 优先级高于 `||`。

## 7. Java 与 C++ 的核心差异总结 (针对考试)

| 特性         | C++                            | Java                                 |
| :----------- | :----------------------------- | :----------------------------------- |
| **Boolean**  | `int` (0/1) 可互换             | 独立类型，**不可**与 int 混用        |
| **if 条件**  | `if (x)` (只要x非0即真)        | 必须是 `if (x != 0)` (必须是boolean) |
| **变量声明** | 可以在条件中声明 `if(int i=0)` | 不允许在 if 条件括号内声明变量       |
| **Switch**   | 主要是整型/枚举                | 支持整型、枚举，以及 **String**      |

## 8. 期末备考 Checklist

1.  [ ] **语法检查**：检查 `if` 括号后是否有分号 `;`。
2.  [ ] **类型检查**：检查 `switch` 的变量是否是 `double` 或 `float`（这是非法的）。
3.  [ ] **逻辑追踪**：对于 `&&` 和 `||`，注意是否发生了**短路**，导致后面的自增(`++`)没执行。
4.  [ ] **Switch 追踪**：注意 `break` 是否存在，不仅看匹配的 case，还要看后面“漏下去”执行的代码。
5.  [ ] **格式规范**：如果题目考代码填空，记得 `if` 和 `else` 最好加上 `{}`。
6.  [ ] **浮点数比较**：虽然本章未重点提及，但切记不要用 `==` 直接比较两个 `double`，可能会有精度问题（应使用 `Math.abs(a-b) < 1e-6`）。
