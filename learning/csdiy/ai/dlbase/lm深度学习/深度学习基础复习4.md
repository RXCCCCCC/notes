## 为什么RNN中要用tanh这个激活函数

RNN 中常用 $\tanh$，主要因为它适合处理**隐藏状态 hidden state** 的递归更新。

RNN 的典型形式是：

$h_t = \tanh(W_{xh}x_t + W_{hh}h_{t-1} + b)$

为什么用 $\tanh$：

1. **把隐藏状态限制在 $[-1, 1]$**

这样可以**避免隐藏状态数值无限变大，让训练更稳定。**

1. **输出有正有负，均值接近 0**

$\tanh$ 的输出范围是 $[-1,1]$，**比 sigmoid 的 $[0,1]$ 更适合作为隐藏表示，因为正负值都能表达信息**。

1. **引入非线性**

如果不用激活函数，RNN 多个时间步叠起来本质上还是线性变换，表达能力很弱。

1. **一定程度缓解数值爆炸**

因为 $\tanh$ 会**压缩较大的输入，所以可以抑制隐藏状态过大。**

但注意：$\tanh$ 不能彻底解决梯度消失问题。RNN 长序列训练困难，主要还是因为反向传播时梯度要经过很多个 $W_{hh}$ 和 $\tanh'$。所以后来才有 LSTM、GRU。

一句话记忆：

**RNN 用 $\tanh$ 是为了让隐藏状态有界、中心化，并引入非线性，使序列建模更稳定。**

在 RNN 的隐藏状态里，一般不用 sigmoid 或 ReLU，主要是因为它们各有明显问题。

**1. 为什么不用 sigmoid？**

sigmoid 输出范围是：

$\sigma(x) \in (0,1)$

问题是：

- 输出永远非负，**不以 0 为中心；**
- 容易饱和，**输入很大或很小时梯度接近 0；**
- 更**容易导致梯度消失。**

相比之下，$\tanh$ 输出范围是：

$\tanh(x) \in (-1,1)$

它是 **zero-centered 零中心化** 的，隐藏状态可以**表达“正向/负向”两类信息，优化通常更方便。**

**2. 为什么不用 ReLU？**

ReLU 是：

$\text{ReLU}(x)=\max(0,x)$

问题是：

- 输出**无上界**，RNN 会**反复递归更新，数值可能越滚越大；**
- 更容易**出现 hidden state exploding，即隐藏状态爆炸；**
- 负数**直接变成 0，可能造成 dead ReLU，信息丢失。**

在普通前馈网络/CNN 中，ReLU 很常用；但在 RNN 这种反复循环的结构里，**有界激活函数**通常更稳定。

**一句话总结：**

RNN 隐藏状态常用 $\tanh$，因为它**比 sigmoid 更适合表达正负信息，比 ReLU 更不容易数值爆炸。**

# 深层 RNN Deep RNN

# 一、深层 RNN Deep RNN

# 1. 什么是深层 RNN？

普通 RNN / GRU / LSTM **只有一层循环层：**

$X_t \to H_t \to O_t$

深层 RNN 是把**多个循环层堆叠起来：**

第 1 层处理输入序列**，得到隐藏状态序列**；

**第 2 层再把第 1 层的隐藏状态序列当作输入；**

第 3 层继续往上堆叠。

可以理解为：

$X_t \to H_t^{(1)} \to H_t^{(2)} \to \cdots \to H_t^{(L)} \to O_t$

其中 $L$ 是层数。

实验八中也写到：普通 LSTM 是**“输入序列 → LSTM → 输出”**，深度 LSTM 是“输入序列 **→ LSTM 第 1 层 → LSTM 第 2 层 →** 输出”。

# 2. 深层 RNN 的公式理解

以第 $l$ 层为例：

第一层：

$H_t^{(1)} = f(X_t, H_{t-1}^{(1)})$

第二层：

$H_t^{(2)} = f(H_t^{(1)}, H_{t-1}^{(2)})$

第 $l$ 层：

$H_t^{(l)} = f(H_t^{(l-1)}, H_{t-1}^{(l)})$

最后输出通常**由最高层隐藏状态得到：**

$O_t = H_t^{(L)}W_{hq}+b_q$

这里的 **$f$ 可以是普通 RNN 单元，也可以是 GRU 或 LSTM。**

# 3. 深层 RNN 为什么有用？

浅层 RNN **只能对序列做较简单的表示。**

深层 RNN 通过**多层抽象，可以学习更复杂的序列模式：**

- **底层学习局部、短期**模式；
- **高层学习更抽象、更长程**的语义模式。

例如文本任务中：

- 第一层可能学习字符组合、局部词形；
- 第二层可能学习短语结构；
- 更高层可能学习句子级语义。

所以深层 RNN 的作用类似 CNN 变深：

**通过堆叠层数增强表达能力。**

# 4. 深层 RNN 一定更好吗？

不一定。

层数增加后，优点是**表达能力更强，但代价也明显：**

1. **参数更多，计算量更大；**
2. **训练速度变慢；**
3. **更容易过拟合；**
4. **梯度传播路径更长，更容易梯度爆炸或消失；**
5. **通常更需要梯度裁剪、Dropout、LayerNorm 等稳定训练方法。**

实验八也要求思考“层数增加后，模型一定更好吗”“为什么深度循环神经网络训练速度会变慢”“为什么深层 RNN 更容易需要梯度裁剪”。

考试答法：

**深层 RNN 通过堆叠多个循环层增强模型表达能力，但层数增加会带来更多参数和更长梯度传播路径，训练更慢、更不稳定，也更容易过拟合，因此不是越深越好。**

# 5. PyTorch 中的 `num_layers`

在 PyTorch 里：

```
nn.LSTM(input_size, hidden_size, num_layers=2)
```

表示堆叠 2 层 LSTM。

实验八中也给出：

```
lstm_layer = nn.LSTM(num_inputs, num_hiddens, num_layers)
```

并要求分别尝试：

```
num_layers = 1
num_layers = 2
num_layers = 3
```

注意：

`num_layers=2` 不是说时间步变成 2，而是说**每个时间步上有两层循环网络堆叠**。

# 二、双向 RNN BiRNN

# 1. 为什么需要双向 RNN？

普通 RNN 是单向的。

它在时间步 $t$ 的隐藏状态**只依赖过去：**

$H_t = f(X_t, H_{t-1})$

也就是：

过去 $\to$ 当前

但有些任务中，当前词的含义不仅依赖前文，也依赖后文。

例如：

“苹果发布了新手机。”

“我吃了一个苹果。”

同样是“苹果”，需要根据上下文判断是公司还是水果。

如果只看前文，有时信息不够；如果**能同时看后文，判断更准确。**

双向 RNN 的核心思想：

**同时用一个正向 RNN 读取过去信息，用一个反向 RNN 读取未来信息，然后把两者拼接起来。**

实验八也用一句话总结：

普通 RNN：过去 → 当前
双向 RNN：过去 → 当前 **← 未来。**

# 2. 双向 RNN 的结构

双向 RNN 有**两个方向。**

## 正向隐藏状态

**从左到右读序列：**

$\overrightarrow{H}*t=f(X_t,\overrightarrow{H}*{t-1})$

它包含 $t$ 之前的信息。

## 反向隐藏状态

从右到左读序列：

$\overleftarrow{H}*t=f(X_t,\overleftarrow{H}*{t+1})$

它包含 $t$ 之后的信息。

## 拼接

在时间步 $t$，**把两个方向的隐藏状态拼接：**

$H_t=[\overrightarrow{H}_t,\overleftarrow{H}_t]$

然后**用于输出：**

$O_t=H_tW_{hq}+b_q$

所以 BiRNN 的每个位置都同时包含：

- 左侧上下文；
- 右侧上下文。

# 3. 输出维度怎么算？

这是实验和考试常考。

如果：

```
num_hiddens = 256
```

普通单向 LSTM 输出维度是：

$256$

如果：

```
bidirectional=True
```

那么输出维度是：

$256 + 256 = 512$

因为：

正向隐藏状态 $256$ 维，反向隐藏状态 $256$ 维，拼接后 $512$ 维。

实验八明确给出这个问题：`num_hiddens=256`，`bidirectional=True` 时输出维度是 $512$，原因是正向 $256$ 加反向 $256$。

# 4. PyTorch 中的 `bidirectional=True`

普通 LSTM：

```
nn.LSTM(input_size, hidden_size, num_layers=2, bidirectional=False)
```

双向 LSTM：

```
nn.LSTM(input_size, hidden_size, num_layers=2, bidirectional=True)
```

注意：

`hidden_size=256` 时，双向输出的最后一维通常是：

$2 \times hidden_size = 512$

因为方向数是 2。

# 5. 双向 RNN 适合什么任务？

BiRNN 适合 **整个序列已知** 的任务。

例如：

- **文本分类 sentiment classification；**
- **命名实体识别 NER；**
- **语音离线识别；**
- **序列标注；**
- **机器翻译编码器；**
- **阅读理解。**

这些任务通常可以先看到完整输入序列，再输出结果。

例如情感分类：

“这部电影前半段很无聊，但结尾非常震撼。”

判断“这部电影”整体情感时，后文非常重要。

# 6. 双向 RNN 不适合什么任务？

BiRNN 不适合 **实时生成 / 在线预测**。

例如语**言生成：**

给定：

“今天天气很”

模型要马上预测下一个词。

此时**未来词还没生成，不可能使用未来信息。**

所以 BiRNN 不适合实时语言模型生成。

实验八也明确要求回答：“双向 RNN 为什么不适合实时语言生成？”

考试答法：

**双向 RNN 的反向层需要访问未来时间步的信息，因此必须先看到完整序列。实时语言生成只能根据已经生成的历史预测下一个 token，无法使用未来信息，所以不适合使用双向 RNN。**

# 7. 深层 RNN 和双向 RNN 的区别

| 对比             | 深层 RNN Deep RNN      | 双向 RNN BiRNN                |
| ---------------- | ---------------------- | ----------------------------- |
| 核心思想         | 堆叠多层循环网络       | 同时从前向和后向读序列        |
| 关键参数         | `num_layers`           | `bidirectional=True`          |
| 解决重点         | 增强表达能力           | **同时利用过去和未来**        |
| 输出维度         | 通常仍是 `hidden_size` | 通常是 $2 \times hidden_size$ |
| 代价             | 更慢、更深、更难训     | 参数和计算约增加一倍          |
| 是否适合实时生成 | 可以                   | 通常不适合                    |

一句话：

**Deep RNN 是纵向堆叠变深；BiRNN 是时间方向上前后同时看。**

# 8. GRU、LSTM、Deep RNN、BiRNN 总对比

实验八要求填写类似综合表。

| 模型     | 是否有门控 | 是否有记忆单元 | 是否多层 | 是否看未来 | 适合任务                   |
| -------- | ---------- | -------------- | -------- | ---------- | -------------------------- |
| GRU      | 有         | 无独立 $C_t$   | 可多层   | 默认不看   | 语言模型、时间序列         |
| LSTM     | 有         | 有 $C_t$       | 可多层   | 默认不看   | 长序列、复杂依赖           |
| Deep RNN | 看单元类型 | 看单元类型     | 是       | 默认不看   | 复杂序列建模               |
| BiRNN    | 看单元类型 | 看单元类型     | 可多层   | 是         | 文本分类、序列标注、编码器 |

# 9. 常见易错点

## 易错 1：`num_layers=2` 不等于双向

`num_layers=2` 表示**堆叠两层。**

**`bidirectional=True` 表示正向和反向两个方向。**

可以同时使用：

```
num_layers=2, bidirectional=True
```

这表示：

**两层双向 RNN。**

## 易错 2：双向 RNN 不是预测未来

BiRNN 不是神奇地知道未来。

它是在**输入完整序列已经给定时**，从右往左再读一遍。

所以它**适合离线任务**，不适合实时生成。

## 易错 3：双向输出维度会翻倍

隐藏单元数 $256$，双向后每个时间步输出通常是 $512$。

如果后面接全连接层，输入维度要对应改成 $512$。

# 10. 考试高频总结

这节必须会：

1. 深层 RNN 通过堆**叠多层循环层增强表达能力**。
2. `num_layers` 控制 RNN/GRU/LSTM 层数。
3. 层数越多不一定越好，可能训练慢、不稳定、过拟合。
4. 双向 RNN 同时使用正向和反向 RNN。
5. 正向隐藏状态看过去，反向隐藏状态看未来。
6. BiRNN 输出通常是两个方向隐藏状态拼接。
7. `hidden_size=256` 且 `bidirectional=True` 时输出维度通常是 $512$。
8. BiRNN 适合文本分类、序列标注、编码器等离线任务。
9. BiRNN 不适合实时语言生成，因为需要未来信息。
10. Deep RNN 是**纵向加深**，BiRNN 是时间方向**双向读取。**

# 11. 考试风格练习题

## 题 1：概念题

什么是深层 RNN？它和普通单层 RNN 有什么区别？

答案：

深层 RNN 是**将多个循环层堆叠起来**，上一层在每个时间步的隐藏状态作为下一层输入。普通单层 RNN 只有一层循环结构，表达能力较弱；深层 RNN 可以学习更复杂、更抽象的序列特征，但训练更慢、更容易不稳定。

## 题 2：简答题

深层 RNN 的层数增加后，模型一定更好吗？为什么？

答案：

不一定。层数增加会增强表达能力，但也**会增加参数量和计算量，使训练速度变慢，并可能导致过拟合、梯度消失或梯度爆炸**。因此需要根据数据规模、任务复杂度和验证集表现选择合适层数。

## 题 3：概念题

什么是双向 RNN？

答案：

双向 RNN 同时**使用两个 RNN：一个从左到右处理序列，捕获过去信息；另一个从右到左处理序列，捕获未来信息**。最后将两个方向的**隐藏状态拼接**，用于当前时间步的输出或序列表示。

## 题 4：公式题

写出双向 RNN 中正向、反向隐藏状态和最终隐藏状态拼接形式。

答案：

正向隐藏状态：

$\overrightarrow{H}*t=f(X_t,\overrightarrow{H}*{t-1})$

反向隐藏状态：

$\overleftarrow{H}*t=f(X_t,\overleftarrow{H}*{t+1})$

拼接：

$H_t=[\overrightarrow{H}_t,\overleftarrow{H}_t]$

## 题 5：计算题

若 `num_hiddens=256`，`bidirectional=True`，则每个时间步输出维度是多少？为什么？

答案：

输出维度是：

$256+256=512$

因为双向 RNN **有正向和反向两个隐藏状态，每个方向都是 $256$ 维，拼接后得到 $512$ 维。**

## 题 6：判断题

`num_layers=2` 表示模型是双向 RNN。对还是错？

答案：

错。`num_layers=2` 表示堆叠两层循环网络；双向 RNN 需要设置 `bidirectional=True`。两者可以同时使用，但含义不同。

## 题 7：判断题

双向 RNN 非常适合实时语言生成，因为它可以利用未来信息。对还是错？

答案：

错。实时语言生成时未来 token 还没有产生，不能使用未来信息。双向 RNN 需要完整输入序列，适合离线任务，如文本分类、序列标注、编码器表示等。

## 题 8：应用题

如果做文本分类任务，LSTM 和 BiLSTM 你更倾向选哪个？为什么？

答案：

通常更倾向选择 BiLSTM。文本分类时整段文本通常已知，模型可以同时利用前文和后文信息。BiLSTM 能从两个方向捕获上下文，比单向 LSTM 表示更充分，因此常用于文本分类。

## 题 9：比较题

Deep RNN 和 BiRNN 的核心区别是什么？

答案：

Deep RNN 是在网络层数方向上堆叠多个循环层，目的是增强模型表达能力；BiRNN 是在时间方向上同时进行正向和反向建模，目的是同时利用过去和未来上下文。前者强调“更深”，后者强调“双向”。

## 题 10：综合题

一个模型设置为 `nn.LSTM(input_size=100, hidden_size=128, num_layers=2, bidirectional=True)`。请说明它的结构含义和输出维度。

答案：

该模型是一个两层双向 LSTM。`num_layers=2` 表示堆叠两层 LSTM；`bidirectional=True` 表示每层都有正向和反向两个方向。每个方向的隐藏状态维度是 $128$，所以每个时间步最后输出维度通常是：

$2 \times 128 = 256$

# Seq2Seq 

# 1. Seq2Seq 解决什么问题？

前面讲的语言模型一般是：

**输入一个序列前缀，预测下一个 token。**

但很多任务是：

**输入一个序列，输出另一个序列，而且输入输出长度都不固定。**

典型任务：

- 机器翻译：中文句子 → 英文句子
- 文本摘要：长文章 → 短摘要
- 对话系统：问题 → 回答
- 语音识别：语音帧序列 → 文字序列

例如机器翻译：

输入：

```
我 爱 深度 学习
```

输出：

```
I love deep learning
```

输入长度是 4，输出长度是 4；但另一句话可能输入 10 个词，输出 7 个词。

所以需要一个能处理 **可变长度输入 + 可变长度输出** 的模型。

Seq2Seq 的核心就是：

**用 Encoder 把输入序列编码成状态，再用 Decoder 根据这个状态逐步生成输出序列。**

D2L 也说明，**编码器-解码器架构**可以**将长度可变的序列作为输入和输出**，因此适用于机器翻译等序列转换问题。

# 2. Encoder 编码器的作用

Encoder 接收输入序列：

$X=(x_1,x_2,\cdots,x_T)$

然后**用 RNN / GRU / LSTM 逐步处理：**

**$H_t=f(X_t,H_{t-1})$**

**最后得到一个编码状态，比如最后一个隐藏状态：**

**$H_T$**

**这个 $H_T$ 可以看作对整个输入序列的信息压缩。**

考试答法：

**Encoder 的作用是读取输入序列，并把可变长度输入编码成固定形状的上下文状态或隐藏状态。**

D2L 中也说，循环神经网络编码器使用长度可变的序列作为输入，将其转换为固定形状的隐状态，输入序列信息被编码到这个隐状态中。

# 3. Decoder 解码器的作用

Decoder 根据 Encoder 给出的编码状态，逐步生成输出序列。

在第 $t$ 个输出时间步，Decoder 通常**依赖：**

1. **Encoder 的编码状态；**
2. **上一个时间步的输出 token；**
3. **Decoder 自己的上一隐藏状态。**

公式可以**抽象写成：**

$S_t=g(y_{t-1},S_{t-1},c)$

$P(y_t|y_{<t},X)=softmax(W_oS_t+b_o)$

其中：

- $S_t$：Decoder **当前隐藏状态；**
- $y_{t-1}$：**上一个输出 token；**
- $c$：Encoder 的**上下文向量 / 编码状态；**
- $y_t$：当前**要预测的输出 token。**

考试答法：

**Decoder 的作用是根据编码状态和已经生成的输出 token，逐步预测下一个 token，直到生成结束符。**

D2L 中也说，解码器在每个时间步会将输入，例如上一时间步生成的词元，和编码后的状态映射成当前时间步的输出词元。

# 4. `<bos>` 和 `<eos>` 是什么？

Seq2Seq 中常见两个特殊符号。

## `<bos>`：beginning of sequence

表示输出序列开始。

Decoder 第一个输入通常不是普通词，**而是 `<bos>`。**

例如翻译时：

Decoder **输入：**

```
<bos> I love deep learning
```

Decoder 标签：

```
I love deep learning <eos>
```

## `<eos>`：end of sequence

表示输出序列结束。

预测时，**一旦 Decoder 生成 `<eos>`，就停止生成。**

D2L 中也说明，`<bos>` 表示序列开始词元，是**解码器输入序列的第一个词元**；`<eos>` 表示序列结束词元，**一旦输出序列生成它，模型就停止预测。**

# 5. Seq2Seq 的训练流程

以机器翻译为例：

输入句子：

```
我 爱 你
```

目标句子：

```
I love you
```

**训练时，Decoder 输入通常是：**

```
<bos> I love you
```

Decoder **标签是**：

```
I love you <eos>
```

模型**每个时间步预测一个 token：**

第 1 步：输入 `<bos>`，预测 `I`

第 2 步：输入 `I`，预测 `love`

第 3 步：输入 `love`，预测 `you`

第 4 步：输入 `you`，预测 `<eos>`

这种训练方式叫 **teacher forcing**：

**训练时 Decoder 的输入使用真实的上一个 token，而不是模型自己上一步预测的 token。**

**优点：**

- **训练更稳定；**
- **收敛更快；**
- **避免早期预测错误不断传递。**

缺点：

- **训练和预测不完全一致；**
- **预测时模型只能用自己生成的 token，错误可能累积**。

# 6. Seq2Seq 的预测流程

**预测时没有真实答案，所以不能 teacher forcing。**

流程：

1. **Encoder 读完整个输入序列，得到编码状态 $c$。**
2. Decoder **初始输入是 `<bos>`。**
3. Decode**r 预测第一个 token。**
4. 把**预测出的 token 作为下一步输入。**
5. 重复生成，直到预测出 `<eos>` 或达到最大长度。

例如：

输入：`我 爱 你`

Decoder：

```
<bos>` → `I
I` → `love
love` → `you
you` → `<eos>
```

输出：`I love you`

这也是为什么预测阶段可能出现错误累积：

如果**第一步把 `I` 预测错了，后面就会基于错误 token 继续生成。**

# 7. 损失函数怎么计算？

Seq2Seq 每个输出时间步都**预测一个词表分布。**

所以和语言模型一样，**使用 softmax + 交叉熵：**

**$L_t=-\log P(y_t|y_{<t},X)$**

**整句损失：**

**$L=\sum_{t=1}^{T'}L_t$**

**或者取平均。**

但问题是：**小批量训练时，不同句子长度不同。**

**为了组成 batch，短句子会补 `<pad>`。**

例如：

句子 1：`I love you <eos>`

句子 2：`OK <eos> <pad> <pad>`

**损失计算时，不能把 `<pad>` 也算进去。**

所以要用 **mask 掩蔽**。

D2L 中也强调，填充词元被添加到序列末尾以便构造相同形状的小批量，但应该**将填充词元的预测排除在损失函数计算之外**，因此需要 sequence mask。

考试答法：

**Seq2Seq 使用交叉熵损失训练每个输出时间步，但 `<pad>` 位置不代表真实预测目标，需要用 mask 排除。**

# 8. Encoder-Decoder 中状态怎么传？

最经典的 RNN Seq2Seq：

**Encoder 最终隐藏状态用于初始化 Decoder 隐藏状态。**

即：

$S_0=H_T$

其中：

- **$H_T$ 是 Encoder 最后隐藏状态；**
- **$S_0$ 是 Decoder 初始隐藏状态。**

D2L 也说明，在解码器初始化时间步，使用 **RNN 编码器最终隐状态来初始化解码器的隐状态**，从而**把输入序列编码信息送入解码器。**

如果 Encoder 是多层 LSTM，传递的状态可能包括：

- 所有层的隐藏状态 $H$
- 所有层的记忆单元 $C$

如果 Encoder 和 Decoder 维度不同，**可能需要线性层变换。**

# 9. Seq2Seq 的核心问题：信息瓶颈

普通 Seq2Seq 最大的问题：

**Encoder 要把整个输入序列压缩到一个固定长度向量中。**

如果**输入句子很长，最后隐藏状态很难保存所有细节。**

例如输入：

```
今天早上我在学校图书馆见到了一个很久没联系的朋友，他告诉我下周要去北京参加比赛
```

如果**只用最后一个隐藏状态表示整句话，信息很容易丢失。**

这叫 **information bottleneck 信息瓶颈**。

表现：

- **长句翻译效果差；**
- **前面词的信息容易丢失；**
- Decoder **生成时无法灵活查看输入的不同部分。**

这就是下一节 Attention 要解决的问题。

Attention 的核心改进是：

**Decoder 每一步不再只依赖一个固定上下文向量，而是动态关注 Encoder 的所有时间步隐藏状态。**

review.md 里也把 “Seq2Seq + Attention：在解码时动态关注输入序列不同位置” 列为 Attention 模块重点。

# 10. Seq2Seq 和普通语言模型的区别

| 对比           | 普通语言模型            | Seq2Seq              |
| -------------- | ----------------------- | -------------------- |
| 输入           | 前文 token              | 一个完整源序列       |
| 输出           | 下一个 token 或续写序列 | 目标序列             |
| 是否有 Encoder | 没有                    | 有                   |
| 是否条件生成   | 通常只依赖前文          | 依赖源序列           |
| 典型任务       | 文本生成                | **翻译、摘要、对话** |
| **训练标签**   | **输入右移一位**        | **目标序列右移一位** |

一句话：

**语言模型是“根据前文继续写”；Seq2Seq 是“根据输入序列生成另一个序列”。**

# 11. Seq2Seq 和 BiRNN 的关系

**BiRNN 常用于 Encoder。**

因为机器翻译时，**输入源句子是完整已知**的，所以 **Encoder 可以同时看前文和后文。**

例如：

Encoder 使用 BiLSTM：

$[\overrightarrow{H}_t,\overleftarrow{H}_t]$

这样每个输入位置的表示都包含双向上下文。

**但 Decoder 通常不能用双向 RNN。**

**因为 Decoder 是自回归生成：**

生成第 $t$ 个词时，未来输出词还不知道。

所以：

**Encoder 可以双向，Decoder 通常单向。**

# 12. Seq2Seq 的考场答题模板

如果问：

**Seq2Seq 的 Encoder 和 Decoder 分别有什么作用？**

可以答：

Seq2Seq 用于输入和输出都是可变长度序列的任务，如机器翻译。Encoder 读取整个输入序列，并将其编码成上下文状态或隐藏状态，表示源序列信息。Decoder 以 `<bos>` 作为起始输入，并利用 Encoder 的编码状态以及已经生成的目标词，逐步预测下一个 token，直到生成 `<eos>`。训练时通常使用 teacher forcing，即 Decoder 输入真实的前一个目标词；预测时使用模型上一步生成的词作为下一步输入。

# 13. 考试高频总结

Seq2Seq 必须会：

1. Seq2Seq 用于输入输出都是可变长度序列的任务。
2. 典型应用是机器翻译、摘要、对话。
3. Encoder 读取输入序列，编码成固定形状状态。
4. Decoder **根据编码状态和已生成 token 逐步生成输出序列。**
5. `<bos>` 是解码开始符。
6. `<eos>` 是解码结束符，生成后停止。
7. 训练时常用 teacher forcing。
8. 预测时用上一步模型预测作为下一步输入。
9. **损失函数是每个输出时间步的交叉熵。**
10. **`<pad>` 位置要 mask 掉，不参与损失。**
11. 普通 Seq2Seq **有信息瓶颈，长序列效果差。**
12. **Attention 解决 Decoder 不能动态查看输入各位置的问题。**

# 14. 考试风格练习题

## 题 1：概念题

什么是 Seq2Seq？它适合解决什么问题？

答案：

Seq2Seq 是序列到序列学习模型，用于输入和输出都是可变长度序列的任务。它通常采**用编码器-解码器结构**，适合机器翻译、文本摘要、对话系统、语音识别等任务。

## 题 2：简答题

Encoder 和 Decoder 的作用分别是什么？

答案：

Encoder 负责读取输入序列，并把可变长度输入编码成隐藏状态或上下文表示；Decoder 负责**根据 Encoder 提供的编码状态，以及已经生成或已知的目标 token，逐步预测下一个 token，直到生成结束符 `<eos>`。**

## 题 3：判断题

Seq2Seq 中 Encoder 和 Decoder 必须是同一种神经网络，例如都必须是 LSTM。对还是错？

答案：

错。Encoder 和 Decoder **不一定必须是同一种网络。它们可以都是 RNN/LSTM/GRU，也可以使用 CNN 或 Transformer**。**关键是 Encoder 产生编码状态，Decoder 能利用该状态生成目标序列**。

## 题 4：概念题

`<bos>` 和 `<eos>` 分别有什么作用？

答案：

`<bos>` 表示序列开始，通常作为 Decoder 的第一个输入；`<eos>` 表示序列结束，预测时一旦生成 `<eos>`，模型就停止生成输出序列。

## 题 5：训练流程题

给定目标句子 `I love you`，写出训练时 Decoder 输入和标签。

答案：

Decoder 输入：

```
<bos> I love you
```

Decoder 标签：

```
I love you <eos>
```

模型学习在输入 `<bos>` 时预测 `I`，输入 `I` 时预测 `love`，输入 `love` 时预测 `you`，输入 `you` 时预测 `<eos>`。

## 题 6：简答题

什么是 teacher forcing？它有什么优缺点？

答案：

Teacher forcing 是 Seq2Seq 训练时常用方法，即 Decoder 每一步输入真实的上一个目标 token，而不是模型自己上一步预测的 token。优点是训练更稳定、收敛更快；缺点是训练和预测过程不完全一致，预测时模型只能使用自己生成的 token，错误可能逐步累积。

## 题 7：简答题

为什么 Seq2Seq 损失中要 mask 掉 `<pad>`？

答案：

因为不同长度序列组成 batch 时，短序列会用 `<pad>` 补齐，但 `<pad>` 只是占位符，不是真实要预测的内容。如果把 `<pad>` 也计入损失，会干扰模型训练。因此需要用 mask 排除 `<pad>` 位置，只计算有效 token 的损失。

## 题 8：判断题

Seq2Seq 预测时可以一直使用真实目标序列作为 Decoder 输入。对还是错？

答案：

错。预测时真实目标序列未知，因此 Decoder 只能先输入 `<bos>`，然后把模型上一步预测出的 token 作为下一步输入，直到生成 `<eos>` 或达到最大长度。

## 题 9：综合题

普通 RNN Seq2Seq 为什么在长句子上效果可能不好？

答案：

普通 Seq2Seq 通常把整个输入序列压缩到 Encoder 最后隐藏状态这一固定长度向量中。输入序列很长时，这个向量难以保留所有细节，早期信息容易丢失，形成信息瓶颈。因此长句翻译或长序列生成效果可能变差。

## 题 10：过渡题

Attention 如何改进普通 Seq2Seq？

答案：

Attention 让 Decoder **在每个生成时间步动态关注 Encoder 的所有时间步隐藏状态**，而不是只依赖一个固定上下文向量。这样 **Decoder 可以根据当前要生成的词选择性地关注源序列不同位置**，缓解普通 Seq2Seq 的信息瓶颈问题，尤其有利于长序列任务。

下一节讲 **Attention 注意力机制**，重点是 Query、Key、Value、注意力权重、加性注意力和缩放点积注意力。

继续讲 **Attention 注意力机制**。这是 RNN/Seq2Seq 后面的重点，review.md 明确写到：Seq2Seq + Attention 的核心是在解码时动态关注输入序列的不同位置；后续 Transformer 和 BERT 也建立在注意力机制之上。

# 1. Attention 想解决什么问题？

上一节讲普通 Seq2Seq：

**Encoder 把整个输入序列压缩成一个固定长度向量，然后 Decoder 依靠这个向量生成输出。**

问题是：

如果输入序列很长，一个固定向量很难保存所有信息。

例如翻译长句时，Decoder 生成某个目标词时，**可能只需要关注源句中的某几个词，而不是整个句子的压缩表示。**

Attention 的核心思想：

**Decoder 每生成一个词时，都动态地查看 Encoder 的所有隐藏状态，并决定当前最应该关注输入序列的哪些位置。**

一句话：

**Attention 解决普通 Seq2Seq 的信息瓶颈，让模型不再只依赖 Encoder 最后一个隐藏状态。**

老师复习课也提到 Encoder 和 Decoder 后面加了 Attention，并要求理解 Transformer 架构和特征。

# 2. Attention 的直观例子

假设翻译：

```
我 喜欢 深度 学习
```

输出：

```
I like deep learning
```

当 Decoder 生成：

- `I` 时，应该关注 `我`
- `like` 时，应该关注 `喜欢`
- `deep` 时，应该关注 `深度`
- `learning` 时，应该关注 `学习`

也就是说，每个输出词**都有自己关注的输入位置。**

Attention **权重可以看成一个对齐关系 alignment：**

$ \text{输出位置} \leftrightarrow \text{输入位置} $

所以在机器翻译中，Attention 不仅提升效果，**还能一定程度解释模型“看哪里”。**

# 3. Query、Key、Value 是什么？

D2L 的注意力框架中，注意力汇聚是根据 **查询 query** 和 **键 key** 计算权重，然后对 **值 value** 做**加权平均**；注意力权重是在**给定查询和不同键之间计算**出来的。

可以这样理解：

- **Query 查询 $q$**：我现在想找什么信息？
- **Key 键 $k$**：每个**候选信息的索引/特征，用来和 query 匹配。**
- **Value 值 $v$**：真正要取出来的信息内容。

Attention 的基本过程：

1. 用 query 和每个 key **算相似度分数。**
2. 对分数**做 softmax，得到注意力权重**。
3. 用**权重对 value 加权求和，得到上下文向量。**

公式：

$ \alpha_i = softmax(score(q,k_i)) $

$ c = \sum_i \alpha_i v_i $

其中：

- $\alpha_i$ 是**第 $i$ 个位置的注意力权重；**
- $c$ 是**注意力输出，也叫 context vector 上下文向量。**

# 4. 在 Seq2Seq + Attention 中，Q/K/V 分别是什么？

以机器翻译为例：

Encoder 得到**每个输入位置的隐藏状态：**

**$h_1,h_2,\cdots,h_T$**

**Decoder 当前隐藏状态是：**

**$s_t$**

那么通常：

- Query：Decoder **当前状态 $s_t$**
- **Key：Encoder 各时间步隐藏状态 $h_i$**
- **Value：Encoder 各时间步隐藏状态 $h_i$**

也就是：

**Decoder 用当前状态作为 query，去查询 Encoder 所有位置的隐藏状态。**

得到**注意力权重：**

$ \alpha_{t,i} = softmax(score(s_t,h_i)) $

**上下文向量：**

$ c_t = \sum_{i=1}^{T}\alpha_{t,i}h_i $

然后 **Decoder 用 $c_t$ 辅助预测当前输出词**。

注意：这里 **$t$ 表示 Decoder 的输出时间步，$i$ 表示 Encoder 的输入位置。**

# 5. 注意力权重怎么理解？

注意力权重 $\alpha_{t,i}$ 表示：

**Decoder 第 $t$ 步生成输出时，对输入第 $i$ 个位置的关注程度。**

它满足两个性质：

$ \alpha_{t,i} \geq 0 $

$ \sum_i \alpha_{t,i}=1 $

因为它**是 softmax 出来的概率分布。**

如果：

$ \alpha_{t,3}=0.8 $

说明 Decoder 第 $t$ 步**很关注输入第 3 个位置。**

如果权重比较均匀，说明模型没有特别关注某个位置。

# 6. Attention 的一般公式

**给定 query $q$，一组 key-value pairs：**

$(k_1,v_1), (k_2,v_2), \cdots, (k_n,v_n)$

第一步，计算**分数：**

$ a_i = score(q,k_i) $

第二步，softmax 得到**权重：**

$ \alpha_i = \frac{\exp(a_i)}{\sum_j \exp(a_j)} $

第三步，**加权求和：**

$ Attention(q,K,V)=\sum_i \alpha_i v_i $

矩阵形式：

$ Attention(Q,K,V)=softmax(score(Q,K))V $

如果使用**点积评分：**

$ Attention(Q,K,V)=softmax(QK^T)V $

如果使用**缩放点积：**

$ Attention(Q,K,V)=softmax(\frac{QK^T}{\sqrt{d_k}})V $

# 7. 加性注意力 Additive Attention

加性注意力**常用于 query 和 key 维度不同时。**

**评分函数：**

$ score(q,k)=w_v^T \tanh(W_q q + W_k k) $

其中：

- $W_q$ 把 query **投影到某个隐藏空间；**
- $W_k$ 把 key **投影到同一隐藏空间；**
- $\tanh$ **引入非线性；**
- $w_v$ 把**结果变成一个标量分数。**

特点：

- 表达能力强；
- **适合 query 和 key 维度不同；**
- 计算比点积注意力稍慢。

考试中不一定要求完整推导，但最好能写出：

**加性注意力先把 query 和 key 映射到同一空间，再用一个小网络计算匹配分数。**

D2L 第 10.3 节专门讲注意力评分函数，包括加性注意力和缩放点积注意力。

# 8. 点积注意力 Dot-Product Attention

点积注意力**要求 query 和 key 维度相同。**

评分函数：

$ score(q,k)=q^Tk $

如果 $q$ 和 $k$ **越相似，点积越大，注意力权重越高。**

矩阵形式：

$ Attention(Q,K,V)=softmax(QK^T)V $

优点：

- 计算简单；
- 可以用矩阵乘法高效并行；
- Transformer 中常用它的缩放版本。

# 9. 缩放点积注意力 Scaled Dot-Product Attention

Transformer 中常用：

$ Attention(Q,K,V)=softmax(\frac{QK^T}{\sqrt{d_k}})V $

其中 $d_k$ 是 key/query 的维度。

为什么要除以 $\sqrt{d_k}$？

当 $d_k$ 很大时，**点积 $q^Tk$ 的数值可能很大。**

softmax 输入太大时，会变得**非常尖锐：**

- **最大项接近 1；**
- **其他项接近 0；**
- **梯度变小；**
- **训练不稳定。**

除以 $\sqrt{d_k}$ 可以控制分数尺度，让 softmax 更稳定。

考试答法：

**缩放点积注意力用 $\sqrt{d_k}$ 缩放点积分数，避免维度较大时点积过大导致 softmax 饱和，从而提高训练稳定性。**

# 10. Masked Softmax 掩蔽 softmax

注意力里经常需要 mask。

常见两种场景：

## 场景 1：padding mask

不同序列长度不同，需要用 `<pad>` 补齐。

但 `<pad>` 没有真实语义，不能让模型关注它。

所以对 padding 位置加 mask，使它们的 **attention weight 变成 0。**

## 场景 2：causal mask / look-ahead mask

Decoder 自回归生成时，第 $t$ 个位置**不能看到未来位置 $t+1,t+2,\cdots$。**

所以要 **mask 掉未来 token。**

这在 Transformer **Decoder 里非常重要。**

D2L 里也说明，Transformer **解码器为了保留自回归属性，掩蔽自注意力保证每个位置只能考虑它之前已经生成的词元。**

# 11. Attention 为什么比普通 Seq2Seq 更好？

普通 Seq2Seq：

- Encoder **最后状态保存全部输入信息；**
- Decoder 每一步**都依赖同一个固定上下文；**
- 长序列容易信息丢失。

**Attention** Seq2Seq：

- Encoder **保留所有时间步隐藏状态；**
- Decoder **每一步动态计算注意力权重；**
- 每一步**得到不同上下文向量 $c_t$；**
- 长序列中也能选择性关注相关位置。

考试答法：

**Attention 让 Decoder 在生成每个输出 token 时动态访问 Encoder 的所有隐藏状态，并根据当前解码状态分配不同注意力权重，从而缓解固定上下文向量的信息瓶颈，尤其改善长序列任务。**

# 12. Attention 和 RNN 的关系

Attention 一开始常用于改进 RNN Seq2Seq。

结构是：

$Encoder\ RNN \to Attention \to Decoder\ RNN$

但是后来发现：

**如果把每个 token 都和其他 token 做 attention**，就可以直接**建模序列内部依赖**。

这就是 **Self-Attention 自注意力**。

Transformer **更进一步：**

**完全基于注意力机制，不使用 RNN 或 CNN。**

D2L 也明确说 Transformer **完全基于注意力机制，没有卷积层或循环神经网络层。**

# 13. Attention 的考场记忆版

最建议背这套：

**Attention = 根据 query 和 key 算权重，再对 value 加权求和。**

公式：

$ \alpha_i = softmax(score(q,k_i)) $

$ c=\sum_i \alpha_i v_i $

Seq2Seq 中：

- **Query：Decoder 当前状态；**
- **Key/Value：Encoder 各时间步隐藏状态；**
- **输出：当前时间步上下文向量。**

缩放点积**注意力：**

$Attention(Q,K,V)=softmax(\frac{QK^T}{\sqrt{d_k}})V$

# 14. 考试高频总结

Attention 必须会：

1. Attention 解决普通 Seq2Seq 的信息瓶颈。
2. Decoder 每一步动态关注 Encoder 不同位置。
3. Query 表示当前查询，Key 用于匹配，Value 是被加权的信息。
4. 注意力权重由 query-key 相似度经过 softmax 得到。
5. **注意力输出是 value 的加权和。**
6. 注意力权重非负且和为 1。
7. Seq2Seq Attention 中，**query 通常来自 Decoder 状态，key/value 来自 Encoder 隐藏状态。**
8. 加性注意力适合 query/key 维度不同。
9. 缩放点积注意力公式：$softmax(\frac{QK^T}{\sqrt{d_k}})V$。
10. 除以 $\sqrt{d_k}$ 是**为了避免点积过大导致 softmax 饱和。**
11. Mask 用于**屏蔽 padding 或未来位置。**
12. Transformer 是**完全基于注意力机制的模型。**

# 15. 考试风格练习题

## 题 1：概念题

Attention 机制主要解决普通 Seq2Seq 的什么问题？

答案：

普通 Seq2Seq 通常**把整个输入序列压缩成一个固定长度上下文向量，长序列中容易丢失信**息。Attention 让 Decoder 在每个输出时间步**动态关注 Encoder 的所有隐藏状态**，根据当前**解码状态选择相关输入位置**，从而**缓解信息瓶颈问题，尤其改善长序列任务效果。**

## 题 2：简答题

Query、Key、Value 分别表示什么？

答案：

Query 表示当前**要查询的信息需求**；Key 表示**每个候选信息的索引或特征**，用来和 Query 计算匹配程度；**Value 表示真正要被取出的内容**。Attention 先用 Query 和 Key 计算权重，再用权重对 Value 加权求和。

## 题 3：公式题

写出 Attention 的一般计算公式。

答案：

先计算注意力权重：

$ \alpha_i = \frac{\exp(score(q,k_i))}{\sum_j \exp(score(q,k_j))} $

再计算输出：

$ c=\sum_i \alpha_i v_i $

其中 $q$ 是 query，$k_i$ 是 key，$v_i$ 是 value，$\alpha_i$ 是注意力权重。

## 题 4：判断题

Attention 权重可以是负数，只要所有权重相加为 1 即可。对还是错？

答案：

错。Attention 权重通常由 softmax 得到，因此每个权重都非负，并且所有权重之和为 1。

## 题 5：Seq2Seq 应用题

在 Seq2Seq + Attention 中，Query、Key、Value 通常分别来自哪里？

答案：

Query 通常来自 **Decoder 当前时间步的隐藏状态**；**Key 和 Value 通常来自 Encoder 所有时间步的隐藏状态**。Decoder **用当前状态去查询 Encoder 的各个输入位置**，从而得到当前时间步的上下文向量。

## 题 6：公式题

写出缩放点积注意力公式，并说明 $d_k$ 的含义。

答案：

$Attention(Q,K,V)=softmax(\frac{QK^T}{\sqrt{d_k}})V$

其中 **$d_k$ 是 key/query 向量的维度**。$QK^T$ 计算 query 和 key 的点积相似度，softmax 得到注意力权重，再**乘以 $V$ 得到加权输出**。

## 题 7：简答题

为什么缩放点积注意力要除以 $\sqrt{d_k}$？

答案：

当 $d_k$ 较大时，query 和 key 的点积可能数值很大，使 softmax 输出过于尖锐，导致梯度变小、训练不稳定。**除以 $\sqrt{d_k}$ 可以控制分数尺度**，避免 softmax 饱和，使训练更稳定。

## 题 8：比较题

加性注意力和点积注意力有什么区别？

答案：

加性注意力通过一个小型神经网络计算 query 和 key 的匹配分数，适合 query 和 key 维度不同的情况，但计算较复杂。点积注意力直接计算 $q^Tk$，要求 query 和 key 维度相同，计算简单且容易并行。Transformer 常用缩放点积注意力。

## 题 9：简答题

Attention 中 mask 的作用是什么？

答案：

Mask 用**于屏蔽不应该被关注的位置**。例如 padding mask 用于屏蔽 `<pad>` 位置，避免模型关注无意义填充；causal mask 用于解码器自注意力，屏蔽未来位置，保证生成第 $t$ 个 token 时只能看到当前位置及之前的信息。

## 题 10：综合题

为什么 Attention 可以提高机器翻译中长句子的效果？

答案：

长句子中，普通 Seq2Seq 把所有输入信息压缩到一个固定长度向量，容易丢失细节。Attention **保留 Encoder 所有时间步隐藏状态**，Decoder 每生成一个目标词时都**根据当前状态计算对源序列各位置的注意力权重**，从而**动态选择相关输入信息**。因此长句翻译时不必完全依赖最后隐藏状态，可以更好对齐和利用源句信息。

# Self-Attention 自注意力和 Multi-Head Attention 多头注意力

# 一、Self-Attention 自注意力

# 1. Self-Attention 解决什么问题？

前面讲的 **Seq2Seq + Attention 是：**

**Decoder 用自己的状态作为 Query，去关注 Encoder 的各个隐藏状态。**

而 **Self-Attention 是**：

**序列内部的每个 token，都去关注同一个序列中的其他 token。**

也就是说，Query、Key、Value **都来自同一个序列。**

例如句子：

```
The animal didn't cross the street because it was tired.
```

这里 `it` 指的是 `animal`，不是 `street`。

Self-Attention **可以让 `it` 直接关注前面的 `animal`，从而建立长距离依赖关系。**

一句话：

**Self-Attention 让序列中每个位置都能直接和其他位置交互，从而建模全局依赖。**

D2L 也强调 Transformer 是完全基于注意力机制的架构，其中使用了 self-attention 和 multi-head attention。

# 2. Self-Attention 中 Q、K、V 从哪里来？

假设输入序列表示为：

$X \in R^{n \times d}$

其中：

- $n$：序列长度；
- **$d$：每个 token 的 embedding 维度。**

Self-Attention 会通过**三个可学习矩阵把 $X$ 投影成：**

$Q=XW_Q$

$K=XW_K$

$V=XW_V$

其中：

- $Q$：Query，表示每个 token 想查询什么；
- $K$：Key，表示每个 token 可以被怎样匹配；
- $V$：Value，表示每个 token 真正提供的信息。

注意：**Q、K、V 都来自同一个输入 $X$，这就是 self 的含义。**

# 3. Self-Attention 如何计算？

核心公式：

$Attention(Q,K,V)=softmax(\frac{QK^T}{\sqrt{d_k}})V$

分三步理解。

## 第一步：算相关性分数

$QK^T$

如果序列长度是 $n$，那么：

$QK^T \in R^{n \times n}$

其中第 $i$ 行第 $j$ 列表示：

**第 $i$ 个 token 对第 $j$ 个 token 的关注分数。**

## 第二步：缩放 + softmax

$\frac{QK^T}{\sqrt{d_k}}$

除以 $\sqrt{d_k}$ 是为了避免维度较大时点积过大，导致 softmax 饱和。

然后对每一行做 softmax：

$A=softmax(\frac{QK^T}{\sqrt{d_k}})$

其中 $A$ 是注意力权重矩阵。

每一行满足：

$A_{ij} \geq 0$

$\sum_j A_{ij}=1$

## 第三步：对 Value 加权求和

$AV$

第 $i$ 个 token 的输出是：

$z_i=\sum_j A_{ij}v_j$

意思是：

**第 $i$ 个 token 的新表示，是它关注到的所有 token 的 value 加权和。**

# 4. Self-Attention 的直观例子

输入：

```
I love deep learning
```

当计算 `learning` 的新表示时，它可以关注：

- `deep`：因为 `deep learning` 是强相关短语；
- `I`：因为主语信息可能有用；
- **`love`：表示情感或动作；**
- `learning` 自己：保留自身信息。

Self-Attention 的**输出不是简单保留原词，而是：**

**融合了上下文信息的新表示。**

# 5. Self-Attention 和普通 Attention 的区别

| 对比       | 普通 Seq2Seq Attention       | Self-Attention                  |
| ---------- | ---------------------------- | ------------------------------- |
| Query 来源 | Decoder 当前状态             | 输入序列自身                    |
| Key 来源   | Encoder 隐藏状态             | 输入序列自身                    |
| Value 来源 | Encoder 隐藏状态             | 输入序列自身                    |
| 作用       | **Decoder 动态关注输入序列** | **序列内部 token 互相关注**     |
| 常见位置   | RNN Seq2Seq                  | **Transformer Encoder/Decoder** |

一句话：

**普通 Attention 是两个序列之间的注意力；Self-Attention 是一个序列内部的注意力。**

# 6. Self-Attention 为什么能并行？

RNN 处理序列必须按时间顺序：

$H_1 \to H_2 \to H_3 \to \cdots$

也就是说，算 $H_t$ 必须先算 $H_{t-1}$，**难以完全并行。**

Self-Attention **不需要递归。**

**它直接用矩阵乘法：**

$QK^T$

一次性计算**所有 token 两两之间**的关系。

所以所有位置的输出可以同时算。

D2L 中也总结：自注意力中每个词元都可以直接连接到其他词元，因此顺序操作数是 $O(1)$，最大路径长度也是 $O(1)$，适合并行计算；但复杂度关于序列长度是二次方，长序列会慢。

考试答法：

**Self-Attention 不像 RNN 那样依赖前一时间步隐藏状态，而是通过矩阵乘法一次性计算所有位置之间的注意力关系，因此可以并行训练。**

# 7. Self-Attention 的优点和缺点

## 优点

1. 能直接建模长距离依赖。
2. **所有 token 两两交互，信息路径短。**
3. 可以并行计算，训练效率高。
4. 不依赖 RNN 的时间递归。

## 缺点

1. 计算复杂度是 $O(n^2)$。
2. 序列很长时，注意力矩阵 $n \times n$ 很大。
3. **本身不包含顺序信息，需要位置编码。**

# 二、位置编码 Positional Encoding

# 1. 为什么需要位置编码？

Self-Attention 本身不关心顺序。

例如：

```
我 爱 你
```

和：

```
你 爱 我
```

如果**只看 token 集合，不加位置信息，Self-Attention 难以知道谁在前、谁在后。**

**RNN 天然有顺序，因为它逐个读 token。**

但 **Transformer 没有递归**，所以必须额外加入位置编码。

D2L 也说明，自注意力为了并行计算放弃了顺序操作，因此需要在输入表示中添加位置编码来注入位置信息。

# 2. 位置编码怎么加？

输入 embedding：

$X$

位置编码：

$P$

最终输入：

$X+P$

其中 **$P$ 和 $X$ 形状相同。**

经典 Transformer 使用**正弦余弦位置编码：**

$P_{i,2j}=\sin(\frac{i}{10000^{2j/d}})$

$P_{i,2j+1}=\cos(\frac{i}{10000^{2j/d}})$

其中：

- $i$：位置；
- $j$：维度索引；
- $d$：embedding 维度。

考试不一定要求完整背公式，但要会说：

**位置编码用于向模型提供 token 的顺序信息，可以是固定的正弦余弦编码，也可以是可学习的位置向量。**

# 三、Multi-Head Attention 多头注意力

# 1. 为什么需要多头？

单头注意力**只有一套 $Q,K,V$ 投影，只能从一个表示子空间里计算注意力**。

但语言关系很复杂。

**同一个词可能需要同时关注不同类型的信息：**

- 语法关系；
- 指代关系；
- 位置邻近关系；
- 语义相关关系；
- 长距离依赖。

Multi-Head Attention 的核心思想：

**把注意力分成多个头，每个头在不同子空间中学习不同类型的关系。**

一句话：

**多头注意力让模型可以从多个角度同时关注序列信息。**

# 2. 多头注意力怎么算？

假设有 $h$ 个头。

**第 $i$ 个头有自己的投影矩阵：**

$Q_i=QW_i^Q$

$K_i=KW_i^K$

$V_i=VW_i^V$

然后**每个头独立计算注意力：**

$head_i=Attention(Q_i,K_i,V_i)$

最后把**所有头拼接：**

$Concat(head_1,\cdots,head_h)$

再经过**一个输出线性变换：**

$MultiHead(Q,K,V)=Concat(head_1,\cdots,head_h)W_O$

# 3. 多头注意力的维度理解

假设模型维度：

$d_{model}=512$

头数：

$h=8$

通常**每个头的维度是：**

$d_k=d_v=\frac{512}{8}=64$

每个**头在 $64$ 维子空间里做注意力。**

**最后 8 个头拼接回来：**

**$8 \times 64 = 512$**

输出仍然是 $d_{model}=512$。

所以多头不是简单把维度扩大 8 倍，而是把**总维度拆成多个子空间计算，再拼回去。**

# 4. 多头注意力为什么有效？

可以从 3 点答。

## 1. 学习不同关系

不同头可以**关注不同模式**。

例如：

- 一个头关注相邻词；
- 一个头关注主谓关系；
- 一个头关注代词指代；
- 一个头关注长距离依赖。

## 2. 增强表达能力

单头注意力只有一种注意力分布。

多头注意力有多个注意力分布，可以**同时捕获多种依赖。**

## 3. 计算仍然高效

多个头**可以并行计算。**

虽然头数增加，但每个头维度较小，总计算量可控。

D2L 第 10.5 节专门讲多头注意力，随后第 10.6 节讲自注意力和位置编码，说明这两者共同构成 Transformer 的关键基础。

# 四、Self-Attention、CNN、RNN 对比

这是非常容易出简答题的地方。

| 对比           | CNN              | RNN                  | Self-Attention         |
| -------------- | ---------------- | -------------------- | ---------------------- |
| 处理方式       | 局部窗口卷积     | 按时间递归           | 所有 token 两两注意    |
| 长距离依赖     | 需要堆很多层     | 路径长，易梯度问题   | **路径短，直接连接**   |
| 并行能力       | 强               | 弱                   | 强                     |
| 是否天然有顺序 | 有局部位置结构   | 有时间顺序           | 没有，**需要位置编码** |
| 复杂度特点     | 与卷积核大小有关 | 与序列长度线性但串行 | $O(n^2)$               |

考试答法：

**RNN 有顺序建模能力，但串行计算慢，长距离依赖路径长；Self-Attention 可以让任意两个位置直接交互，路径短且可并行，但计算复杂度随序列长度平方增长，并且需要位置编码补充顺序信息。**

# 五、Masked Self-Attention

Decoder 里必须用 **masked self-attention**。

因为生成第 $t$ 个 token 时，不能看到第 $t+1$ 个及之后的 token。

否则训练时就“偷看答案”了。

例如目标句子：

```
I love deep learning
```

训练时所有 token 都已知，但模型预测 `love` 时不能看到后面的 `deep learning`。

所以要用 causal mask，把未来位置遮住。

D2L 在 Transformer 解码器部分也说明，为保留自回归属性，掩蔽自注意力使每个位置只能和已经生成的词元位置进行注意力计算。

# 六、考场答题模板

如果问：

**Self-Attention 如何计算？**

可以答：

Self-Attention 首先将输入序列 $X$ 通过三个线性变换得到 $Q=XW_Q$、$K=XW_K$、$V=XW_V$。然后计算 query 和 key 的缩放点积相似度 $\frac{QK^T}{\sqrt{d_k}}$，经过 softmax 得到注意力权重，再用权重对 $V$ 加权求和，得到每个 token 融合上下文后的表示：

$Attention(Q,K,V)=softmax(\frac{QK^T}{\sqrt{d_k}})V$

如果问：

**Multi-Head Attention 为什么有用？**

可以答：

多头注意力把 $Q,K,V$ 投影到多个不同子空间，每个头独立计算注意力，再把多个头的结果拼接并线性变换。这样模型可以同时从不同角度关注不同位置和不同类型的关系，比如局部关系、长距离依赖和指代关系，从而增强表达能力。

# 七、考试高频总结

这节必须会：

1. Self-Attention 中 $Q,K,V$ 都来自同一个序列。
2. 公式：$Attention(Q,K,V)=softmax(\frac{QK^T}{\sqrt{d_k}})V$。
3. $QK^T$ 得到 token 两两之间的相关性。
4. softmax 后得到注意力权重。
5. 输出是对 $V$ 的加权和。
6. Self-Attention 能**直接建模长距离依赖。**
7. Self-Attention **可以并行计算。**
8. Self-Attention 复杂度是 $O(n^2)$。
9. Self-Attention 本身没有顺序信息，需要位置编码。
10. Multi-Head Attention 用**多个头在不同子空间学习不同关系。**
11. 多头结果**先 concat，再线性变换。**
12. Decoder 中要用 masked self-attention 防止看到未来 token。

# 八、考试风格练习题

## 题 1：概念题

什么是 Self-Attention？

答案：

Self-Attention 是一种序列内部的注意力机制。它让序列中每个 token 都可以和同一序列中的其他 token 计算注意力关系，并根据注意力权重融合其他 token 的信息，从而得到包含上下文的新表示。

## 题 2：公式题

写出缩放点积 Self-Attention 的公式。

答案：

$Attention(Q,K,V)=softmax(\frac{QK^T}{\sqrt{d_k}})V$

其中 $Q,K,V$ 分别由输入序列线性变换得到，$d_k$ 是 key/query 的维度。

## 题 3：简答题

Self-Attention 中的 $Q,K,V$ 分别从哪里来？

答案：

在 Self-Attention 中，$Q,K,V$ 都来自同一个输入序列 $X$，通过不同的可学习线性变换得到：

$Q=XW_Q$

$K=XW_K$

$V=XW_V$

## 题 4：判断题

Self-Attention 和 RNN 一样，必须按照时间步从左到右依次计算。对还是错？

答案：

错。Self-Attention 通过矩阵乘法一次性计算所有 token 两两之间的注意力关系，不依赖前一时间步隐藏状态，因此可以并行计算。

## 题 5：简答题

为什么 Self-Attention 需要位置编码？

答案：

Self-Attention 本身**只计算 token 之间的相似度，不包含序列顺序信息**。如果不加入位置编码，模型难以区分相同 token 在不同位置的含义，也难以知道词序。因此需要将位置编码加到输入表示中，为模型提供顺序信息。

## 题 6：计算题

设 $d_{model}=512$，多头注意力头数 $h=8$，若均匀分配维度，每个头的维度是多少？

答案：

每个头的维度为：

$d_k=\frac{d_{model}}{h}=\frac{512}{8}=64$

## 题 7：简答题

Multi-Head Attention 的核心思想是什么？

答案：

Multi-Head Attention 将 $Q,K,V$ 投影到多个不同子空间，每个头独立计算注意力，然后将各个头的结果拼接并线性变换。这样模型可以**同时关注不同位置和不同类型的依赖关系，增强表示能力。**

## 题 8：判断题

多头注意力只是把同一个注意力结果复制多份，因此不会增强模型能力。对还是错？

答案：

错。多头注意力中的**每个头都有不同的投影矩阵，会在不同子空间中学习不同的注意力模式**，因此**可以捕获多种关系，不是简单复制同一个结果**。

## 题 9：简答题

为什么 Transformer **Decoder** 中需要 masked self-attention？

答案：

Decoder 是**自回归生成模型**，生成第 $t$ 个 token 时只能依赖第 $t$ 个位置之前已经生成的 token，**不能看到未来 token。Masked self-attention 通过遮蔽未来位置，防止模型在训练时偷看答案**，保证训练和预测一致。

## 题 10：比较题

Self-Attention 相比 RNN 有什么优点和缺点？

答案：

优点是 Self-Attention 可以**让任意两个位置直接交互**，长距离依赖路径短，并且可以通过矩阵乘法并行计算，训练效率高。缺点是注意力矩阵大小为 $n \times n$，**计算和存储复杂度随序列长度平方增长**；此外 Self-Attention 本身不包含顺序信息，需要位置编码。

下一节讲 **Transformer 架构**：重点是 Encoder、Decoder、多头自注意力、残差连接、LayerNorm、前馈网络，以及为什么 Transformer 可以替代 RNN。

# Transformer 

继续讲 **Transformer 架构**。这是 Attention 部分的核心，review.md 明确把 Transformer 列为重点：核心是 **Self-Attention，自注意力机制，不依赖 RNN**，并且可能考“Transformer 为什么可以并行训练”。 老师复习课也提到要理解 Transformer 的架构、主要部分、特征和性能。

# 1. Transformer 是什么？

Transformer 是一种 **Encoder-Decoder 编码器-解码器架构**，**最初主要用于机器翻译。**

它和之前的 Seq2Seq 最大区别是：

**Transformer 不使用 RNN，也不使用 CNN，而是主要依赖 Self-Attention 和 Multi-Head Attention 建模序列关系。**

普通 RNN Seq2Seq：

$Encoder\ RNN \to Decoder\ RNN$

Transformer：

$Transformer\ Encoder \to Transformer\ Decoder$

核心优势：

- 能直接建模长距离依赖；
- 可以并行计算；
- 训练效率比 RNN 更高；
- 后续 BERT、GPT 等模型都基于 Transformer。

D2L 中的 Transformer 也是按 Encoder-Decoder 结构实现，并用它训练英语到法语的机器翻译任务。

# 2. Transformer 总体结构

Transformer 由两大部分组成：

1. **Encoder 编码器**
	读取源序列，**输出每个位置的上下文表示。**
2. **Decoder 解码器**
	**根据已经生成的目标 token 和 Encoder 输出，逐步生成目标序列。**

整体流程：

$Input\ Tokens \to Embedding \to Positional\ Encoding \to Encoder$

$Target\ Tokens \to Embedding \to Positional\ Encoding \to Decoder$

$Decoder\ Output \to Linear \to Softmax \to Next\ Token$

# 3. Transformer Encoder 结构

一个 Transformer Encoder block 包含**两个子层**：

1. **Multi-Head Self-Attention 多头自注意力**
2. **Position-wise Feed-Forward Network 基于位置的前馈网络**

**每个子层外面都有：**

- **残差连接 residual connection**
- **层归一化 LayerNorm**

所以一个 **Encoder block 可以写成：**

$X_1 = LayerNorm(X + MultiHeadSelfAttention(X))$

$Y = LayerNorm(X_1 + FFN(X_1))$

D2L 中也明确说，Transformer 编码器中的一个层包含两个子层：多头自注意力和基于位置的前馈网络，这两个子层都使用残差连接和紧随的层规范化。

# 4. Encoder 中每个部分的作用

## 1. Multi-Head Self-Attention

作用：

**让输入序列中每个 token 都能关注其他 token。**

例如句子中某个代词可以直接关注它指代的名词。

公式：

$Attention(Q,K,V)=softmax(\frac{QK^T}{\sqrt{d_k}})V$

Encoder 里是 self-attention，所以：

$Q,K,V$ 都来自同一个输入序列。

## 2. Add & Norm

**“Add” 是残差连接：**

$X + Sublayer(X)$

作用：

- 保留原始输入信息；
- 让梯度更容易传播；
- 缓解深层网络训练困难。

**“Norm” 是 LayerNorm：**

作用：

- 稳定每层输入分布；
- 加速训练；
- 和 BatchNorm 不同，LayerNorm 通常**对单个样本的特征维度归一化，更适合 NLP 序列任务。**

## 3. Position-wise FFN

**FFN 是对每个位置单独应用的前馈网络。**

通常形式：

$FFN(x)=W_2 ReLU(W_1x+b_1)+b_2$

它对**每个 token 位置使用同一个 MLP。**

注意：

Self-Attention 负责 **token 之间的信息交互**；

FFN 负责 **对每个 token 的表示做非线性变换**。

# 5. Transformer Decoder 结构

一个 Transformer Decoder block 有**三个子层：**

1. **Masked Multi-Head Self-Attention**
2. **Encoder-Decoder Attention**
3. **Position-wise Feed-Forward Network**

同样**每个子层外面都有残差连接和 LayerNorm。**

D2L 中也写到，Transformer 解码器的每个层包含**三个子层：解码器自注意力、“编码器-解码器”注意力和基于位置的前馈网络**，并且这些子层都被残差连接和层规范化围绕。

# 6. Decoder 三个子层分别干什么？

## 1. Masked Self-Attention

Decoder 生成目标序列时，不能看到未来 token。

例如训练时目标句子是：

```
I love deep learning
```

当模型预测 `love` 时，不能提前看到 `deep learning`。

所以 Decoder 的 self-attention 要加 mask：

**第 $t$ 个位置只能关注 $1 \sim t$ 的位置，不能关注 $t+1$ 之后的位置。**

作用：

- 防止训练时偷看答案；
- **保持自回归 autoregressive 生成性质。**

## 2. Encoder-Decoder Attention

这一层**让 Decoder 关注 Encoder 输出。**

这里：

- Query 来自 Decoder 当前表示；
- **Key 和 Value 来自 Encoder 输出。**

也就是：

**Decoder 每个位置根据当前生成状态，去源序列中找相关信息。**

这对应前面讲的 Seq2Seq + Attention。

## 3. FFN

和 Encoder 一样，**对每个位置单独做非线性变换，增强表达能力。**

# 7. Encoder Attention 和 Decoder Attention 的区别

| 位置            | Attention 类型            | Q 来源   | K/V 来源     | 是否 Mask                |
| --------------- | ------------------------- | -------- | ------------ | ------------------------ |
| Encoder         | Self-Attention            | 源序列   | 源序列       | 通常只 mask padding      |
| Decoder 第 1 层 | Masked Self-Attention     | 目标序列 | 目标序列     | mask 未来位置            |
| Decoder 第 2 层 | Encoder-Decoder Attention | Decoder  | Encoder 输出 | 通常 mask 源序列 padding |

考试记忆：

**Encoder 看完整输入；Decoder 先看已生成目标词，再去看 Encoder 输出。**

# 8. 为什么 Transformer 需要位置编码？

Self-Attention 本身不按顺序读序列。

如果不加位置编码，模型很难区分：

```
我 爱 你
```

和：

```
你 爱 我
```

所以 Transformer 在词嵌入中加入位置编码：

$X = Embedding + PositionalEncoding$

D2L 中的 Transformer 编码器实现也是先做 embedding，再乘以 $\sqrt{num_hiddens}$ 缩放，然后加位置编码。

考试答法：

**因为 Transformer 没有 RNN 的递归结构，Self-Attention 本身不包含词序信息，所以必须加入位置编码来告诉模型 token 的位置。**

# 9. 为什么 Transformer 可以并行训练？

RNN **必须按时间步递推**：

$H_t=f(X_t,H_{t-1})$

计算 $H_t$ 前必须先有 $H_{t-1}$。

所以 RNN 难以完全并行。

Transformer 的 **Self-Attention 是矩阵运算：**

$QK^T$

可以**一次性计算所有 token 两两之间的关系。**

所以训练时：

**整个序列所有位置可以同时计算注意力，不需要从左到右逐步递推。**

考试答法：

**Transformer 不依赖循环结构，而是通过 Self-Attention 直接计算序列中任意两个位置的关系，因此所有位置的表示可以用矩阵乘法并行计算。**

注意：Decoder 训练时虽然用了 mask，但**训练阶段仍可以并行计算所有目标位置**；**预测生成时仍然要一个 token 一个 token 生成，因为下一个输入依赖上一步输出。**

# 10. Transformer 为什么适合长距离依赖？

RNN 中，如果第 1 个词影响第 100 个词，信息要经过 99 次递推。

路径很长，容易梯度消失。

Self-Attention 中，第 1 个词和第 100 个词可以直接计算注意力。

**路径长度近似为 1。**

所以 Transformer 更容易捕获长距离依赖。

但代价是：

注意力矩阵大小是 $n \times n$，所以序列长度为 $n$ 时，Self-Attention 计算复杂度约为：

$O(n^2)$

长序列时计算和显存开销大。

# 11. Transformer 和 RNN Seq2Seq 对比

| 对比       | RNN Seq2Seq      | Transformer                             |
| ---------- | ---------------- | --------------------------------------- |
| 核心结构   | RNN/GRU/LSTM     | Self-Attention                          |
| 是否串行   | 是               | 训练时可并行                            |
| 长距离依赖 | 路径长，较难     | 任意位置直接交互                        |
| 顺序信息   | 天然有时间顺序   | 需要位置编码                            |
| Encoder    | RNN 编码         | 多层 self-attention                     |
| Decoder    | RNN 解码         | masked self-attention + cross-attention |
| 缺点       | 训练慢，长依赖难 | $O(n^2)$，长序列成本高                  |

一句话：

**Transformer 用注意力替代循环，让序列中任意位置直接交互，因此更并行、更擅长长距离依赖，但需要位置编码，且长序列开销较大。**

# 12. Transformer 中的残差连接和 LayerNorm 为什么重要？

Transformer **很深，如果没有残差连接，梯度传播会困难。**

残差连接：

$Y=X+Sublayer(X)$

作用：

- 保留原输入；
- 提供**梯度捷径；**
- 类似 ResNet，帮助深层网络训练。

LayerNorm：

$LayerNorm(x)=\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}\gamma+\beta$

作用：

- **稳定**每层表示尺度；
- **减少训练震荡；**
- 比 BatchNorm 更适合变长序列和小 batch NLP 任务。

考试答法：

**残差连接帮助信息和梯度跨层传播，LayerNorm 稳定每层输出分布，二者共同提高 Transformer 深层训练稳定性。**

# 13. Transformer 的输出怎么生成？

以机器翻译为例：

Encoder 输入源句：

```
I am home
```

**Decoder 输入目标前缀：**

```
<bos> je suis
```

Decoder **输出每个位置的隐藏表示。**

最后通过：

$Linear \to Softmax$

**得到词表上每个词的概率。**

预测时：

1. 输入 `<bos>`；
2. 预测第一个词；
3. 把预测词接到 Decoder 输入后面；
4. 继续预测；
5. 直到生成 `<eos>`。

所以 Transformer Decoder 仍是 **自回归生成**。

# 14. Transformer 的考场记忆模板

如果问：

**Transformer 主要由哪些部分组成？**

可以答：

Transformer 是 Encoder-Decoder 架构。Encoder **由多个相同 Encoder block 堆叠组成**，每个 block **包含多头自注意力和基于位置的前馈网络**，并**配有残差连接和 LayerNorm**。Decoder 由多个 Decoder block 堆叠组成，每个 **block 包含 masked self-attention、encoder-decoder attention 和前馈网络**，也配有残差连接和 LayerNorm。由于 Transformer 没有循环结构，所以需要位置编码提供序列顺序信息。

如果问：

**Transformer 为什么能替代 RNN？**

可以答：

RNN 通过隐藏状态递推建模序列，但计算串行，长距离依赖路径长。Transformer 使用 Self-Attention，使任意两个 token 可以直接交互，并且训练时可以用矩阵乘法并行计算所有位置的表示，因此更容易建模长距离依赖，训练效率也更高。

# 15. 考试高频总结

Transformer 必须会：

1. Transformer 是 Encoder-Decoder 架构。
2. Transformer 核心是 Self-Attention，不依赖 RNN。
3. Encoder block = **Multi-Head Self-Attention + FFN。**
4. Decoder block = **Masked Self-Attention + Encoder-Decoder Attention + FFN。**
5. 每个子层都有残差连接和 LayerNorm。
6. Self-Attention 训练时可并行计算。
7. Decoder 用 mask 防止看到未来 token。
8. Encoder-Decoder Attention 中，Q 来自 Decoder，K/V 来自 Encoder。
9. Transformer 需要位置编码。
10. Transformer 擅长长距离依赖。
11. 缺点是 Self-Attention 的复杂度是 $O(n^2)$。
12. 训练阶段 Decoder 可以并行，预测阶段仍需逐步生成。

Transformer 的核心思想是什么？

答案：

Transformer 的核心思想是**使用 Self-Attention 和 Multi-Head Attention 替代 RNN 的循环结构，使序列中任意两个位置可以直接交互**，并通过矩阵运算实现并行训练。它通常采用 Encoder-Decoder 架构，并使用位置编码补充顺序信息。

Transformer Encoder block 包含哪些主要部分？

Transformer Decoder block 包含哪些主要部分？

答案：

Transformer Decoder block 包含三个子层：Masked Multi-Head Self-Attention、Encoder-Decoder Attention 和 Position-wise Feed-Forward Network。每个子层外也有残差连接和 LayerNorm。

为什么 Transformer 需要位置编码？

Transformer 为什么可以并行训练？

答案：

Transformer 使用 Self-Attention，通过矩阵乘法一次性计算所有 token 两两之间的注意力关系，不需要像 RNN 那样等待前一个时间步隐藏状态计算完成。因此训练时所有位置可以并行计算。

Transformer Decoder 在训练和预测时都可以一次性生成整个目标序列。对还是错？

答案：

错。训练时由于目标序列已知，并使用 masked self-attention，所有位置可以并行计算。但预测时目标序列未知，Decoder 必须从 `<bos>` 开始，一个 token 一个 token 自回归生成，直到 `<eos>`。

答案：

Masked self-attention 用于遮蔽未来位置，保证 Decoder 在预测第 $t$ 个 token 时只能看到第 $t$ 个位置及之前的 token，不能提前看到未来答案，从而保持自回归生成性质。

## 题 8：比较题

Transformer 和 RNN 相比有什么优点和缺点？

答案：

Transformer 的**优点是可以并行训练，任意两个 token 可以直接通过注意力交互，长距离依赖路径短，适合建模复杂上下文**。缺点是 Self-Attention 的计算和存储复杂度为 $O(n^2)$，**长序列开销较大，并且需要位置编码补充顺序信息**。RNN 天然有顺序结构，但计算串行，长距离依赖较难学习。

## 题 9：应用题

在 Transformer 的 Encoder-Decoder Attention 中，Q、K、V 分别来自哪里？

答案：

Query 来自 Decoder 当前层的表示，Key 和 Value 来自 Encoder 的输出。这样 Decoder 在生成目标 token 时，可以根据当前解码状态去关注源序列中的相关位置。

## 题 10：综合题

请说明 Transformer 如何完成机器翻译任务。

答案：

Transformer Encoder 首先**读取源语言句子，将 token embedding 加上位置编码后送入多层 Encoder block，得到源序列每个位置的上下文表示**。Decoder **以 `<bos>` 开始，将目标前缀加位置编码后送入多层 Decoder block**；其中 **masked self-attention 建模已生成目标词之间的关系**，**encoder-decoder attention 根据 Decoder 当前状态关注源序列输出**。最后**经过线性层和 softmax 预测下一个目标词，重复生成直到 `<eos>`。**

# QA

## 残差连接和 LayerNorm一般放在transformer的block的什么位置

在 Transformer block 里，**残差连接 residual connection** 和 **LayerNorm** 一般围绕两个子层放：

1. **多头自注意力 Multi-Head Self-Attention**
2. **前馈网络 FFN / MLP**

常见有两种放法。

------

## 1. 原始 Transformer：Post-LN

**先做子层，再残差相加，最后 LayerNorm：**

$y = \text{LayerNorm}(x + \text{SelfAttention}(x))$

$z = \text{LayerNorm}(y + \text{FFN}(y))$

结构可以记成：

$x \rightarrow \text{Attention} \rightarrow +x \rightarrow \text{LayerNorm}$

$y \rightarrow \text{FFN} \rightarrow +y \rightarrow \text{LayerNorm}$

也就是：
**残差连接先加，LayerNorm 后做。**

------

## 2. 现在更常见：Pre-LN

**先 LayerNorm**，再做子层，最后残差相加：

$y = x + \text{SelfAttention}(\text{LayerNorm}(x))$

$z = y + \text{FFN}(\text{LayerNorm}(y))$

结构可以记成：

$x \rightarrow \text{LayerNorm} \rightarrow \text{Attention} \rightarrow +x$

$y \rightarrow \text{LayerNorm} \rightarrow \text{FFN} \rightarrow +y$

也就是：
**LayerNorm 先做，残差连接后加。**

------

## 考试/面试一句话

Transformer block 中，每个子层**外面**都有一个残差连接和 LayerNorm：

- **Attention 子层外面一组**
- **FFN 子层外面一组**

原始 Transformer 常写成：

$\text{LayerNorm}(x+\text{Sublayer}(x))$

现代大模型更常用：

$x+\text{Sublayer}(\text{LayerNorm}(x))$

继续讲 **BERT, Bidirectional Encoder Representations from Transformers**。这是 Attention 模块最后一个重点。review.md 里明确把 BERT 归为“基于 Transformer Encoder 的预训练语言模型”，并提示可能考“BERT 和传统语言模型有什么区别”。 D2L 第 14.8 节也专门讲 BERT，并指出它的预训练包括 **Masked Language Modeling 掩蔽语言模型** 和 **Next Sentence Prediction 下一句预测** 两个任务。

# BERT

# 1. BERT 是什么？

BERT 是一种基于 **Transformer Encoder** 的预训练语言模型。

它的核心思想是：

**先在大规模无标注文本上预训练一个通用语言表示模型，再把它微调到具体下游任务上。**

**例如：**

- **文本分类**
- **情感分析**
- **自然语言推断**
- **问答**
- **命名实体识别**
- **句子匹配**

所以 BERT 不是从零训练一个任务模型，而是：

**预训练 Pre-training + 微调 Fine-tuning**

这和前面图像里的微调类似：

ImageNet 预训练 ResNet → 替换输出层 → 微调新任务

NLP 中：

大语料预训练 BERT → 加任务头 → 微调新任务

# 2. BERT 为什么只用 Transformer Encoder？

Transformer 原本有 Encoder 和 Decoder。

机器翻译需要：

- Encoder 读源语言；
- Decoder 生成目标语言。

但 BERT 的**目标不是逐词生成文本**，而是**学习每个 token 的上下文表示。**

所以它只需要 Encoder。

Transformer Encoder 的特点是：

**每个 token 可以通过 self-attention 同时看到左右两边上下文。**

这正好**适合 BERT 学习双向表示。**

所以：

**BERT = 多层 Transformer Encoder 堆叠 + 预训练任务。**

BERT **不使用 Transformer Decoder，因此它不是典型的自回归生成模型。**

# 3. BERT 和传统语言模型的区别

传统从左到右语言模型：

$P(x_t|x_1,x_2,\cdots,x_{t-1})$

只能用左侧上下文预测当前词。

例如：

```
I went to the bank to deposit money
```

预测 `bank` 时，如果只看左边：

```
I went to the
```

信息不够充分。

BERT 的双向编码可以同时看左右上下文：

左边：`I went to the`

右边：`to deposit money`

所以更容易知道 `bank` 是“银行”，不是“河岸”。

考试答法：

**传统语言模型通常单向建模，只能利用左侧或右侧上下文；BERT 基于 Transformer Encoder，通过 masked language modeling 在预训练时利用双向上下文学习词表示。**

# 4. BERT 的输入表示由哪三部分组成？

BERT 的输入不是只有 token embedding，而是三部分相加：

$Input = TokenEmbedding + SegmentEmbedding + PositionEmbedding$

D2L 中的 BERTEncoder 也是**把 token embedding 和 segment embedding 相加**，再加上可学习的位置嵌入。

## 1. Token Embedding

表示词元本身。

例如：

```
I`, `love`, `deep`, `learning
```

每个 token 对应一个向量。

## 2. Segment Embedding

用于**区分句子 A 和句子 B。**

例如句子对任务：

句子 A：`I like cats`

句子 B：`They are cute`

BERT 会给句子 A 的 token 加 **segment** 0，给句子 B 的 token 加 segment 1。

作用：

**让模型知道哪些 token 属于第一句话，哪些属于第二句话。**

这对自然语言推断、句子匹配、问答等文本对任务很重要。

## 3. Position Embedding

表示 token 的位置。

因为 Transformer Encoder 本身没有递归结构，不天然知道词序，所以必须加入位置编码。

BERT 使用的是 **可学习位置嵌入 learnable positional embedding**，不是原始 Transformer 中固定正弦余弦位置编码。

# 5. BERT 的特殊符号：`[CLS]` 和 `[SEP]`

BERT 输入中常见两个特殊 token。

## `[CLS]`

放在整个输入序列最前面。

它的最终隐藏表示常用于整个句子或句子对的分类任务。

例如文本分类时：

```
[CLS] this movie is great [SEP]
```

最终取 `[CLS]` 对应的输出向量，接一个分类器。

D2L 中也提到，NSP 任务使用特殊词元 `<cls>` 的 BERT 表示来预测第二个句子是否是第一个句子的下一句。

## `[SEP]`

用于**分隔句子。**

单句任务：

```
[CLS] sentence [SEP]
```

句子对任务：

```
[CLS] sentence A [SEP] sentence B [SEP]
```

作用：

**告诉模型一句话结束，或者两个句子之间的边界。**

# 6. BERT 的预训练任务一：MLM 掩蔽语言模型

MLM 全称：

**Masked Language Modeling，掩蔽语言模型。**

做法：

随机选取输入中的一部分 token，把它们遮住，然后让模型根据左右上下文预测原来的 token。

例如原句：

```
I love deep learning
```

变成：

```
I love [MASK] learning
```

模型要预测：

```
deep
```

D2L 中也说明，为了双向编码上下文表示每个词元，BERT 会随机掩蔽词元，并使用来自双向上下文的词元以自监督方式预测被掩蔽词元，这就是掩蔽语言模型。

## 为什么 MLM 能实现双向？

因为被预测的 token 被 `[MASK]` 遮住了。

模型不能直接看到答案，但可以看到它左右两边的词。

例如：

```
I went to the [MASK] to deposit money
```

模型可以用左边和右边共同判断 `[MASK]` 是 `bank`。

这就让 BERT 学到双向上下文表示。

# 7. BERT 的预训练任务二：NSP 下一句预测

NSP 全称：

**Next Sentence Prediction，下一句预测。**

任务是**判断两个句子是否是连续句子。**

输入：

```
[CLS] sentence A [SEP] sentence B [SEP]
```

输出：

- IsNext：B 确实是 A 的下一句；
- NotNext：B 是随机抽来的，不是 A 的下一句。

D2L 中说明，NSP 是一个二分类任务：生成句子对时，一半是真实连续句子，标签为真；另一半第二句从语料库随机抽取，标签为假。

## NSP 的作用

MLM 主要学习 token 级别上下文表示。

NSP 试图让模型学习句子之间的关系。

例如：

句子 A：`A man is playing guitar.`

句子 B：`He is performing music.`

模型需要理解两个句子之间是否有关联。

D2L 小结中也说：MLM 能编码双向上下文表示单词，NSP 显式建模文本对之间的逻辑关系。

# 8. BERT 为什么叫“预训练语言模型”？

因为 MLM 和 NSP 的**标签不需要人工标注。**

**MLM 的标签来自原文本中被 mask 的词。**

**NSP 的标签来自语料中句子是否相邻。**

所以 BERT **可以利用大量无标注文本进行自监督学习。**

预训练完成后，BERT 已经学到通用语言知识：

- 词义
- 句法
- 上下文关系
- 一定的语义关系
- 文本对关系

然后再微调到具体任务。

# 9. BERT 如何微调 Fine-tuning？

BERT 微调流程：

1. 加载预训练 BERT。
2. 根据任务添加一个小的输出层。
3. 用目标任务数据训练整个模型或部分模型。
4. 通常预训练参数用较小学习率微调。

D2L 第 15.7 节就展示了加载预训练 BERT，并在自然语言推断任务上微调；它提到预训练 BERT 包含词表文件和预训练参数文件，加载后用于下游任务。

## 例子 1：文本分类

输入：

```
[CLS] this movie is wonderful [SEP]
```

**取 `[CLS]` 输出向量：**

$h_{CLS}$

接分类器：

$\hat{y}=softmax(W h_{CLS}+b)$

## 例子 2：句子对分类 / 自然语言推断

输入：

```
[CLS] premise [SEP] hypothesis [SEP]
```

输出：

- entailment 蕴含
- contradiction 矛盾
- neutral 中立

D2L 微调 BERT 的自然语言推断例子中，就是把前提和假设组成文本对输入 BERT。

## 例子 3：命名实体识别

对每个 token 的输出向量做分类。

例如判断每个词是：

- 人名
- 地名
- 组织名
- 其他

# 10. BERT 和 Transformer 的关系

Transformer 是模型架构。

BERT 是基于 Transformer Encoder 的预训练模型。

可以理解为：

**Transformer Encoder 是骨架；MLM/NSP 预训练任务给它注入语言知识。**

区别：

| 对比               | Transformer                                      | BERT                        |
| ------------------ | ------------------------------------------------ | --------------------------- |
| 类型               | 通用 Encoder-Decoder 架构                        | 预训练语言模型              |
| 结构               | Encoder + Decoder                                | 只用 Encoder                |
| 主要用途           | 翻译、生成等 Seq2Seq 任务                        | **文本理解任务**            |
| 训练方式           | 通常针对具体任务训练                             | **大语料预训练 + 下游微调** |
| 注意力             | Encoder self-attention，Decoder masked attention | **双向 self-attention**     |
| **是否自回归生成** | **Decoder 是**                                   | **不是典型自回归模型**      |

# 11. BERT 和 GPT 的区别

考试可能不一定考 GPT，但“BERT 和传统语言模型区别”可能会带到这个。

| 对比       | BERT                  | GPT 类自回归模型        |
| ---------- | --------------------- | ----------------------- |
| 结构       | Transformer Encoder   | Transformer **Decoder** |
| 上下文     | 双向上下文            | **单向，从左到右**      |
| 预训练任务 | MLM，预测被 mask 的词 | **下一个词预测**        |
| 擅长       | 理解类任务            | **生成类任务**          |
| 例子       | 文本分类、NLI、NER    | **文本续写、对话生成**  |

一句话：

**BERT 更偏理解，GPT 更偏生成。**

原因：

BERT 训练时能看双向上下文，但预测生成时不能像 GPT 那样自然地从左到右逐词生成。

# 12. BERT 的优点和局限

## 优点

1. 双向上下文表示强。
2. 预训练后可迁移到很多 NLP 任务。
3. 微调成本比从零训练低。
4. 对文本分类、匹配、问答、NER 等理解任务效果好。

## 局限

1. 预训练成本高。
2. 输入长度受限制，比如常见最大长度 512。
3. Self-Attention 复杂度是 $O(n^2)$，长文本开销大。
4. 不适合直接做长文本自回归生成。
5. MLM 预训练中 `[MASK]` 只出现在预训练，不出现在下游真实输入，存在一定预训练-微调不一致。

# 15. 考试风格练习题

## 题 1：概念题

BERT 是什么？它基于 Transformer 的哪一部分？

答案：

BERT 是一种基于 Transformer Encoder 的预训练语言模型。它使用多层 Transformer Encoder 通过 self-attention 学习双向上下文表示，然后通过预训练和微调应用到各种 NLP 下游任务。

## 题 2：简答题

BERT 的输入表示由哪三部分组成？

答案：

BERT 的输入表示由 token embedding、segment embedding 和 position embedding 三部分相加组成。**Token** embedding 表示词元本身，**segment** embedding 区分句子 A 和句子 B，**position** embedding 提供词元位置信息。

## 题 3：概念题

`[CLS]` 和 `[SEP]` 在 BERT 中分别有什么作用？

答案：

`[CLS]` 放在输入序列开头，其最终表示常用于句子级分类任务；`[SEP]` 用于分隔句子或表示句子结束，在句子对任务中用于区分两个句子的边界。

## 题 4：简答题

什么是 MLM？它为什么能让 BERT 学到双向上下文？

答案：

MLM 是 masked language modeling，掩蔽语言模型。它随机遮蔽输入中的部分 token，让模型根据左右上下文预测原来的 token。由于被预测词本身被 mask，模型必须同时利用左侧和右侧上下文，因此能学习双向表示。

## 题 5：简答题

什么是 NSP？它的作用是什么？

答案：

NSP 是 next sentence prediction，下一句预测。它让模型判断两个句子是否是连续句子，是一个二分类任务。它的作用是帮助模型学习句子对之间的关系，适合自然语言推断、问答、句子匹配等任务。

## 题 6：判断题

BERT 使用 Transformer Decoder，因此非常适合从左到右生成文本。对还是错？

答案：

错。BERT 主要使用 Transformer Encoder，不使用 Decoder。它通过 MLM 学习双向上下文表示，更适合理解类任务，不是典型的从左到右自回归生成模型。

## 题 7：比较题

BERT 和传统从左到右语言模型有什么区别？

答案：

传统从左到右语言模型根据前文预测下一个词，只能利用左侧上下文。BERT 通过 MLM 预测被遮蔽词，可以同时利用左右上下文，因此能学习双向语言表示。BERT 更适合文本理解任务，而从左到右语言模型更适合文本生成。

## 题 8：比较题

BERT 和 Transformer 原始架构有什么关系和区别？

答案：

Transformer 原始架构包含 Encoder 和 Decoder，常用于机器翻译等 Seq2Seq 任务。BERT 只使用 Transformer Encoder，通过 self-attention 学习双向上下文表示，并通过 MLM 和 NSP 进行预训练，主要用于文本理解任务。

## 题 9：应用题

如何用 BERT 做文本分类？

答案：

将输入文本组织为 `[CLS] text [SEP]`，送入 BERT 得到每个 token 的上下文表示。取 `[CLS]` 对应的最终输出向量，接一个全连接分类层和 softmax，得到类别概率。训练时在分类数据集上微调 BERT 和分类层参数。

## 题 10：综合题

为什么 BERT 的“预训练 + 微调”范式有效？

答案：

BERT 在大规模无标注文本上通过 MLM 和 NSP 学到通用语言知识，包括词义、上下文关系和句子关系。下游任务通常数据较少，如果从零训练容易效果差。使用预训练 BERT 作为初始化，再加任务输出层微调，可以把通用语言表示迁移到具体任务中，因此训练更快、泛化更好。

到这里，RNN 到 Attention 主线已经完整讲完：**RNN → GRU → LSTM → Deep/BiRNN → Seq2Seq → Attention → Self-Attention → Transformer → BERT**。接下来建议做一轮**高频综合对比与押题复盘**，把 CNN、RNN、Attention 三大模块容易混的结构题统一整理。
