# Java 期末复习讲义：第7章 一维数组 (Single-Dimensional Arrays)

## 1. 数组的基本概念与内存模型

### 1.1 定义
数组是一种数据结构，用于存储**固定大小**的**同类型**元素集合。

### 1.2 声明与创建 (Declaration & Creation)
在 Java 中，数组是**对象**（Object），存放在**堆（Heap）**中，而数组变量只是一个**引用（Reference）**。

**语法格式：**
*   **推荐格式（Java 风格）：** `elementType[] arrayRefVar;`
*   **兼容格式（C 风格）：** `elementType arrayRefVar[];` （考试中也能用，但建议用前者）

**创建步骤：**
1.  **声明引用：** `double[] myList;` （此时 `myList` 为 `null`，不占用数组空间）
2.  **创建数组：** `myList = new double[10];` （在堆中分配空间，并赋值给引用）
3.  **一步完成：** `double[] myList = new double[10];`

**内存图解（重要考点）：**
*   **Stack (栈):** 存储变量 `myList`，其值是一个内存地址。
*   **Heap (堆):** 存储实际的数组对象（包含10个 double 元素）。

### 1.3 长度与边界
*   **固定大小：** 数组一旦创建，大小不可改变。
*   **获取长度：** 使用 `.length` **属性**（注意：是属性不是方法，没有括号，这与 `String.length()` 不同）。
    ```java
    int len = myList.length; // 正确
    // int len = myList.length(); // 错误！编译不通过
    ```
*   **索引：** `0` 到 `length - 1`。访问越界会抛出 `ArrayIndexOutOfBoundsException`（运行时异常）。

### 1.4 默认值 (Default Values)
`new` 关键字创建数组后，元素会被自动初始化：
*   **数值型 (int, double, etc.):** `0` 或 `0.0`
*   **字符型 (char):** `'\u0000'` (即 null 字符)
*   **布尔型 (boolean):** `false`
*   **引用型 (String, Object):** `null`

## 2. 数组初始化 (Array Initializers)

### 2.1 静态初始化（简写语法）
**语法：** `elementType[] arrayRefVar = {value0, value1, ..., valuek};`

**示例：**

```java
double[] myList = {1.9, 2.9, 3.4, 3.5};
```
该语句隐含了 `new` 操作和赋值操作。

### 🚨 易错坑点 (Caution)
简写语法必须在**声明时**直接赋值，**不能分开写**。
```java
// 正确
double[] list = {1.0, 2.0};

// 错误！！！
double[] list;
list = {1.0, 2.0}; // 编译错误

// 如果非要分开写，必须使用完整 new 语法（匿名数组）：
double[] list;
list = new double[]{1.0, 2.0}; // 正确
```

## 3. 数组处理常见操作

### 3.1 增强型 for 循环 (For-Each Loop)
JDK 1.5 引入，用于遍历数组。
```java
for (double value : myList) {
    System.out.println(value);
}
```
*   **优点：** 代码简洁，不易越界。
*   **缺点：** 无法通过索引修改数组元素，也无法控制遍历步长（比如每隔一个访问）。

```Java
int[] arr = {1, 2, 3};
// 使用 var 关键字 类似auto
for (var val : arr) {
    System.out.println(val);
}
```

你提供的课件截图显示：Liang, Introduction to Java Programming, Tenth Edition, (c) 2015。

- **教材年份：** 2015年（基于 Java 8）。
- **var 发布年份：** 2018年（Java 10）。

**结论：**
尽管现在的 Java 开发中 var 很常用，但**在你的期末考试中，千万不要写 var！** 除非老师明确说过可以用 Java 10+ 的特性。

### 3.2 复制数组 (Copying Arrays)
*   **浅拷贝陷阱：**
    ```java
    list2 = list1; // 这不是复制数组内容！
    ```
    这只是将 `list1` 的引用地址赋给了 `list2`。此时两个变量指向堆中的同一个数组对象（垃圾回收机制可能会回收原本 `list2` 指向的对象）。

*   **真正的复制（内容复制）：**
    1.  **使用循环：** 手动逐个赋值。
    2.  **使用 `System.arraycopy` (高效，推荐)：**
        ```java
        // 参数：源数组, 源起始位置, 目标数组, 目标起始位置, 复制长度
        System.arraycopy(sourceArray, 0, targetArray, 0, sourceArray.length);
        ```

### 3.3 经典算法逻辑（课件示例）
1.  **找最大值：** 假设第一个是最大值，遍历后续元素进行比较更新。
2.  **随机洗牌 (Random Shuffling)：**
    *   从后往前遍历 (`i` 从 `length-1` 到 `1`)。
    *   随机生成一个索引 `j` (`0 <= j <= i`)。
    *   交换 `list[i]` 和 `list[j]`。
3.  **循环移位 (Shifting Elements)：**
    *   **左移示例：** 保留第一个元素 -> 将所有元素左移一位 -> 将保留的元素放到最后。
    ```java
    double temp = myList[0];
    for (int i = 1; i < myList.length; i++) {
        myList[i - 1] = myList[i];
    }
    myList[myList.length - 1] = temp;
    ```

## 4. 数组与方法 (Passing Arrays to Methods)

### 4.1 值传递 (Pass By Value) - 核心考点
Java 中**只有值传递**。
*   **基本类型参数：** 传递的是数据的副本。方法内修改不影响原数据。
*   **数组/对象参数：** 传递的是**引用的副本**（即内存地址）。
    *   **现象：** 在方法内修改 `array[i]`，会影响方法外的原数组（因为指向同一块堆内存）。
    *   **陷阱：** 如果在方法内让形参指向新的数组 `array = new int[5]`，这**不会**改变方法外的实参指向。

**代码示例（Quiz Slide 114）：**

```java
public static void m(int x, int[] y) {
    x = 3;      // 修改基本类型局部变量，不影响外部
    y[0] = 3;   // 修改引用指向的堆内存内容，影响外部
}
// 结果：x 还是 0，但 numbers[0] 变成了 3。
```

### 4.2 匿名数组 (Anonymous Array)
无需定义变量名，直接创建并传递给方法：
```java
printArray(new int[]{3, 1, 2, 6}); // 这里的 new int[]{} 不能省
```

### 4.3 方法返回数组
方法可以返回数组的引用。
```java
public static int[] reverse(int[] list) {
    int[] result = new int[list.length];
    // ...处理逻辑...
    return result; // 返回新数组的引用
}
```

## 5. 搜索与排序 (Searching & Sorting)

### 5.1 线性查找 (Linear Search)
*   **逻辑：** 遍历数组，逐个比较。
*   **复杂度：** O(N)。
*   **返回值：** 找到返回索引，没找到返回 `-1`。

### 5.2 二分查找 (Binary Search)
*   **前提：** 数组必须是**已排序**（升序）的。
*   **逻辑：** 比较中间值，缩小一半范围。
*   **复杂度：** O(log N)。
*   **`java.util.Arrays.binarySearch(list, key)` 返回值规则（常考）：**
    *   找到：返回索引（`>= 0`）。
    *   **没找到：** 返回 `-(insertionPoint) - 1`。
    *   *insertionPoint* 是指假如要把这个 key 插入并保持有序，它应该在的位置。
    *   **例子：** `list = {1, 2, 3, 7, 14}`，找 `5`。
        *   `5` 应该插在 `3` 和 `7` 之间，索引为 `3`。
        *   返回结果：`-3 - 1 = -4`。

### 5.3 选择排序 (Selection Sort)
*   **逻辑：**
    1.  遍历数组，找到当前范围 `[i, length-1]` 内的最小值。
    2.  将最小值与当前位置 `i` 的元素交换。
    3.  `i` 自增，重复。
*   **复杂度：** O(N^2)。

### 5.4 `java.util.Arrays` 工具类
*   `Arrays.sort(list)`: 对数组进行排序。
*   `Arrays.sort(list, fromIndex, toIndex)`: 对部分排序。
*   `Arrays.parallelSort(list)`: Java 8 引入，利用多核 CPU 并行排序。
*   `Arrays.toString(list)`: 快速打印数组内容（讲义未提及，但考试编程题很有用）。

## 6. Main 方法与命令行参数

`public static void main(String[] args)`
*   `args` 是一个字符串数组，接收命令行参数。
*   **运行命令：** `java TestMain arg0 arg1 arg2`
*   **对应关系：**
    *   `args[0]` -> "arg0"
    *   `args[1]` -> "arg1"
    *   `args.length` -> 3
*   **注意：** 与 C++ 不同，Java 的 `args[0]` **不是**程序本身的名字，而是第一个真正的参数。

## 7. Java 数组 vs. C++ 数组 (重点对比)

对于软工学生，理解语言差异很重要：

| 特性         | Java                                          | C++                                            |
| :----------- | :-------------------------------------------- | :--------------------------------------------- |
| **内存位置** | 始终在堆(Heap)上，通过引用访问                | 可以在栈(Stack)上，也可以在堆上                |
| **越界检查** | 严格检查，抛 `ArrayIndexOutOfBoundsException` | 不检查，可能访问垃圾数据或导致段错误(Segfault) |
| **长度感知** | 知道自己的长度 (`array.length`)               | 原生数组不知道长度，通常需要单独传递 size 参数 |
| **声明语法** | `int[] a` (推荐) 或 `int a[]`                 | `int a[10]` 或 `int* a`                        |
| **内存回收** | 垃圾回收器 (GC) 自动处理                      | 堆上分配的 (`new`) 必须手动 `delete[]`         |
| **默认值**   | 保证初始化 (0/null/false)                     | 栈上数组如果不初始化，包含随机垃圾值           |

## 8. 期末考试 Cheat Sheet (易错点总结)

1.  **声明与创建的区别：** `int[] x` 只是引用，`new int[5]` 才是创建。
2.  **索引越界：** 最后一个元素是 `length-1`，不是 `length`。
3.  **Length 语法：** 数组是 `.length`，字符串是 `.length()`，集合是 `.size()`。
4.  **二分查找返回值：** 未找到时返回负数，计算公式是 `-(插入点) - 1`，不是直接返回 -1。
5.  **增强型 For 循环：** 里面的变量是只读的拷贝（对于基本类型），修改它不会改变数组原元素。
6.  **引用传递：** 方法内修改数组内容会影响外部，但在方法内 `new` 一个新数组赋值给形参不会影响外部引用。
7.  **混合类型：** 数组只能存同一种类型，但如果是 `double[]`，可以存 `int`（自动提升），反之不行。
