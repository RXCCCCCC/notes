# Java 第6章复习讲义：方法 (Methods)

## 1. 核心概念与定义 (Defining Methods)

方法（Method）是为了执行特定操作而组合在一起的语句集合。它体现了**模块化**和**代码复用**的思想。

### 1.1 语法结构
```java
modifier returnValueType methodName(list of parameters) {
    // Method body
    // ...
    return value; // 如果 returnValueType 不是 void
}
```

*   **Modifier (修饰符)**: 如 `public static`。
    *   *注意*：在本章中，大部分方法都是 `public static`，这意味着它们可以在 `main` 方法中直接调用，而不需要实例化对象。
*   **Return Value Type (返回值类型)**: 方法返回的数据类型（如 `int`, `double`, `String`）。如果不返回值，必须写 `void`。
*   **Method Name (方法名)**: 遵循驼峰命名法（camelCase），如 `computeSum`。
*   **Parameters (参数)**:
    *   **形式参数 (Formal Parameters)**: 方法定义头部的变量（如 `int num1`）。
    *   **实际参数 (Actual Parameters/Arguments)**: 调用方法时传递的具体值（如 `max(5, 2)` 中的 5 和 2）。
*   **Method Signature (方法签名)**: **方法名 + 参数列表**。
    *   *考点*: 返回值类型**不是**签名的一部分。

### 1.2 示例代码
```java
// 定义
public static int max(int num1, int num2) {
    if (num1 > num2)
        return num1;
    else
        return num2;
}

// 调用
int z = max(5, 7); // 5 和 7 是实参
```

## 2. 方法调用与内存模型 (Call Stacks)

理解**调用栈 (Call Stack)** 对于理解代码执行流程和变量作用域至关重要。

### 2.1 执行流程 (LIFO - 后进先出)
1.  当调用一个方法时，系统会在**栈 (Stack)** 中创建一个**活动记录 (Activation Record)** 或栈帧。
2.  该记录存储了方法的参数和局部变量。
3.  方法执行完毕后（遇到 `return` 或右大括号 `}`），该活动记录从栈中弹出，内存被释放。
4.  控制权返回给调用者。

### 2.2 考试常考题型：追踪堆栈
（参考课件Slide 16-26的动画演示）
给定一段嵌套调用的代码，问你某时刻变量的值，或者画出栈的变化。
*   **关键点**: `main` 方法最后才会被弹出。局部变量（如 `i`, `j`）只在当前方法的栈帧中有效，不同方法中的同名变量互不干扰。

## 3. 参数传递：值传递 (Pass-by-Value)

这是本章**最重要**的概念，也是与C++易混淆的地方。

### 3.1 核心规则
**Java 只有值传递 (Pass-by-Value)。**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                

*   当你调用方法时，你传递的是**变量值的副本**。
*   对于基本数据类型（int, double, char等）：方法内部对参数的修改**不会影响**原来的变量。

### 3.2 代码示例与坑点
```java
public static void swap(int n1, int n2) {
    int temp = n1;
    n1 = n2;
    n2 = temp;
    System.out.println("In method: " + n1 + " " + n2); // 输出交换后的值
}

public static void main(String[] args) {
    int num1 = 1;
    int num2 = 2;
    swap(num1, num2);
    System.out.println("In main: " + num1 + " " + num2); 
    // 输出: In main: 1 2
    // 并不是 2 1，因为 main 中的 num1 和 num2 从未被触碰。
}
```

## 4. 方法重载 (Method Overloading)

### 4.1 定义
在同一个类中，方法名相同，但**参数列表不同**（参数个数不同，或参数类型不同）。

```java
// 下面两个方法构成了重载
public static int max(int num1, int num2) { ... }
public static double max(double num1, double num2) { ... }
```

### 4.2 歧义调用 (Ambiguous Invocation) - 编译错误
当编译器无法确定哪一个重载方法最匹配时，会报错。

**经典考题 (Slide 47)**:
```java
public static void max(int n1, double n2) { ... } // 方法 A
public static void max(double n1, int n2) { ... } // 方法 B

public static void main(String[] args) {
    max(1, 2); // 错误！Ambiguous invocation
}
```
*   **解析**: `1` 是 int，`2` 是 int。
    *   如果调用方法 A，`2` 需要自动转为 double。
    *   如果调用方法 B，`1` 需要自动转为 double。
    *   两者匹配程度相同，编译器无法抉择，因此报错。

## 5. 局部变量的作用域 (Scope of Local Variables)

### 5.1 规则
*   变量的作用域从**声明处**开始，到**包含它的块结束**（即最近的 `}`）为止。
*   **嵌套块规则**:
    *   外部块定义的变量，在内部块中可以直接使用。
    *   **但是在内部块中，不能定义与外部块同名的变量**（这与C++不同，C++允许遮蔽/Shadowing，但Java不允许，会报编译错）。

**错误示例 (Slide 51)**:
```java
public static void method() {
    int i = 1;
    // ...
    for (int k = 0; k < 10; k++) {
        int i = 2; // 编译错误！变量 i 已经在外部定义过了。
    }
}
```
**正确示例**:
```java
public static void method() {
    for (int i = 0; i < 10; i++) { ... } // 第一个 i
    for (int i = 0; i < 10; i++) { ... } // 第二个 i
    // 这是合法的，因为第一个 i 的作用域在第一个循环结束时已经销毁。
}
```

## 6. Java 与 C++ 的区别 (重点对比)

作为软工学生，这是你面试和考试加深理解的关键。

| 特性             | Java                                     | C++                                                      | 备注                                                         |
| :--------------- | :--------------------------------------- | :------------------------------------------------------- | :----------------------------------------------------------- |
| **方法位置**     | 方法必须定义在类 (Class) 内部。          | 函数可以独立于类存在（全局函数）。                       | Java 中一切皆对象，没有孤立的函数。                          |
| **参数传递**     | **永远是值传递 (Pass-by-Value)**。       | 支持值传递和**引用传递** (Pass-by-Reference, 使用 `&`)。 | C++ 中 `void swap(int &a, int &b)` 可以真正交换外部变量，Java 做不到这点（针对基本类型）。 |
| **默认参数**     | **不支持**默认参数值。                   | 支持 (e.g., `void func(int a = 0)`).                     | Java 通过**方法重载**来实现类似默认参数的效果。              |
| **局部变量遮蔽** | **不允许**在嵌套块中重定义同名变量。     | **允许**，内部变量会遮蔽外部变量。                       | Java 的设计更安全，防止意外的命名冲突。                      |
| **布尔值判断**   | `if(n)` 只有当 n 是 `boolean` 时才合法。 | `if(n)` 只要 n 非0即为真。                               | Java 中 `int` 不能自动转为 `boolean`。                       |

## 7. 常见陷阱与易错点 (Exam Pitfalls)

### 7.1 "Missing Return Statement" 编译错误 (Slide 14/25)
如果在有返回值的方法中使用了 `if-else`，编译器必须确保**所有**可能的路径都有返回值。

**错误代码**:
```java
public static int sign(int n) {
    if (n > 0) return 1;
    else if (n == 0) return 0;
    else if (n < 0) return -1; 
    // 编译器报错！它认为如果 n 不满足上述任何条件怎么办？
    // 虽然逻辑上涵盖了所有整数，但编译器只看语法结构。
}
```
**修正**: 将最后一个 `else if` 改为 `else`，或者在方法最后加一个默认 `return`。

### 7.2 void 方法中的 return
`void` 方法可以有 `return;` 语句，用于提前结束方法执行，但后面不能跟任何值。

### 7.3 参数类型不匹配
调用 `nPrintln("Hello", 5)` 与定义 `nPrintln(String message, int n)` 匹配。
但调用 `nPrintln(5, "Hello")` 则**不匹配**，除非你有另一个重载方法支持这种顺序。

## 8. 实战代码：数字求和 (Slide 37-38)

这个例子涵盖了取模、除法循环以及方法调用，是期末大题的热门考点。

**题目**: 编写方法 `sumDigits(long n)` 计算整数所有数位之和。例如 `234` -> `2+3+4=9`。

**完整代码解析**:
```java
import java.util.Scanner;

public class Test {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Enter a number: ");
        long value = input.nextLong(); // 使用 long 防止溢出
        
        System.out.println("The sum of digits for " + value + 
                           " is " + sumDigits(value));
    }

    public static int sumDigits(long n) {
        // 1. 处理负数情况 (虽然题目可能只假设正数，但写上Math.abs更严谨)
        // 注意：课件代码将其强转为 int，如果 n 很大可能会溢出，
        // 但计算数位和本身通常不会超过 int 范围。
        // 课件写法：int temp = (int)Math.abs(n); 
        
        // 更通用的写法建议直接用 long 运算：
        long temp = Math.abs(n); 
        int sum = 0;

        // 2. 循环提取每一位
        while (temp != 0) {
            long remainder = temp % 10; // 取出最后一位 (例如 234 % 10 = 4)
            sum += remainder;           // 累加
            temp = temp / 10;           // 去掉最后一位 (例如 234 / 10 = 23)
        }

        return sum;
    }
}
```

### 8.1 算法核心 (背诵)
*   **提取个位**: `n % 10`
*   **删除个位**: `n / 10`
*   **循环条件**: `n != 0` (或 `n > 0`)
