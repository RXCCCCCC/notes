# 引脚对应关系

| **模块**              | **接口类型** | **引脚/外设**                              | **仿真图位置/备注**                |
| --------------------- | ------------ | ------------------------------------------ | ---------------------------------- |
| **MQ-135 (或其他)**   | Analog       | **PA0** (ADC1_IN0)                         | 原理图 `MQ_Series` 左侧            |
| **MQ-136**            | Analog       | **PA1** (ADC1_IN1)                         | 原理图 `MQ_Series` 中间            |
| **MQ-137**            | Analog       | **PA2** (ADC1_IN2)                         | 原理图 `MQ_Series` 右侧            |
| **OLED (128x64)**     | I2C          | **PB10 (SCL)**, **PB3 (SDA)**   **(I2C2)** | **注意：OLED接的是I2C2，不是I2C1** |
| **SHT35 (图为SHT21)** | I2C          | **PB6 (SCL)**, **PB7 (SDA)**   **(I2C1)**  | 仿真中使用SHT21模型代替            |
| **SGP30**             | I2C          | **PA8 (SCL)**, **PC9 (SDA)**   **(I2C3)**  | 使用独立的一组I2C                  |
