### 小知识点

- 于多维数组来说，`a[10:][:]` 其实是先切行再对结果整体切片，容易引起歧义或错误。标准写法是 `a[10:, :]`,**用逗号分割维度更适合数据处理**

- ```
	V = np.cov(a[:10, :].T, ddof=1)  #计算协方差阵
	```

	这行代码的意思是：

	- `a[:10, :]`：取前 10 行所有列的数据（即两类已知样本）。
	- `.T`：对数据进行转置，使每一列代表一个变量，每一行为一个样本。
	- `np.cov(..., ddof=1)`：计算这些变量的协方差矩阵，**`ddof=1` 表示用无偏估计（分母用 n-1）。**

- `np.linspace` 是 NumPy 库中的一个函数，用于在指定的区间内生成**等间隔的数字序列**。

### 大知识点

`linkage` 是 SciPy 库中 `scipy.cluster.hierarchy` 模块的一个函数，用于层次聚类（Hierarchical Clustering）。

主要功能：

- 根据输入的距离矩阵或原始数据，计算聚类的层次结构（树状结构）。
- 返回一个 linkage matrix（连接矩阵），描述每一步聚类的合并过程。

常用参数：

- `y`：原始数据（二维数组）或距离矩阵（一维数组）。
- `method`：聚类方法，如 `'single'`（单链接）、`'complete'`（全链接）、`'average'`（均值链接）、`'ward'`（最小方差法）等。
- `metric`：距离度量方式（如 `'euclidean'`、`'cityblock'` 等），仅在输入原始数据时使用。

返回值：

- 一个二维数组，每一行表示一次聚类合并，包含：两个被合并的簇的编号、合并后的距离、合并后簇的样本数。

### 大知识点

### LaTeX 编译选项

1. Recipe: PDFLaTeX
	 - 生成 PDF，适合大多数**标准 LaTeX 文档（不含特殊字体/中文/Unicode）**。
	 - 推荐用于普通英文论文、模板。
2. Recipe: XeLaTeX
	 - 生成 PDF，**支持 Unicode 和系统字体，适合需要中文、特殊符号或自定义字体的文档。**
	 - 推荐用于含中文、特殊符号或需要用系统字体的场景。
3. Recipe: BibTeX
	 - **处理参考文献，需配合其它编译流程**（如 PDFLaTeX + BibTeX + PDFLaTeX）。
	 - 当文档有文献引用时，需先编译主文件，再运行 BibTeX，然后再编译主文件两次。
4. Recipe: LaTeXmk
	 - **自动多次编译**，处理交叉引用、目录、文献等，适合复杂文档。
	 - 推荐用于需要**自动处理所有依赖**的场景。
5. Recipe: xelatex -> bibtex -> xelatex*2
	 - 适合**含中文/特殊字体且有参考文献**的文档，自动完成所有编译步骤。
	 - 推荐用于**中文论文**或需要 XeLaTeX 编译且有文献的场景。
6. Recipe: pdflatex -> bibtex -> pdflatex*2
	 - 适合**英文论文且有参考文献**，自动完成所有编译步骤。
	 - 推荐用于英文论文或标准 LaTeX 模板。

总结：

- **英文/标准文档用 PDFLaTeX 或 pdflatex -> bibtex -> pdflatex*2。**
- **中文/特殊字体用 XeLaTeX 或 xelatex -> bibtex -> xelatex*2。**
- 有文献引用时需用 BibTeX 或自动流程。
- **LaTeXmk 适合自动化和复杂文档(可以无脑用)。**

### 大知识点

机器学习中的“率”通常指模型评估指标，常见的有以下几种：

1. **正确率（Accuracy）**

- 定义：**预测正确的**样本数**占总样本数**的比例。
- 适用场景：类别分布均衡时效果好。
- 缺点：类别不均衡时容易误导。

1. **精确率（Precision）**

- 定义：**预测为正类的样本中，实际为正类**的比例。
- 适用场景：关注假阳性（误报）时，如垃圾邮件检测。
- 缺点：不能反映假阴性（漏报）情况。

1. 召回率（Recall）

- 定义：**实际为正类的样本中，被正确预测为正类的**比例。
- 适用场景：关注假阴性（漏报）时，如疾病筛查。
- 缺点：不能反映假阳性（误报）情况。

1. F1值（F1-score）

- 定义：**精确率和召回率的调和平均数，综合考虑两者。**
- 适用场景：需要**平衡**精确率和召回率时。
- 缺点：不易解释为概率。

1. ROC曲线与AUC

- ROC曲线：反映不同阈值下的假阳性率和真正率。
- AUC：ROC曲线下的面积，越大模型越好。

比较：

- 正确率简单直观，但不适合类别极度不均衡的数据。
- 精确率和召回率分别关注误报和漏报，适合不同实际需求。
- F1值综合精确率和召回率，适合需要平衡两者的场景。
- AUC适合评估模型整体区分能力，尤其在二分类问题中常用。
