# Java 期末复习讲义 (Chapter 1 & 2)

## 第一部分：Java 核心概念与运行机制 (Chapter 1)

这部分通常出现在选择题或简答题中，考察对Java生态系统的理解。

### 1. 核心术语辨析 (必考)
课件中强调了三层金字塔结构，包含关系如下：**JDK > JRE > JVM**

*   **JVM (Java Virtual Machine):**
    *   **作用：** 运行Java字节码（`.class`文件），是Java实现"跨平台"（Platform-independent）的核心。
    *   **特点：** 它是软件模拟的计算机。不同操作系统（Windows, Linux, Mac）有不同版本的JVM，但它们运行相同的字节码。
*   **JRE (Java Runtime Environment):**
    *   **包含：** JVM + Java核心类库 (Libraries)。
    *   **作用：** 仅仅是运行Java程序的环境，不能开发。
*   **JDK (Java Development Kit):**
    *   **包含：** JRE + 开发工具 (编译器 `javac`, 运行器 `java`, 调试器 `jdb` 等)。
    *   **作用：** 开发者必须安装JDK。

### 2. 程序编译与执行流程
与C++直接编译成机器码不同，Java是半编译半解释的。

1.  **编写源码：** `Welcome.java`
2.  **编译 (Compile):** 使用 `javac Welcome.java`。
    *   生成字节码文件 `Welcome.class`。
    *   **注意：** 字节码不是机器码，它是CPU无关的 (CPU-specific code)。
3.  **运行 (Run):** 使用 `java Welcome`。
    *   JVM加载类，解释执行字节码。

### 3. Java 版本与应用领域
*   **Java SE (Standard Edition):** 桌面应用、Applet（虽然已过时但课件提了）、基础开发。**本书和考试基于此版本。**
*   **Java EE (Enterprise Edition):** 企业级应用，服务器端 (Server-side)。
*   **Java ME (Micro Edition):** 移动设备、嵌入式设备 (资源受限设备)。

## 第二部分：基础语法与程序结构 (Chapter 1 & 2)

### 1. 主类结构 (Template)
Java是纯面向对象的，所有代码必须包裹在 `class` 中。

```java
// 文件名必须是 Welcome.java (与 public class 类名一致)
public class Welcome { 
    // main 方法入口，语法必须严格一致
    public static void main(String[] args) { 
        System.out.println("Welcome to Java!"); 
    }
}
```

*   **C++ 对比：**
    *   Java 的 `main` 方法必须放在类里面。
    *   `String[] args` 对应 C++ 的 `int argc, char* argv[]`，但Java中 `args` 不包含程序名本身。

### 2. 基本数据类型 (Primitive Data Types)
Java的数据类型长度是**固定**的，不随操作系统改变（这是可移植性的体现）。

| 类型      | 大小 (Bit) | 范围              | 注意事项                         |
| :-------- | :--------- | :---------------- | :------------------------------- |
| `byte`    | 8          | -128 ~ 127        | **易错点：** 超出范围会溢出      |
| `short`   | 16         | -32768 ~ 32767    |                                  |
| `int`     | 32         | -2^31 ~ 2^31-1    | 整数默认类型                     |
| `long`    | 64         | -2^63 ~ 2^63-1    | 数值后需加 `L` (如 `100L`)       |
| `float`   | 32         |                   | 数值后需加 `F` (如 `1.0F`)       |
| `double`  | 64         |                   | 浮点默认类型                     |
| `boolean` | -          | `true` 或 `false` | **C++区别：** 不能用 0 或 1 代表 |

### 3. 常量 (Named Constants)
*   **语法：** `final datatype CONSTANTNAME = VALUE;`
*   **规范：** 变量名全大写。
*   **C++ 对比：** 对应 C++ 的 `const` 关键字，但Java使用 `final`。

### 4. 键盘输入 (Scanner 类)
这是Chapter 2的重点代码，必须背诵。

```java
import java.util.Scanner; // 1. 导包

public class InputExample {
    public static void main(String[] args) {
        // 2. 创建Scanner对象
        Scanner input = new Scanner(System.in); 
        
        System.out.print("Enter a double: ");
        // 3. 读取输入
        double d = input.nextDouble(); 
        
        System.out.print("Enter an int: ");
        int i = input.nextInt();
        
        // 4. 关闭 (习惯上要写，虽然课件主要关注读取)
        // input.close(); 
    }
}
```

## 第三部分：运算、转换与易错坑点 (Chapter 2 重点)

这部分是编程题和代码阅读题的重灾区。

### 1. 数值类型转换 (Type Conversion)
Java 在二元运算中会遵循**类型提升**规则：
*   如果有一个操作数是 `double` -> 另一个转 `double`。
*   否则，如果有 `float` -> 转 `float`。
*   否则，如果有 `long` -> 转 `long`。
*   **否则，两个都转 `int` 进行计算 (即使是 byte 或 short)。**

**类型转换 (Casting):**
*   **隐式 (Widening):** 小转大，自动。 `double d = 3;` (3 变为 3.0)
*   **显式 (Narrowing):** 大转小，必须强制。 `int i = (int)3.9;` (结果为3，截断小数，**不是四舍五入**)

### 2. 常见的 5 大错误与陷阱 (课件特别强调)

#### 错误 1: 整数除法 (Integer Division)
这是最经典的坑。
```java
int number1 = 1;
int number2 = 2;
double average = (number1 + number2) / 2; 
// 结果是 1.0！因为 (1+2)/2 是整数运算，结果为1，赋值给double变成1.0

// 修正：
double average = (number1 + number2) / 2.0; // 结果 1.5
```

#### 错误 2: 整数溢出 (Integer Overflow)
```java
int value = 2147483647 + 1; 
// 结果会变成负数 -2147483648 (回绕)
```

#### 错误 3: 浮点数精度丢失 (Round-off Errors)
浮点数在计算机中是近似存储的。
```java
System.out.println(1.0 - 0.9); 
// 输出: 0.09999999999999998 而不是 0.1
```
*   **考试技巧：** 如果判断两个浮点数是否相等，**绝对不能**用 `d1 == d2`，而应该用 `Math.abs(d1 - d2) < 1e-6`。

#### 错误 4: 未初始化的变量
C++中未初始化的局部变量可能是垃圾值，Java中**局部变量**如果不初始化，编译器会直接**报错** (Compilation Error)，无法运行。

#### 坑点: 冗余的输入对象
**不要**在每次读取时都 `new Scanner(System.in)`。应该只创建一个对象，多次使用。

### 3. 常用数学方法 (Math 类)
*   `Math.pow(a, b)`: 计算 $a^b$。**注意：** 返回值永远是 `double` 类型。
*   示例：`Math.pow(2, 3)` 返回 `8.0`。

### 4. 自增/自减运算符 (++, --)
逻辑与C++一致，但课件建议：**避免在复杂表达式中使用**，以防代码难以阅读。
*   `int j = ++i;` (先加后用)
*   `int j = i++;` (先用后加)

## 第四部分：Java 与 C++ 的核心区别 (考试加分项)

根据课件内容及隐含知识，总结如下：

1.  **指针 (Pointers):**
    *   **C++:** 广泛使用指针，直接操作内存，灵活但危险。
    *   **Java:** **不使用指针**，使用“引用 (Reference)”。内存管理自动处理（垃圾回收机制），更安全、简单。
2.  **布尔类型 (Boolean):**
    *   **C++:** 数值和布尔可以互转 (0是false，非0是true)。
    *   **Java:** `boolean` 是独立类型，**不能**与 `int` 互转。
        *   `if (1) { ... }` 在 Java 中是**编译错误**。必须写 `if (true) { ... }`。
3.  **内存管理:**
    *   **C++:** 需手动 `delete` 释放内存。
    *   **Java:** 自动垃圾回收 (Garbage Collection)。
4.  **平台独立性:**
    *   **C++:** 编译为特定CPU的机器码 (Windows编译的exe不能在Linux跑)。
    *   **Java:** 编译为字节码 (Bytecode)，由JVM解释，"Write Once, Run Anywhere"。

## 第五部分：实战代码演练 (模拟题)

根据课件最后的 Quiz 编写一个计算程序。

**题目：** 计算复利值。
公式：$FutureValue = Investment \times (1 + MonthlyRate)^{Years \times 12}$
要求：输入年利率，输出结果保留两位小数（逻辑上保留，或使用特定格式化）。

```java
import java.util.Scanner; 

public class InvestmentCalculator {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        // 1. 输入本金
        System.out.print("Enter investment amount: ");
        double investmentAmount = input.nextDouble();

        // 2. 输入年利率 (例如 4.25 代表 4.25%)
        System.out.print("Enter annual interest rate: ");
        double annualRate = input.nextDouble();
        
        // 转换成年利率小数和月利率
        // 坑点：必须除以1200 (即 /100 变成百分比，再 /12 变成月率)
        double monthlyRate = annualRate / 1200.0;

        // 3. 输入年数
        System.out.print("Enter number of years: ");
        int years = input.nextInt();

        // 4. 计算 (使用 Math.pow)
        // 坑点：指数部分是 years * 12
        double futureValue = investmentAmount * Math.pow(1 + monthlyRate, years * 12);

        // 5. 输出
        // 方法一：课件中的简易保留两位小数法 (先乘100，转int截断，再除100.0)
        double formattedValue = (int)(futureValue * 100) / 100.0;
        System.out.println("Accumulated value is " + formattedValue);
        
        // 方法二 (扩展知识，课件注释中提到)：
        // System.out.printf("Accumulated value is %.2f", futureValue);
    }
}
```
