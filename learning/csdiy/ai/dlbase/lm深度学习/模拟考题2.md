

# 1. 请简述你对误差反向传播算法的理解

误差反向传播算法，**Backpropagation，简称 BP**，是神经网络训练中用于**计算参数梯度**的核心算法。它的基本思想是：**先通过前向传播计算模型输出和损失**，再**从输出层开始，利用链式法则将误差逐层向前传播**，计算**损失函数对每一层参数的梯度，最后用梯度下降类优化算法更新参数。**

完整流程可以概括为：

第一步，前向传播：

输入样本经过各层网络计算，得到预测结果 $\hat{y}$。

第二步，计算损失：

用损失函数衡量预测值和真实标签 $y$ 的差异，例如分类任务中常用交叉熵损失。

第三步，反向传播：

从输出层开始，**根据链式法则计算损失对每层参数的偏导数**。例如**某层参数为 $W$，**需要计算：

$\frac{\partial L}{\partial W}$

第四步，**参数更新：**

**用优化算法更新参数**，例如 SGD：

$W \leftarrow W-\eta \frac{\partial L}{\partial W}$

其中 $\eta$ 是学习率。

BP 的核心是**链式法则**。因为神经网络是多层复合函数，损失函数对前面层参数的影响不能直接得到，需要把后一层的梯度逐层传回前一层。因此反向传播可以高效地复用中间梯度，避免对每个参数单独做低效求导。

考场总结句：

**误差反向传播算法通过前向传播计算损失，再利用链式法则从后向前逐层计算梯度，并结合梯度下降更新参数，是训练深度神经网络的基础算法。**

# 2. 请列出卷积神经网络的主要结构模块，以及各个模块完成的功能

卷积神经网络 CNN 通常由以下几个主要模块组成：

## 1. 输入层 Input Layer

**输入层接收原始图像数据。**

图像通常表示为：

$C \times H \times W$

其中 $C$ 是通道数，$H$ 是高度，$W$ 是宽度。

例如彩色图像一般是：

$3 \times H \times W$

作用：

**保存图像的空间结构和通道信息。**

## 2. 卷积层 Convolutional Layer

卷积层使用**多个卷积核在图像上滑动，提取局部特征**。

**低层卷积可能提取：**

**边缘、角点、纹理。**

**高层卷积可能提取：**

**局部部件、语义特征。**

卷积层的优势是：

- 局部连接；
- 参数共享；
- 保留空间结构；
- 参数量比全连接层少。

作用：

**提取图像局部特征，是 CNN 的核心模块。**

## 3. 激活函数层 Activation Layer

常用**激活函数是 ReLU：**

$ReLU(x)=\max(0,x)$

作用：

**引入非线性，使网络能够拟合复杂函数。**

如果没有激活函数，多层卷积或全连接**叠加后仍然等价于线性变换，**表达能力有限。

## 4. 池化层 Pooling Layer

常见池化有：

- 最大池化 Max Pooling；
- 平均池化 Average Pooling。

池化层通常在局部窗口内取最大值或平均值。

作用：

- **降低特征图空间尺寸；**
- **减少计算量；**
- **增强一定的平移鲁棒性；**
- **保留主要**特征。

注意：

**池化通常改变高宽，不改变通道数。**

## 5. 归一化层 Normalization Layer

**常见是 BatchNorm。**

作用：

- **稳定中间层特征分布；**
- **加快收敛；**
- **缓解梯度**过大或过小；
- **提高训练稳定性。**

在 CNN 中常见结构是：

$Conv \to BatchNorm \to ReLU$

## 6. 全连接层 Fully Connected Layer

全连接层通常位于 CNN 后端，将卷积层提取到的**特征映射到最终类别。**

作用：

**综合前面提取到的特征，完成分类或回归。**

例如图像分类中，全连接层输出类别分数。

## 7. 输出层 Output Layer

分类任务中，输出层通常接 softmax：

$\hat{y}_j=\frac{\exp(o_j)}{\sum_k \exp(o_k)}$

作用：

**输出每个类别的预测概率。**

考场总结句：

**CNN 主要由输入层、卷积层、激活层、池化层、归一化层、全连接层和输出层组成。卷积层负责提取局部特征，激活层引入非线性，池化层降低尺寸并增强鲁棒性，归一化层稳定训练，全连接层和输出层完成最终分类。**

# 3. 请简述你对 LSTM 的理解，并解释为什么它能够解决长时依赖问题

LSTM，全称 Long Short-Term Memory，长短期记忆网络，是一种改进的循环神经网络。它主要用于解决普通 RNN 在长序列中容易出现的**梯度消失**和**长距离依赖难以学习**的问题。

普通 RNN 的隐藏状态更新为：

$H_t=\tanh(X_tW_{xh}+H_{t-1}W_{hh}+b_h)$

普通 RNN 每个时间步都会重新计算隐藏状态，旧信息容易被不断覆盖；反向传播时梯度需要经过很多时间步连乘，容易变得非常小，从而导致模型难以记住很早之前的信息。

LSTM 的**核心改进是引入：**

- 记忆单元 $C_t$；
- 输入门 $I_t$；
- 遗忘门 $F_t$；
- 输出门 $O_t$。

其中，记忆单元 $C_t$ 用来**保存长期信息**，**三个门用来控制信息的写入、保留和输出。**

## 1. 输入门 Input Gate

输入门控制当前**新信息写入**多少。

$ I_t = \sigma(X_tW_{xi}+H_{t-1}W_{hi}+b_i) $

如果 **$I_t$ 接近 1，新信息大量写入**；如果接近 0，新信息基本不写入。

## 2. 遗忘门 Forget Gate

遗忘门控制**上一时刻记忆保留**多少。

$ F_t = \sigma(X_tW_{xf}+H_{t-1}W_{hf}+b_f) $

如果 $F_t$ 接近 1，旧记忆保留；如果接近 0，旧记忆遗忘。

## 3. 候选记忆 Candidate Memory

候选记忆表示当前时间步**可能写入的新内容：**

$ \tilde{C}*t=\tanh(X_tW*{xc}+H_{t-1}W_{hc}+b_c) $

## 4. 记忆单元更新

LSTM 的核心公式是：

$C_t=F_t\odot C_{t-1}+I_t\odot \tilde{C}_t$

这表示**当前记忆**由两部分组成：

- $F_t\odot C_{t-1}$：保留旧记忆；
- $I_t\odot \tilde{C}_t$：写入新记忆。

## 5. 输出门 Output Gate

输出门**控制记忆单元中有多少信息输出为隐藏状态**：

$O_t=\sigma(X_tW_{xo}+H_{t-1}W_{ho}+b_o)$

**隐藏状态为：**

**$H_t=O_t\odot \tanh(C_t)$**

# 为什么 LSTM 能解决长时依赖问题？

关键在于记忆单元 $C_t$。

如果模型**需要长期保存某个信息**，可以令：

$F_t \approx 1$

$I_t \approx 0$

则：

$C_t=F_t\odot C_{t-1}+I_t\odot \tilde{C}*t \approx C*{t-1}$

也就是说，**旧记忆可以沿着时间方向比较稳定地传递下去，而不会每一步都被重新计算和覆盖。**

因此，LSTM **通过记忆单元提供了一条长期信息传递路径**，并**通过门控机制选择性地遗忘无用信息、保留重要信息、写入新信息**，从而**缓解普通 RNN 的梯度消失问题**，更适合建模长距离依赖。

考场总结句：

**LSTM 是一种带门控机制的循环神经网络。它通过输入门、遗忘门、输出门和记忆单元控制信息的写入、保留和输出。由于记忆单元 $C_t$ 可以在遗忘门接近 1、输入门接近 0 时近似保持不变，因此重要信息能够跨越多个时间步稳定传递，从而缓解普通 RNN 的长时依赖和梯度消失问题。**

# 3. 请简述 YOLO 算法的主要思想和实现过程

YOLO，全称 **You Only Look Once**，是一种典型的 **单阶段目标检测算法 One-stage Object Detector**。它的核心思想是：

**把目标检测看成一个回归问题，直接从整张图像中一次性预测目标的类别和边界框，而不是先生成候选区域再分类。**

传统 R-CNN 系列通常是两阶段方法：

先找候选区域，再对候选区域分类和回归边界框。

而 YOLO 是：

**输入一张图像，只经过一次神经网络前向传播，就同时输出多个目标的位置和类别。**

因此 YOLO 的特点是：

- 检测速度快；
- 适合实时目标检测；
- 整体上把分类和定位统一到一个网络中完成。

## YOLO 的主要实现过程

第一步，将输入图像划分为网格。

YOLO 会把图像划分成 $S \times S$ 个网格。每个**网格负责检测中心点落在该网格内的目标。**

例如图像被划分为 $7 \times 7$ 网格，如果某个物体中心落在第 $(i,j)$ 个网格中，那么这个网格负责预测该物体。

第二步，每个网格预测若干个边界框。

每个网格会预测 $B$ 个 bounding boxes。每个边界框通常包含：

- 边界框中心坐标 $(x,y)$；
- 宽高 $(w,h)$；
- 置信度 confidence。

置信度可以理解为：

**该框中是否有目标，以及预测框和真实框重合程度有多高。**

常见形式可以理解为：

$confidence = P(object) \times IoU$

第三步，每个网格**预测类别概率。**

每个网格还会预测**该目标属于各个类别的概率，例如：**

**人、车、狗、猫等。**

第四步，组合类别概率和边界框置信度。

对每个预测框，可以得到某个类别的最终得分：

$class\ score = P(class|object) \times confidence$

这个分数表示：

**该框包含某一类别目标的可信程度。**

第五步，使用 **NMS 去除重复框。**

由于多个网格或多个边界框可能检测到同一个目标，所以需要使用 **NMS 非极大值抑制**。

NMS 的过程是：

1. 按置信度从高到低排序；
2. **保留置信度最高的框；**
3. 删除与**它 IoU 过高的低分框；**
4. 重复该过程，最终得到检测结果。

## YOLO 的优缺点

YOLO 的优点是**速度快、流程简单、可以端到端训练，适合实时检测任务。**

YOLO 的缺点是早期版本对小目标、密集目标和定位精度的处理相对较弱，因为它用网格负责目标检测，如果**多个小目标落在同一网格中，可能难以同时检测。**

考场总结版：

**YOLO 将目标检测转化为单个神经网络的回归问题。它把图像划分为 $S \times S$ 网格，每个网格预测若干边界框、置信度和类别概率，然后结合置信度与类别概率得到最终检测分数，最后通过 NMS 去除重复框。YOLO 只需一次前向传播即可完成检测，因此速度快，适合实时目标检测。**

# 4. 请简述 GRU 网络的主要思想

GRU，全称 **Gated Recurrent Unit，门控循环单元**，是一种改进的循环神经网络。它主要用于缓解普通 RNN 在长序列中容易出现的**梯度消失**和**长期依赖难以学习**的问题。

普通 RNN 的隐藏状态更新为：

$H_t=\tanh(X_tW_{xh}+H_{t-1}W_{hh}+b_h)$

普通 RNN 每个时间步都会直接用当前输入和上一隐藏状态重新计算新的隐藏状态，因此早期信息容易被不断覆盖，长序列中难以保留重要历史信息。

GRU 的核心思想是：

**引入门控机制，让网络自己决定哪些历史信息应该保留，哪些信息应该遗忘，哪些新信息应该写入。**

GRU 主要有两个门：

## 1. 更新门 Update Gate

更新门记作 $Z_t$，用于**控制上一时刻隐藏状态保留多少，以及当前候选状态写入多少。**

公式：

$Z_t=\sigma(X_tW_{xz}+H_{t-1}W_{hz}+b_z)$

最终隐藏状态更新为：

$H_t=Z_t\odot H_{t-1}+(1-Z_t)\odot \tilde{H}_t$

其中：

- $H_{t-1}$ 是旧隐藏状态；
- $\tilde{H}_t$ 是候选隐藏状态；
- $Z_t$ 控制旧信息保留比例。

如果 $Z_t \approx 1$，则：

$H_t \approx H_{t-1}$

说明模型主要保留过去信息，有利于长期记忆。

如果 $Z_t \approx 0$，则：

$H_t \approx \tilde{H}_t$

说明模型主要采用当前新信息。

所以：

**更新门决定旧状态和新状态之间如何平衡。**

## 2. 重置门 Reset Gate

重置门记作 $R_t$，用于**控制在计算候选隐藏状态时，上一时刻隐藏状态参与多少。**

公式：

$R_t=\sigma(X_tW_{xr}+H_{t-1}W_{hr}+b_r)$

**候选隐藏状态**为：

$\tilde{H}*t=\tanh(X_tW*{xh}+(R_t\odot H_{t-1})W_{hh}+b_h)$

如果 $R_t \approx 0$，则：

$R_t\odot H_{t-1}\approx 0$

说明**过去信息基本被重置，候选状态主要由当前输入决定。**

如果 $R_t \approx 1$，说明过去隐藏状态被保留，模型会参考历史信息。

所以：

**重置门决定计算新候选状态时要不要参考过去信息。**

## GRU 为什么能缓解长时依赖问题？

GRU 通过**更新**门**提供了一条保留旧隐藏状态的路径**：

$H_t=Z_t\odot H_{t-1}+(1-Z_t)\odot \tilde{H}_t$

当**更新门 $Z_t$ 长时间接近 1 时**，隐藏状态**可以近似保持不变：**

$H_t\approx H_{t-1}$

这样**重要历史信息可以跨越多个时间步传递**，**不容易被当前输入覆盖**，从而缓解普通 RNN 的长期依赖问题。

## GRU 和 LSTM 的区别

GRU 和 LSTM 都是门控循环网络。

区别是：

- GRU 有两个门：更新门、重置门；
- LSTM 有三个门：输入门、遗忘门、输出门；
- GRU 没有独立的记忆单元 $C_t$；
- LSTM 有独立记忆单元 $C_t$；
- GRU 参数更少，训练通常更快；
- LSTM 结构更复杂，长序列任务中通常更稳定。

考场总结版：

**GRU 是一种带门控机制的循环神经网络。它通过更新门控制旧隐藏状态保留多少、新候选状态写入多少，通过重置门控制计算候选状态时参考多少历史信息。由于更新门可以让重要历史状态在多个时间步中持续保留，GRU 能够缓解普通 RNN 的梯度消失和长时依赖问题。**

# 1. 请简述 Dropout 的实现方式，并阐述它解决过拟合问题的原因

Dropout 是一种常用的正则化方法，主要用于缓解神经网络的过拟合。它的核心思想是：

**在训练过程中随机丢弃一部分神经元，使模型不能过度依赖某些特定神经元组合，从而提高泛化能力。**

## Dropout 的实现方式

在训练阶段，设某一层隐藏单元输出为 $h$，Dropout 会随机生成一个掩码 $m$：

$m_i \sim Bernoulli(1-p)$

其中：

- $p$ 是 dropout 概率，**表示神经元被丢弃的概率；**
- $1-p$ 是神经元被保留的概率；
- $m_i=0$ 表示该神经元被丢弃；
- $m_i=1$ 表示该神经元被保留。

为了保持输出期望不变，常用 inverted dropout：

$h_i'=\frac{m_i h_i}{1-p}$

也就是说，训练时被保留的神经元**输出会除以 $1-p$，以补偿被丢弃神经元带来的整体输出变小。**

在测试阶段，不再随机丢弃神经元，而是使用完整网络进行预测。

所以：

**训练阶段随机丢弃，测试阶段不丢弃。**

## Dropout 为什么能缓解过拟合？

过拟合时，模型可能**过度依赖训练数据中的某些局部特征或某些神经元组合，从而在训练集上表现很好，但在测试集上泛化能力差。**

Dropout 通过随机丢弃神经元，使每次训练时网络结构都不同。这样模型**不能依赖某几个固定神经元，而必须学习更加分散、更加鲁棒的特征表示。**

可以从三个角度理解：

第一，减少神经元之间的共适应关系。

如果某些神经元总是一起工作，模型可能记住训练集细节。Dropout 随机打破这种固定组合，使模型学习更通用的特征。

第二，相当于训练多个子网络。

每次随机丢弃不同神经元，相当于训练不同的子网络；测试时使用完整网络，近似于多个子网络的集成平均，因此泛化能力更好。

第三，降低模型有效复杂度。

虽然原网络参数量没有减少，但训练时每次只使用部分神经元，相当于限制模型过度拟合训练集。

考场总结版：

**Dropout 在训练阶段以一定概率随机将部分神经元输出置为 0，并对保留神经元进行缩放；测试阶段使用完整网络。它通过破坏神经元之间的共适应关系，使模型不能依赖少数特征组合，相当于训练多个子网络的集成，从而降低过拟合、提高泛化能力。**

# 2. 请简述你对 Batch Normalization 的理解，并说明其在训练和测试阶段如何实现

Batch Normalization，简称 BN，中文叫 **批量归一化**。它是一种用于稳定神经网络训练的方法。

它的核心思想是：

**对神经网络中间层的输入或输出进行标准化，使其分布更加稳定，然后再通过可学习参数恢复表达能力。**

## Batch Normalization 的基本计算

对一个 mini-batch 中某个特征，**先计算均值和方差：**

$\mu_B=\frac{1}{m}\sum_{i=1}^{m}x_i$

$\sigma_B^2=\frac{1}{m}\sum_{i=1}^{m}(x_i-\mu_B)^2$

然后进行**标准化：**

$\hat{x}_i=\frac{x_i-\mu_B}{\sqrt{\sigma_B^2+\epsilon}}$

其中 $\epsilon$ 是一个很小的常数，用于**防止除以 0。**

最后**进行缩放和平移：**

$y_i=\gamma \hat{x}_i+\beta$

其中：

- **$\gamma$ 是可学习的缩放参数；**
- **$\beta$ 是可学习的平移参数。**

为什么需要 $\gamma,\beta$？

因为如果只做标准化，输出会被**强制变成均值为 0、方差为 1，可能限制模型表达能力。**加入 $\gamma,\beta$ 后，模型可以自**己学习合适的分布尺度和偏移。**

## BatchNorm 的作用

BatchNorm 的主要作用包括：

1. 稳定中间层特征分布；
2. 缓解梯度过大或过小；
3. 加快模型收敛；
4. 降低模型对初始化和学习率的敏感性；
5. 使深层网络更容易训练。

在 CNN 中，BN 通常放在卷积层和激活函数之间：

$Conv \to BN \to ReLU$

在全连接网络中，通常是：

$Linear \to BN \to ReLU$

## 训练阶段如何实现？

训练阶段，BatchNorm 使用**当前 mini-batch 的均值和方差**进行归一化。

也就是说，**每个 batch 都会计算**自己的：

$\mu_B$

$\sigma_B^2$

然后用它们标准化当前 batch 的数据。

同时，**训练过程中还会维护整体的移动平均统计量：**

$moving_mean$

$moving_variance$

这些统计量用于测试阶段。

训练阶段总结：

**用当前 mini-batch 的均值和方差归一化，并更新 moving mean 和 moving variance。**

## 测试阶段如何实现？

测试阶段不能再依赖当前 mini-batch 的统计量。

原因是：

测试时 batch size 可能很小，甚至只有一个样本；如果用当前 batch 的均值和方差，会导致输出不稳定。

因此测试阶段使用训练过程中累计得到的：

$moving_mean$

$moving_variance$

进行归一化。

测试阶段公式可以理解为：

$\hat{x}=\frac{x-moving_mean}{\sqrt{moving_variance+\epsilon}}$

$y=\gamma \hat{x}+\beta$

测试阶段总结：

**不用当前 batch 的统计量，而使用训练阶段保存的 moving mean 和 moving variance，保证预测结果稳定。**

## 考场总结版

**Batch Normalization 是对神经网络中间层特征进行标准化的方法。训练时，它使用当前 mini-batch 的均值和方差对特征归一化，并通过可学习参数 $\gamma,\beta$ 进行缩放和平移，同时更新 moving mean 和 moving variance。测试时，为了保证输出稳定，不再使用当前 batch 的统计量，而使用训练阶段累计的 moving mean 和 moving variance。BN 可以稳定中间层分布、加快收敛、缓解梯度问题，使深层网络更容易训练。**



你记得的 **“aa、ab、bb”** 很像老师在讲 **语言模型 Language Model 里的 bigram / 二元语法模型** 时举的计算题。

因为如果有一个字符序列：

$a\ a\ b\ b$

那么相邻两个字符组成的 bigram 就是：

$aa,\ ab,\ bb$

这正好对应你记住的 “aa ab bb”。

你们实验里也明确有语言模型数据构造：输入是 $x_1,x_2,x_3,x_4$，标签是右移一位的 $x_2,x_3,x_4,x_5$，本质就是“根据当前词预测下一个词”。

# 最可能的题型：Bigram 词预测概率计算

题目可能长这样：

给定语料：

$a\ a\ b\ b$

请统计 bigram，并计算：

$P(a|a), P(b|a), P(a|b), P(b|b)$

也就是：

**已知前一个字符，预测下一个字符的概率。**

------

# 1. 先统计 bigram

序列是：

位置 1：$a$
位置 2：$a$
位置 3：$b$
位置 4：$b$

**相邻 bigram：**

$(a,a)$

$(a,b)$

$(b,b)$

所以计数：

$C(aa)=1$

$C(ab)=1$

$C(bb)=1$

$C(ba)=0$

------

# 2. 统计作为“前一个词”的出现次数

注意这里不是简单统计 $a,b$ 总出现次数，而是统计它作为上下文，也就是作为 bigram **第一个元素出现多少次。**

在：

$aa,\ ab,\ bb$

里：

$a$ **作为前一个词出现 2 次**：

$aa,\ ab$

所以：

$C_{context}(a)=2$

$b$ 作为前一个词出现 1 次：

$bb$

所以：

$C_{context}(b)=1$

------

# 3. 计算条件概率

公式：

$P(next|current)=\frac{C(current,next)}{C_{context}(current)}$

所以：

$P(a|a)=\frac{C(aa)}{C_{context}(a)}=\frac{1}{2}$

$P(b|a)=\frac{C(ab)}{C_{context}(a)}=\frac{1}{2}$

$P(a|b)=\frac{C(ba)}{C_{context}(b)}=\frac{0}{1}=0$

$P(b|b)=\frac{C(bb)}{C_{context}(b)}=\frac{1}{1}=1$

所以概率表是：

| 当前词 | 下一个是 $a$  | 下一个是 $b$  |
| ------ | ------------- | ------------- |
| $a$    | $\frac{1}{2}$ | $\frac{1}{2}$ |
| $b$    | $0$           | $1$           |

------

# 4. 如果题目让算序列概率

比如问：

在 bigram 模型下，序列 $aabb$ 的概率是多少？

通常写成：

$P(aabb)=P(a)P(a|a)P(b|a)P(b|b)$

如果用 unigram 估计：

$P(a)=\frac{2}{4}=\frac{1}{2}$

那么：

$P(aabb)=\frac{1}{2}\times \frac{1}{2}\times \frac{1}{2}\times 1=\frac{1}{8}$

如果题目只关心“根据前一个词预测下一个词”，可能只算转移概率：

$P(a|a)P(b|a)P(b|b)=\frac{1}{2}\times \frac{1}{2}\times 1=\frac{1}{4}$

考试时要看题目有没有要求包含第一个词的先验概率 $P(a)$。

------

# 5. 如果题目加了平滑 smoothing

有时老师可能会问：

如果不用平滑，$P(a|b)=0$，这有什么问题？

问题是：

只要一个 bigram 没在训练语料出现，它的概率就是 0。这样如果测试句子里出现了 $ba$，整个句子概率就变成 0。

所以会加 **Laplace smoothing / 加一平滑**。

公式：

$P(next|current)=\frac{C(current,next)+1}{C_{context}(current)+|V|}$

这里词表是：

$V={a,b}$

所以：

$|V|=2$

计算：

$P(a|a)=\frac{C(aa)+1}{C_{context}(a)+2}=\frac{1+1}{2+2}=\frac{1}{2}$

$P(b|a)=\frac{1+1}{2+2}=\frac{1}{2}$

$P(a|b)=\frac{0+1}{1+2}=\frac{1}{3}$

$P(b|b)=\frac{1+1}{1+2}=\frac{2}{3}$

平滑后就不会出现 0 概率。

------

# 6. 这题可能考的核心点

你上课问的那个题，大概率想考这几个点之一：

## 题型 A：统计 bigram

给序列：

$aabb$

问 bigram 有哪些？

答案：

$aa,ab,bb$

## 题型 B：计算转移概率

问：

$P(a|a),P(b|a),P(a|b),P(b|b)$

答案：

$P(a|a)=\frac{1}{2}$

$P(b|a)=\frac{1}{2}$

$P(a|b)=0$

$P(b|b)=1$

## 题型 C：计算序列概率

问：

用 bigram 模型计算 $P(aabb)$

答案：

$P(aabb)=P(a)P(a|a)P(b|a)P(b|b)$

如果 $P(a)=\frac{1}{2}$：

$P(aabb)=\frac{1}{8}$

## 题型 D：解释为什么需要平滑

因为没出现过的 bigram 概率为 0，会导致整个句子概率为 0。加一平滑可以避免零概率问题。

------

# 7. 和 RNN 语言模型的关系

这个 bigram 题其实是 RNN 语言模型的前置基础。

bigram 模型是：

$P(x_t|x_{t-1})$

只看前一个词。

RNN 语言模型是：

$P(x_t|x_1,x_2,\cdots,x_{t-1})$

理论上可以利用更长历史。

所以如果老师从 $aa,ab,bb$ 开始讲，很可能是在说明：

**语言模型就是根据前文预测下一个 token。**

最小版本是 bigram，深度学习版本就是 RNN / GRU / LSTM / Transformer 语言模型。
