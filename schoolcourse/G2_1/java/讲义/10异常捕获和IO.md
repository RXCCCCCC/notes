# Java 期末复习讲义：第12章 异常处理与文本 I/O

## 1. 异常处理概览 (Motivation & Overview)

### 核心概念
*   **什么是异常 (Exception)?** 程序运行过程中发生的运行时错误（Runtime Error），导致程序非正常终止。
*   **为什么需要异常处理?** 为了让程序在遇到错误时能够**优雅地终止 (terminate gracefully)** 或者**恢复运行 (continue to run)**，而不是直接崩溃退出。
*   **机制:** 将错误处理代码从正常的业务逻辑代码中分离出来，提高代码的可读性和可维护性。

---

## 2. 异常类的层次结构 (The Hierarchy)

这是考试中填空题和选择题的常考点，请务必背诵以下继承关系。

所有的异常类都继承自 `java.lang.Throwable`。

1.  **`Throwable`** (根类)
    *   **`Error` (错误)**:
        *   **含义**: JVM 内部的严重问题，通常资源耗尽或系统错误。
        *   **特点**: 程序通常**无法恢复**，也不应该尝试去捕获它。
        *   **例子**: `OutOfMemoryError` (内存溢出), `StackOverflowError` (栈溢出), `VirtualMachineError`.
    *   **`Exception` (异常)**:
        *   **含义**: 程序本身产生的错误或外部环境问题。程序**可以捕获并处理**。
        *   **两大分类**:
            1.  **`RuntimeException`**: 程序逻辑错误（如数组越界、空指针）。
            2.  **其他 Exception**: 外部环境问题（如文件未找到、网络断开）。

---

## 3. Checked vs. Unchecked Exceptions (考试重难点)

这是 Java 异常体系中最独特的特性，也是与 C++ 最大的不同点之一。

| 类型           | **Unchecked Exception (免检异常)**                           | **Checked Exception (必检异常)**                             |
| :------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **包含类**     | `RuntimeException`, `Error` 及其子类                         | `Exception` 下除了 RuntimeException 以外的所有类             |
| **典型例子**   | `NullPointerException`, `IndexOutOfBoundsException`, `ArithmeticException` (/0) | `IOException`, `ClassNotFoundException`, `SQLException`      |
| **编译器行为** | 编译器**不强制**要求处理。                                   | 编译器**强制**要求处理 (Must be caught or declared)。        |
| **产生原因**   | 通常是**编程逻辑错误** (可以修复代码避免)。                  | 通常是**不可控的外部因素** (文件不存在、网络中断)。          |
| **处理策略**   | 一般不捕获，而是修改代码逻辑。                               | 必须使用 `try-catch` 捕获 或者 在方法签名上 `throws` 声明抛出。 |

## 4. 语法与关键字 (Syntax & Keywords)

### A. 声明与抛出 (Declaring & Throwing)
*   **`throw` (动作)**: 在方法体内，手动抛出一个异常对象。
    ```java
    if (radius < 0) {
        throw new IllegalArgumentException("Radius cannot be negative");
    }
    ```
*   **`throws` (声明)**: 在方法签名上，告诉调用者这个方法可能会抛出异常（针对 Checked Exception 必须声明）。
    ```java
    public void myMethod() throws IOException, ClassNotFoundException {
        // ...
    }
    ```

### B. 捕获 (Catching)
*   **基本结构**:
    ```java
    try {
        // 可能抛出异常的代码
        statement1;
        statement2; // 假设这里抛出了异常
        statement3; // 这句将被跳过
    } catch (ExceptionType1 ex) {
        // 处理 Type1 异常
    } catch (ExceptionType2 ex) {
        // 处理 Type2 异常
    } finally {
        // 无论是否发生异常，永远会执行的代码 (用于资源释放)
    }
    ```

### C. 重新抛出 (Rethrowing)
*   在 catch 块中，如果处理不了，可以将异常再次抛出给上层调用者。
    ```java
    catch (Exception ex) {
        // 做一些记录日志的工作
        throw ex; // 把异常扔给调用这个方法的人去处理
    }
    ```

## 5. 执行流程追踪 (Tracing Execution) - ⚠️ 读代码题必考

考试中常给出一段嵌套的 try-catch-finally 代码，让你写出输出结果。

**规则：**
1.  一旦 try 块中发生异常，剩余的 try 块代码**立即跳过**。
2.  JVM 寻找匹配的 `catch` 块。
    *   **多态匹配**: `catch (Exception ex)` 可以捕获所有 Exception 的子类。
    *   **顺序很重要**: 子类异常必须写在父类异常**之前**。如果 `catch (Exception e)` 写在 `catch (IOException e)` 前面，代码编译报错（Unreachable code）。
3.  **`finally` 块永远执行**：
    *   即使 try 中有 `return`。
    *   即使 catch 中有 `return`。
    *   即使 catch 中又 `throw` 了新异常。
    *   **唯一例外**: `System.exit(0)` 会直接终止 JVM，finally 不执行。

**示例代码分析：**
```java
try {
    System.out.println("Start");
    throw new RuntimeException("Error");
    // System.out.println("Unreachable"); // 不会执行
} catch (RuntimeException ex) {
    System.out.println("Caught");
    // return; // 即使这里 return，finally 依然执行
} finally {
    System.out.println("Finally");
}
System.out.println("End");
```
**输出**:
```text
Start
Caught
Finally
End
```

## 6. 自定义异常 (Custom Exceptions)

当 JDK 自带的异常无法描述你的业务错误时，可以自定义异常。
*   通常继承 `Exception` (变为 Checked) 或 `RuntimeException` (变为 Unchecked)。
*   代码非常简单，主要是构造器：

```java
public class InvalidRadiusException extends Exception {
    private double radius;

    public InvalidRadiusException(double radius) {
        super("Invalid radius: " + radius);
        this.radius = radius;
    }
    
    public double getRadius() { return radius; }
}
```

```java
public class Circle {
    private double radius;

    // 构造器：初始化半径
    public Circle(double radius) {
        this.radius = radius;
    }

    /**
     * 计算圆的面积
     * @return 面积值
     * @throws InvalidRadiusException 若半径 <= 0，则抛出此异常
     */
    public double calculateArea() throws InvalidRadiusException {
        if (radius <= 0) {
            // 当半径无效时，抛出自定义异常（携带无效的半径值）
            throw new InvalidRadiusException(radius);
        }
        return Math.PI * radius * radius; // 正常计算面积
    }

    // 主方法：测试自定义异常
    public static void main(String[] args) {
        try {
            // 模拟“传入无效半径（负数）”的场景
            Circle circle = new Circle(-5);
            double area = circle.calculateArea();
            System.out.println("圆的面积是: " + area);
        } catch (InvalidRadiusException e) {
            // 捕获自定义异常，并打印错误信息
            System.out.println("捕获到异常: " + e.getMessage()); // 输出: Invalid radius: -5.0
            System.out.println("无效的半径是: " + e.getRadius()); // 输出: -5.0
        }
    }
}

```

## 7. Java vs. C++ (异常处理差异) - ⚠️ 课件第5页重点

这是面试和比较语言特性的考试中常见的问题。

| 特性             | **Java**                                                     | **C++**                                                      |
| :--------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **可抛出的类型** | 只能抛出 `Throwable` 及其子类的**对象**。                    | 可以抛出任何类型 (int, string, class object 等)。            |
| **Catch All**    | 使用 `catch(Exception e)` 捕获大部分，通常不捕获 Throwable。 | 使用 `catch(...)` 捕获所有异常。                             |
| **Finally 块**   | **有 `finally` 块**，用于清理资源。                          | **无 `finally` 块**。C++ 依赖析构函数 (RAII) 清理资源。      |
| **异常分类**     | 区分 Checked (必须处理) 和 Unchecked。                       | 所有异常都是 Unchecked (不强制处理)。                        |
| **Throws 声明**  | 关键字 `throws` 强制列出可能抛出的 Checked 异常。            | 关键字 `throw` (注意少个s) 用于列出异常，但主要是文档作用（C++11后用 noexcept）。 |

## 8. 文本 I/O (Text Input/Output)

### A. `File` 类 (java.io.File)
*   **注意**: `File` 对象**不包含**读写文件的方法！它只是文件或目录路径的**抽象表示**（Wrapper）。
*   **常用方法**: `exists()`, `canRead()`, `isDirectory()`, `length()`, `getAbsolutePath()`.

### B. 写文件: `PrintWriter`
*   类似于 `System.out` (它是 PrintStream，与 PrintWriter 类似)。
*   **必须关闭**: 如果不调用 `.close()`，数据可能还在缓冲区中，不会写入硬盘。
*   **常用方法**: `print()`, `println()`, `printf()`.

### C. 读文件: `Scanner`
*   不仅可以从控制台读 (`new Scanner(System.in)`), 也可以从文件读。
*   **构造**: `Scanner input = new Scanner(new File("input.txt"));`
*   **常用方法**: `next()`, `nextInt()`, `nextLine()`, `hasNext()`.

### D. 从 Web 读取
*   使用 `java.net.URL`。
*   `Scanner input = new Scanner(new URL("http://google.com").openStream());`

### E. Try-with-resources (JDK 7+) - ⚠️ 推荐写法
为了防止忘记写 `close()`，Java 7 引入了自动资源管理。
只要实现了 `AutoCloseable` 接口的资源（如 PrintWriter, Scanner）都可以这样写：

```java
// 括号内声明资源，try 块结束自动调用 close()
try (PrintWriter output = new PrintWriter("file.txt");
     Scanner input = new Scanner(new File("other.txt"))) {
    
    output.println("Hello");
    // 不需要显式调用 output.close()
} catch (FileNotFoundException e) {
    e.printStackTrace();
}
```

## 9. 易错点与考试坑点 (Pitfalls)

1.  **Catch 的顺序**:
    *   **错误写法**: 先 catch `Exception`，后 catch `IOException`。
    *   **原因**: `IOException` 是 `Exception` 的子类。父类捕获范围大，放在前面会拦截掉所有子类异常，后面的 catch 块永远无法到达（Unreachable code）。
    *   **正确**: 子类在上，父类在下。

2.  **Checked Exception 必须处理**:
    *   如果在 `main` 方法中调用了抛出 `IOException` 的方法，`main` 方法要么 try-catch，要么也声明 `throws IOException`。如果什么都不做，**编译不通过**。

3.  **`File` 类无法读写**:
    *   代码题中如果出现 `new File("t.txt").write("abc")` 是错的。必须配合 `PrintWriter` 或 `FileOutputStream`。

4.  **Try-with-resources 的语法**:
    *   资源声明必须在 `try` 后面的圆括号 `()` 里，而不是大括号 `{}` 里。

5.  **Finally 中的变量作用域**:
    *   如果在 try 块内部定义变量 `int x = 10;`，在 finally 块中是**访问不到** `x` 的。变量必须在 try 之前定义。

6.  **RuntimeException 不需要声明**:
    *   即使方法内部 `throw new NullPointerException()`，方法签名**不需要**写 `throws NullPointerException`。

## 10. 复习代码模版 (Cheat Sheet)

```java
import java.io.*;
import java.util.*;

public class ExamReview {
    // 1. 声明抛出 Checked Exception
    public static void main(String[] args) throws IOException {
        
        File file = new File("test.txt");
        
        // 2. Try-with-resources (自动关闭)
        try (PrintWriter output = new PrintWriter(file)) {
            output.println("Java IO is fun");
        } 
        // 3. 捕获具体的 Checked Exception
        catch (FileNotFoundException ex) {
            System.out.println("File error: " + ex.getMessage());
        } 
        // 4. 捕获更广泛的 Exception (多态)
        catch (Exception ex) {
            System.out.println("Other error");
        } 
        // 5. Finally 总是执行
        finally {
            System.out.println("Done writing.");
        }

        // 6. 读取文件
        try (Scanner input = new Scanner(file)) {
            while (input.hasNext()) {
                String s = input.next();
                System.out.println(s);
            }
        }
    }

    // 7. 自定义方法手动抛出异常
    public static void checkAge(int age) {
        if (age < 0) {
            // Unchecked Exception, 不需要 throws 声明
            throw new IllegalArgumentException("Age cannot be negative");
        }
    }
}
```
