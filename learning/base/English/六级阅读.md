# 段落匹配

同阅读,第一遍**(快)**先**快速扫过全文有各个初步印象(大概理解就行,然后读几段就回扫选项勾画),该划划**,稍微**能做就做做几个题**，第二遍**(全)**就**以此勾画后再做题**

# 仔细阅读

先看**题干（注意设问暗示）**但是**不先看选项（防止先入为主）**，**先夹逼定位文章区域（无定位词就由段落逻辑推）**
**以有主题句角度去大概理解后再做**题
**读几段就回看一个题**，一定要**找到完全（不是擦边）切题的内容**再确定（**正确的同义转换**太重要了），然后**比较四个（不能提前锁定了一个其他的就漏掉了）选择最好**的那个

切忌**自己臆断推断**,原文中一定有相关切实依据,**对就是有依据**

警惕**半对**,**对但不切题**的迷惑选项
